## 逐篇要点

### 1. [Motus2: A Self-Evolving General World Model for Dexterous Manipulation](https://arxiv.org/abs/2608.30237)
- 事实：论文提出 Motus2，把策略、动作条件世界模拟器和值评估器放进同一套共享权重接口，用于 dexterous manipulation 的闭环自演化。
- 方法：候选 action chunk 由 policy 提出，simulator 预测视觉后果，evaluator 评价结果，并把失败/次优交互转成后续 dynamics 与 value 学习信号。
- 推断：这是今天最贴近“灵巧操作 × 世界模型 × 具身智能”的论文；主要风险在于真实灵巧手接触、遮挡和长时稳定性是否真的被模型状态承载。
- 值得关注：如果代码/数据开放充分，它可以成为后续做 VLA-dexterous、open-loop vs closed-loop 控制实验的核心参照。

### 2. [AnyWorld: Factorized Egocentric World Models for Cross-Embodiment Generalization](https://arxiv.org/abs/2608.29242)
- 事实：AnyWorld 用人类第一视角交互视频扩展为 robot-native rollouts，并把交互因子分解为 action、camera 和 embodiment。
- 方法：先进行大规模 human interaction 预训练，再混合 embodiment 微调，让同一交互可重组到不同视角、场景和机器人身体。
- 推断：亮点是把 human-object physical interaction 作为机器人经验扩增源；局限是人手接触到机器人末端执行器的力学差异可能被视觉世界模型掩盖。
- 值得关注：适合跟 3D HOI、affordance-guided manipulation、human-to-robot demonstration transfer 方向连接。

### 3. [AGM: Achievement-Grounded Memory for Closed-Loop Agents with Frozen VLA Policies](https://arxiv.org/abs/2608.29537)
- 事实：AGM 针对 frozen VLA policy 的 open-loop action chunk 问题，引入 achievement-grounded memory 来决定继续、重试或停止。
- 方法：把任务写成 subgoal sequence，只在物理证据验证当前子目标完成后推进 progress pointer；验证头只有 2.43M 参数。
- 推断：这是低成本修补 VLA 闭环执行的强候选；风险在于验证器的错误会直接变成高层状态错误。
- 值得关注：和“可验证 memory update”以及机器人任务级 state tracking 很相关。

### 4. [CometVLA: Co-Training on an Embodied Data Pyramid towards Physical Understanding](https://arxiv.org/abs/2608.30289)
- 事实：CometVLA 构建与机器人动作数据和 embodiment 对齐的 embodied physical VQA 数据与 benchmark，并用 Global Action Prior token 连接物理理解和动作生成。
- 方法：在 teleoperation、simulation、egocentric video、physical VQA 等数据金字塔上共同训练，试图避免 VLM 物理常识与 robot action domain 脱节。
- 推断：贡献在于把“物理问答是否帮助动作”变成可测问题；局限是 GAP bottleneck 是否真的携带可泛化动力学，而非数据集偏置。
- 值得关注：对 VLA manipulation、物理常识和低维动作先验都值得细读。

### 5. [Training-Free Action Correction for VLA Model Failures via Language Feedback](https://arxiv.org/abs/2608.29967)
- 事实：CorrectVLA 在不改 VLA 权重的前提下，把一次任务级语言纠正转成 additive action magnitude adjustment。
- 方法：针对 execution misalignment failure，统一作用于后续 rollouts；在 LIBERO-90 和 xArm7 环境偏移中测试。
- 推断：它明确区分可纠正的执行幅值错误和不可纠正的语义理解错误，是很好的 failure taxonomy 入口。
- 值得关注：低算力可复现度高，适合做 VLA 错误修复和人类反馈接口的小实验。

### 6. [SymVD: Symmetric Vision Language Action Distillation for Robot Manipulation](https://arxiv.org/abs/2608.29828)
- 事实：SymVD 用几何对称性做 VLA teacher 到 compact student policy 的蒸馏，主分类为 eess.SY。
- 方法：采用 equivariant actor-critic 和 symmetry-aware objective，让旋转/反射等群变换下的 teacher action 对齐。
- 推断：它把 manipulation task 的几何不变性显式放进蒸馏目标；风险是复杂接触任务的对称性可能并不严格成立。
- 值得关注：和小模型机器人策略、低数据 VLA adaptation、affordance 等变先验都有交叉。

### 7. [Blind Dexterity: Whole-Body Humanoid Manipulation via Pure Proprioception](https://arxiv.org/abs/2608.29487)
- 事实：Blind Dexterity 在 Unitree G1 上只用 proprioception，不用视觉、marker、force-torque 或 tactile sensor，学习全身 humanoid manipulation。
- 方法：通过主动接触动作让关节编码器历史变成“全身触觉”通道，并用独立小型状态估计器揭示可解码的物体状态。
- 推断：核心机制有很强启发性：接触动作本身是信息采集；局限是任务范围和物体几何复杂度仍需谨慎看实验。
- 值得关注：对 tactile dexterity、blind manipulation、active perception 都非常重要。

### 8. [$\mathcal{N}_0$-Foundation: Towards the Age of Tactile Intelligence](https://arxiv.org/abs/2608.29601)
- 事实：N0-Foundation 提出 tactile-enabled embodied manipulation 范式，包含触觉硬件、NeoData、OpenNeoData 和 NeoForce 表征模型。
- 方法：用大规模同步视觉-触觉 demonstration 与三轴力场监督，学习跨传感器/跨 embodiment 的 tactile representation。
- 推断：如果数据真实可用，会明显推进 tactile foundation model；风险是大规模采集声明和开放子集质量需要核验。
- 值得关注：这是今天触觉方向最系统的一篇，和 dexterous hand 的接触状态建模直接相关。

### 9. [The Potential of Haptic Foundation Models](https://arxiv.org/abs/2608.28664)
- 事实：论文综述/展望 Haptic Foundation Models，讨论触觉数据、动作耦合、连续时序和未来状态预测。
- 方法：整理大规模 tactile datasets，并在 TacBench 上比较 UniTouch、AnyTouch、T3、Sparsh 等模型。
- 推断：更像 position/survey paper，不是单一新算法；价值在于给 tactile-dexterity 建立评价维度。
- 值得关注：适合快速建立 haptic foundation model 的术语和 benchmark 地图。

### 10. [SpectraTac: A Compact Camera-Free Optical Tactile Sensor with Distributed Color Sensing](https://arxiv.org/abs/2608.30368)
- 事实：SpectraTac 是低成本、无相机的光学触觉传感器，用分布式颜色传感估计 3D 力和接触区域。
- 方法：弹性透明体接触变形改变内部 RGB 光场，三个颜色传感器输出低维 spatio-spectral features。
- 推断：硬件思路适合低算力边缘机器人；局限是复杂接触、多点接触和长期标定漂移需要验证。
- 值得关注：对把触觉塞进小型夹爪/灵巧手有直接工程价值。

### 11. [Anomaly Detection on Small Industrial Components via Vision-Based Tactile Sensing](https://arxiv.org/abs/2608.30506)
- 事实：论文用 GelSight Mini + 协作机器人采集小型工业部件触觉数据，并系统评估无监督 anomaly detection 方法。
- 方法：比较 SPADE、PaDiM、FAPM、InReaCh，并设置贴近触觉部署约束的验证协议。
- 推断：虽然不是 dexterous hand，但它把 tactile perception 放到真实检测任务中；局限是对象和缺陷类型可能较窄。
- 值得关注：可以借鉴其触觉表征、接触采样和异常定位协议到手内操作质量检测。

### 12. [Proximity3D: Shape from Capacitive Proximity on Sensing Manifold](https://arxiv.org/abs/2608.30344)
- 事实：Proximity3D 用曲面电容纺织传感器上的 proximity field 重建物体形状。
- 方法：把非平面 sensing manifold 上的多视角电容场聚合为 feed-forward 3D reconstruction。
- 推断：它连接接触前感知、手掌传感和 3D 形状估计；风险是仿真到真实的介电/几何泛化。
- 值得关注：适合关注“灵巧手在接触前估计可操作形状”的读者。

### 13. [DARP: A Calibrated Dual-Arm RGB-D-IR Dataset for Multi-View Robotic Perception](https://arxiv.org/abs/2608.31002)
- 事实：DARP 发布双臂 RGB-D-IR、多视角、eye-in-hand 的 object-centered robotic perception 数据集。
- 方法：两个独立移动的机械臂从桌面物体两侧采集 RGB、深度、红外和关节状态，并做自动定位与自适应视角生成。
- 推断：数据规模只有 10 个物体，可能更适合标定/感知 pipeline 研究而非大规模预训练。
- 值得关注：对 hand-object/dual-arm perception 的遮挡补全和 pose recovery 有参考价值。

### 14. [Zeva: In-Context Causal Learning for Generalizable Embodied Manipulation](https://arxiv.org/abs/2608.30880)
- 事实：Zeva 让机器人在部署时从自身物理交互中做 in-context causal learning，保持 policy model 冻结。
- 方法：Causal Interaction Extractor 把执行动作及其状态变化编码为 causal interaction signal，并写入双时间尺度 causal memory。
- 推断：这是 embodied manipulation 中“边做边学”的轻量路线；关键风险是因果信号是否稳定区分真实物理因果和观测噪声。
- 值得关注：与 AGM 一起构成 frozen policy 的闭环适配方向。

### 15. [Behavior-Skill: A Fine-Grained Benchmark for Evaluating Vision-Language-Action Policies in Long-Horizon Tasks](https://arxiv.org/abs/2608.30536)
- 事实：Behavior-Skill 把长时程 household mobile manipulation 拆成可独立评估的 constituent skills，包含 235,492 个 skill instances。
- 方法：每个 skill 有指令、观察-动作片段、可恢复中间状态和 skill success condition。
- 推断：价值在于把 aggregate task success 分解为技能级诊断；风险是 skill 边界和 restore state 是否过度依赖模拟器。
- 值得关注：适合评估 VLA 在长任务中到底失败在哪个技能。

### 16. [DREAM: Deployment-Time Demonstration Generation via Real-to-Sim for Scalable Policy Adaptation](https://arxiv.org/abs/2608.29078)
- 事实：DREAM 用 real-to-sim 在部署时生成新工作区的 VLA 微调 demonstrations，不需要任务级人工遥操作示范。
- 方法：重建 workspace，用大模型把语言指令转成 symbolic goals/success criteria，再在仿真中生成 fine-tuning 数据。
- 推断：对低成本 robot adaptation 很实用；风险是自动 success criteria 与真实任务的接触细节不一致。
- 值得关注：和数据匮乏场景下的 VLA manipulation adaptation 高度相关。

### 17. [AdaVLA: Adaptive Step Flow Matching for Training-free Acceleration of Vision-Language-Action Models](https://arxiv.org/abs/2608.29208)
- 事实：AdaVLA 针对 flow-matching VLA 的 ODE 求解过程，提出在线、training-free 的自适应步数加速。
- 方法：不依赖训练集或 fine-tuning，动态调整推理步，目标是降低 on-device robot control 延迟。
- 推断：这是工程上最容易接入已有 VLA 的加速类论文；风险是少步推理在接触敏感动作上产生不可见误差。
- 值得关注：低算力部署和实时闭环控制都需要这类接口。

### 18. [SMILE: Smooth Motion for Improved Long-Horizon VLA Execution](https://arxiv.org/abs/2608.29432)
- 事实：SMILE 只改变 VLA 的动作表示，用 B-spline coefficients 解码平滑 action sequences，提升长 horizon 执行。
- 方法：保持 backbone 和模型规模不变，在 SmolVLA、Evo1、VPP、DAWN 上测试 LIBERO、CALVIN 和真实实验。
- 推断：平滑表示可能降低 jitter/outlier；局限是过度平滑会压掉接触切换或快速纠错动作。
- 值得关注：这是低成本改善 action chunk 质量的强基线。

### 19. [DriftingVLA: Native One-Step Vision-Language-Action Generation via Per-Dimension Temporal Drifting](https://arxiv.org/abs/2608.29749)
- 事实：DriftingVLA 把 flow-based VLA 的多步 refinement 改为一轮 action-expert forward pass 生成完整 action chunk。
- 方法：用 distribution-drifting objective 学习 noise-to-action-chunk 的直接映射，并考虑各动作维度不同控制语义。
- 推断：核心收益是低延迟；风险是 one-step 生成可能牺牲多模态动作分布细节。
- 值得关注：适合和 AdaVLA 比较“少步 ODE”与“原生一步生成”的取舍。

### 20. [Temporal Forcing: 4D Representation Alignment for Vision-Language-Action Models](https://arxiv.org/abs/2608.30643)
- 事实：Temporal Forcing 针对 VLA 只对齐当前 3D 几何导致长时程和观测混淆的问题，引入 4D representation alignment。
- 方法：history pathway 汇总观测历史，latent representation 与时间感知的 4D target 对齐，在 LIBERO、RoboTwin 和真实 UR3 任务中测试。
- 推断：这是 VLA manipulation 中处理 hidden state/temporal aliasing 的清晰设计；风险是历史窗口和 4D target 生成成本。
- 值得关注：对“物体被遮挡后机器人是否记得已完成状态”很关键。

### 21. [PAVE: Predictive Alignment and Value-Guided Evolution for World-Action Policies](https://arxiv.org/abs/2608.30378)
- 事实：PAVE 把 direct world-action policy 与 outcome-agnostic predictive learning、outcome-aware policy improvement 结合。
- 方法：保留 fixed-offset JEPA 目标，并加入多时间尺度 transition alignment 与 trajectory-relative reweighting。
- 推断：优点是把动作策略表征和未来场景演化对齐；局限是多目标训练可能难以判定每个损失实际贡献。
- 值得关注：与 NFF/JEPA 式世界模型控制接口很接近。

### 22. [SUN: Persistent Programs For Language-Grounded Control-to-Learning-to-Real Policies](https://arxiv.org/abs/2608.31167)
- 事实：SUN Programs 把几何和接触关系写成 typed executable，再编译成 MPC costs、RL rewards、transition guards 和 diagnostics。
- 方法：Kuafu 由大视觉语言系统从语言和场景语义合成 SUN Programs，先用 MPC 筛可行性，再训练 stage-conditioned policies。
- 推断：亮点是语义、控制和学习共用一份规格；风险是自动合成程序的覆盖范围和错误恢复。
- 值得关注：适合思考 tool-use/VLA 如何进入真实控制栈。

### 23. [Bridging Semantics and Physics with Constrained LLMs for Safe and Trustworthy Robotic Manipulation](https://arxiv.org/abs/2608.29379)
- 事实：论文把语言级任务计划和物理可执行性之间的边界形式化为 typed contract，用 RGB-D 场景模型约束 LLM 决策。
- 方法：通过 schema-validated tool calls、碰撞/运动学约束和显式 scene model 检查机器人厨房操作计划。
- 推断：方法偏系统集成，但针对“LLM 计划看似合理却物理不可行”这一真实问题。
- 值得关注：可作为 safe robotic manipulation 中语义-物理约束接口参考。

### 24. [Autonomously Acquiring Robot Manipulation Skills with Language-Driven Quality-Diversity](https://arxiv.org/abs/2608.30983)
- 事实：论文用语言驱动 quality-diversity，让机器人自主生成多样 motion primitive archives。
- 方法：LLM 提供成功条件、fitness 和 diversity metrics，QD 算法产出可在部署时适配约束的技能库。
- 推断：比单一 reward shaping 更强调多样性；风险是 LLM 生成的评价维度可能不稳定。
- 值得关注：适合低成本探索“语言生成任务规格 + QD 技能发现”。

### 25. [Learning to infer and manipulate through distributed whole-arm interaction in a soft robot](https://arxiv.org/abs/2608.30773)
- 事实：论文研究软体机器人通过 distributed whole-arm interaction 同时推断物体信息并完成 manipulation。
- 方法：把大面积柔顺接触视为信息获取和动作组织的一体过程，而不是需要消除的扰动。
- 推断：机制上接近主动触觉/身体智能；局限是平台专用性强，难以直接迁移到多指手。
- 值得关注：对非视觉 object state inference 和 contact-rich manipulation 很有启发。

### 26. [Task-Relevant Feature-Dynamics Fidelity Enables Zero-Shot Sim-to-Real Transfer for Robotic Ultrasound Scanning](https://arxiv.org/abs/2608.29516)
- 事实：论文提出 task-relevant feature-dynamics fidelity（TR-FDF）解释 robotic ultrasound 的 zero-shot sim-to-real transfer。
- 方法：分析仿真观测随探头运动变化的任务相关特征是否匹配真实域，并据此设计 ultrasound simulator。
- 推断：虽然是医学机器人，但“任务相关动态一致性”概念可迁移到操控仿真；局限是 B-mode 图像域较专门。
- 值得关注：对 sim-to-real 的评价不要只看单帧视觉 realism，很有借鉴价值。

### 27. [RoboPhys-3D: A Comprehensive Embodied World Model Evaluation via 3D Reconstruction](https://arxiv.org/abs/2608.28718)
- 事实：RoboPhys-3D 用 RoboTwin 2.0 构建 3D-grounded embodied world model benchmark，覆盖 50 个 manipulation tasks、5,000 episodes 和 25,000 多视角视频。
- 方法：把生成视频和 GT 视频放进同一 3D reconstruction pipeline，区分 reconstruction-induced error 和 generation-induced error。
- 推断：这是评估 video/world model 是否保留 3D 状态的强基准；风险是重建 pipeline 自身偏差会影响评价结论。
- 值得关注：和 embodied world model、机器人可执行动作、3D 状态一致性直接相关。

### 28. [Matrix-Game 3.5: Enhancing Real-Time Streaming Interactive World Models with Patch Memory](https://arxiv.org/abs/2608.29910)
- 事实：Matrix-Game 3.5 面向实时流式交互世界模型，加入 geometry-aware memory、patch retrieval 和 tiled PRoPE。
- 方法：把历史图像 patch 提升到持久 3D memory，并按目标视角检索可见区域，同时做长期蒸馏以支持实时生成。
- 推断：更偏交互世界模拟而非机器人操控，但对 embodied agents/XR/robotics simulator 有潜在价值。
- 值得关注：可对比视频世界模型中“显式几何记忆”和“隐式 latent memory”的效果。

### 29. [Hydra: A Navigation World Action Model with Discrete Latent Planning and Continuous Flow-Matching Execution](https://arxiv.org/abs/2608.28995)
- 事实：Hydra 是 navigation world action model，把 sampler 和 evaluator 移到模型内部的离散 latent manifold。
- 方法：用 VQ bottlenecks 压缩 visual states、physical poses 和 control actions，避免 planner 每次都 decode 到像素空间。
- 推断：适合实时机器人导航；局限是离散 kinodynamic intents 对复杂接触操作未必足够。
- 值得关注：对 world model planning 的表示对齐问题给了清晰方案。

### 30. [AcrossWAM1.0:A Modular Latent World-Action Stack for Compact Robot Policies](https://arxiv.org/abs/2608.29937)
- 事实：AcrossWAM1.0 把 latent world-action stack 模块化，显式划分 policy adapter、latent world decoder 和 flow-matching action expert。
- 方法：不把 latent subgoal 当新算法，而是研究不同 backbone/模块边界和部署 checkpoint 的组合。
- 推断：价值在工程可替换性和消融清晰；局限是如果没有强开源实现，复现边界可能仍模糊。
- 值得关注：适合做 compact robot policies 的模块级对照。

### 31. [Does Latent Planning Survive Point Clouds? Action-Conditioned JEPA World Models for Geometric Observations](https://arxiv.org/abs/2608.29434)
- 事实：论文把 JEPA world models 从图像提升到 point clouds，测试 latent planning 是否能在稀疏无序几何观测下存活。
- 方法：比较 frozen-encoder、distribution-prior、action-sensitive 三类 JEPA 设计，并只改变观测形式来重感知 stable-worldmodel benchmark。
- 推断：和物理 rollout/latent bottleneck 关系密切；风险是点云中运动点比例很低时仍可能学到 slow-feature shortcut。
- 值得关注：对 3D world model 和几何观测下的动作条件预测很有用。

### 32. [Can Video World Models Track Unobserved World States?](https://arxiv.org/abs/2608.30692)
- 事实：论文用 action-conditioned video Shell Game 检验 video world model 是否跟踪不可见 hidden state。
- 方法：让渲染和隐藏状态分离，比较 Transformer、Mamba、linear attention 等架构在更长 swap chains 上的外推。
- 推断：结论指向“视觉保真不等于世界状态存在”；对机器人世界模型评估非常关键。
- 值得关注：适合作为 falsifying gate，检查模型到底记住状态还是只生成合理画面。

### 33. [Off-Manifold Refinement: Guiding Video Generators with a Frozen World Model](https://arxiv.org/abs/2608.29904)
- 事实：OMR 用 frozen world model 在视频生成采样过程中注入物理反馈，减少漂浮、接触消失和重力违规。
- 方法：在中间 ODE steps 中调整 generator velocity，而不是额外训练生成器或生成多个候选再筛选。
- 推断：低额外训练成本是优点；风险是 frozen world model 的物理偏差会被直接注入生成轨迹。
- 值得关注：对用世界模型指导视频/仿真生成的物理一致性有参考。

### 34. [CAER: Causal Action Effect Reweighting for World Model Training](https://arxiv.org/abs/2608.30897)
- 事实：CAER 针对 action-conditioned world model 的 uniform MSE 问题，把监督权重转移到受 action 因果影响的 tokens。
- 方法：在线比较有/无 action conditioning 的模型预测，定位 action-effect tokens 并归一化成训练权重。
- 推断：无需外部标注，适合低成本改造已有 world model loss；局限是 action-effect map 的自举误差可能早期放大。
- 值得关注：和交互动态、接触稀疏区域的 loss reweighting 高度相关。

### 35. [Lucida: Parse, Generate, and Place for Composable Real-to-Sim Scene Modeling](https://arxiv.org/abs/2608.30821)
- 事实：Lucida 把真实室内场景恢复为可编辑 object assets，并为机器人仿真/embodied AI 提供 simulation-ready replica。
- 方法：先解析多视角视频为 scene graph，再生成每个对象的完整 asset，最后用 GizmoAct 以 GUI 交互方式闭环放置对象。
- 推断：强在 object-centric real-to-sim；局限是对象资产真实性、遮挡恢复和物理属性仍需要额外验证。
- 值得关注：和 3D object-centric interaction、模拟环境自动构建密切相关。

### 36. [Agri-Sim: Agricultural Simulation Platform for Embodied Intelligence Evaluation in Greenhouse Robotics](https://arxiv.org/abs/2608.29100)
- 事实：Agri-Sim 是 Unity + ROS2 温室农业机器人仿真平台，包含移动双臂采摘机器人和多种虚拟传感器。
- 方法：Unity 负责渲染、刚体动力学、碰撞、虚拟感知和任务状态，ROS2/MoveIt 负责导航、规划、IK 和轨迹生成。
- 推断：应用场景专门，但把导航、感知和双臂 manipulation 串成闭环评价。
- 值得关注：适合看 embodied intelligence benchmark 如何落到真实任务链。

### 37. [LightNav-0: Eliciting VLM Spatial Intelligence for Generalist Embodied Navigation](https://arxiv.org/abs/2608.30935)
- 事实：LightNav-0 用 compact VLM backbone 统一 instruction following、object navigation 和 visual tracking。
- 方法：用 dual-channel pointing 表达空间意图，再通过 residual VQ action tokenizer 生成 embodiment-specific trajectories。
- 推断：它把 VLM spatial priors 显式导入导航控制；局限是导航空间点接口到复杂操控接触的延展性未证。
- 值得关注：对 embodied navigation 和 VLM spatial intelligence 很重要。

### 38. [CGFM-Nav: Cognitive Graph-Field Memory for Semantic-Guided Lifelong Multimodal Embodied Navigation](https://arxiv.org/abs/2608.29114)
- 事实：CGFM-Nav 提出 Cognitive Graph-Field Memory，把显式 multimodal scene graph 与连续 spatial field 结合用于 VLN。
- 方法：scene graph 支持目标检索和关系推理；找不到可靠目标时，连续场给探索方向。
- 推断：适合长时程导航 memory；局限是图构建错误会影响后续决策。
- 值得关注：和 object-centric embodied memory、空间探索策略相关。

### 39. [Scaffolding Foundation Models into Physical-World Agents Pushes the Frontier of Long-Horizon Navigation](https://arxiv.org/abs/2608.30396)
- 事实：NavMCP 把 VLM reasoning agent 和 navigation foundation model executor 组合成长时程 physical-world navigation agent。
- 方法：VLM 决定找什么证据、去哪里、何时停止；NFM 负责语义目标的闭环执行。
- 推断：这是 agent scaffolding 方向，偏导航而非操控；关键风险是高层推理和底层执行之间的信息损失。
- 值得关注：对“foundation models 如何拼成物理世界 agent”有系统启发。

### 40. [SeqAlign3DVG: A Sequence-Aligned Benchmark and Voxel Reasoning Framework for 3D Visual Grounding](https://arxiv.org/abs/2608.30451)
- 事实：SeqAlign3DVG 构建严格观察对齐、时间有序的 image-based 3D visual grounding benchmark。
- 方法：包含 9,622 个单视图样本和 14,493 个序列样本，并提出 voxel reasoning framework。
- 推断：主要是 3D grounding benchmark，离操控还有距离；但它补上 embodied agents 需要的时序视角对齐问题。
- 值得关注：适合评估 3D 语言 grounding 是否真的跟随观测序列。

## 今日最值得细读的 5 篇

1. [Motus2: A Self-Evolving General World Model for Dexterous Manipulation](https://arxiv.org/abs/2608.30237)：最强交叉：dexterous manipulation、world model、policy/value/simulator 闭环统一。
2. [AnyWorld: Factorized Egocentric World Models for Cross-Embodiment Generalization](https://arxiv.org/abs/2608.29242)：把人类 egocentric interaction 重组为机器人 rollout，直接连接 3D/HOI 到操控数据扩增。
3. [AGM: Achievement-Grounded Memory for Closed-Loop Agents with Frozen VLA Policies](https://arxiv.org/abs/2608.29537)：冻结 VLA 的轻量闭环记忆修补，适合低成本复现和 failure 分析。
4. [CometVLA: Co-Training on an Embodied Data Pyramid towards Physical Understanding](https://arxiv.org/abs/2608.30289)：把 embodied physical VQA 与 action generation 对齐，是 VLA 物理常识方向的代表。
5. [$\mathcal{N}_0$-Foundation: Towards the Age of Tactile Intelligence](https://arxiv.org/abs/2608.29601)：大规模视觉-触觉数据和表征体系，切中 dexterous/contact manipulation 的核心缺口。

## 10 篇低算力可改进论文

以下均为推断性研究建议，优先选择不需要重新训练大模型、可用小规模仿真/离线轨迹/轻量头验证的方向。

### 1. [Training-Free Action Correction for VLA Model Failures via Language Feedback](https://arxiv.org/abs/2608.29967)
- 可改进点：把语言纠正从统一 additive offset 扩展为“动作维度门控 + 失败类型门控”：先由轻量分类器判断是幅值、方向还是终止时机错误，再只改对应动作维度。
- 低算力可行原因：只需要冻结 VLA 的 rollout 日志和少量人工/规则 failure labels，不需要重新训练大模型。
- 小实验建议：在 LIBERO 选 3 个失败率高的任务，比较原 CorrectVLA、全维 offset、门控 offset；加入 action shuffle/zero correction 作为反控制。
- 预期收益与风险：预期收益是减少过修正；风险是 failure classifier 本身误判会引入新错误。

### 2. [AGM: Achievement-Grounded Memory for Closed-Loop Agents with Frozen VLA Policies](https://arxiv.org/abs/2608.29537)
- 可改进点：把 AGM 的 achievement verification 加入“负证据记忆”：不仅记录完成的 subgoal，也显式记录已尝试但未完成的动作和观测证据。
- 低算力可行原因：只训练/微调小验证头，甚至可先用规则状态和离线轨迹验证。
- 小实验建议：在 PickXTimes/BinFill 子集构造 failed-attempt replay，比较只推进成功记忆 vs 成功+失败记忆。
- 预期收益与风险：预期收益是减少重复失败动作；风险是负证据过强导致本可重试的子目标被跳过。

### 3. [AdaVLA: Adaptive Step Flow Matching for Training-free Acceleration of Vision-Language-Action Models](https://arxiv.org/abs/2608.29208)
- 可改进点：给 AdaVLA 的自适应步数加一个接触敏感阈值：接近目标、夹爪闭合、速度突变时提高 ODE steps，远离接触时降低 steps。
- 低算力可行原因：只改 inference scheduler，可用现成轨迹中的 proprio/action statistics 估计接触阶段。
- 小实验建议：在一个开源 flow-VLA 或简化 diffusion policy 上复现，统计延迟、成功率和接触阶段 action error。
- 预期收益与风险：预期收益是速度-精度更稳；风险是接触检测信号噪声导致步数抖动。

### 4. [SMILE: Smooth Motion for Improved Long-Horizon VLA Execution](https://arxiv.org/abs/2608.29432)
- 可改进点：在 SMILE 的 B-spline action 表示中加入“接触断点”piecewise spline，而不是全程单一平滑曲线。
- 低算力可行原因：只改动作解码头和损失，不需要更大模型；可用 LIBERO/CALVIN 轨迹自动检测夹爪/速度断点。
- 小实验建议：比较全局 B-spline、piecewise B-spline、原 action chunk 在开关抽屉/抓取放置任务上的成功率。
- 预期收益与风险：预期收益是保留平滑同时不过度抹平接触切换；风险是断点检测错误会造成轨迹不连续。

### 5. [SymVD: Symmetric Vision Language Action Distillation for Robot Manipulation](https://arxiv.org/abs/2608.29828)
- 可改进点：把 SymVD 的几何对称蒸馏改成“可学习对称置信度”：每类任务自动学习旋转/反射是否真的保持动作等价。
- 低算力可行原因：在小仿真任务上加一个标量权重或门控网络即可，teacher 和 student 不必重训到大规模。
- 小实验建议：构造对称严格成立和不成立的两组 tabletop tasks，比较固定 equivariance loss 与可学习权重。
- 预期收益与风险：预期收益是避免错误对称性伤害接触任务；风险是权重学成捷径，直接关闭有用约束。

### 6. [Temporal Forcing: 4D Representation Alignment for Vision-Language-Action Models](https://arxiv.org/abs/2608.30643)
- 可改进点：给 Temporal Forcing 加一个“历史必要性反事实测试”：训练时随机遮挡/打乱历史，评估 4D alignment 是否真的使用时间信息。
- 低算力可行原因：这是评估和小规模 ablation，不需要重训大模型；可在 100 条示范的 hidden-placement 任务上做。
- 小实验建议：比较正常历史、零历史、shuffle 历史、copy-current 历史四种设置下的阶段成功率和表示相似度。
- 预期收益与风险：预期收益是识别时间表征是否有效；风险是 benchmark 太小导致结论不稳。

### 7. [Proximity3D: Shape from Capacitive Proximity on Sensing Manifold](https://arxiv.org/abs/2608.30344)
- 可改进点：为 Proximity3D 加入“主动视角选择”小模块：根据当前重建不确定性选择下一次手掌/传感器扫描姿态。
- 低算力可行原因：可先在论文的仿真电容场上做，不需要真实硬件；策略可用贪心信息增益。
- 小实验建议：固定 3/5/8 次扫描预算，比较随机视角、均匀视角和不确定性视角选择的 Chamfer/F-score。
- 预期收益与风险：预期收益是少视角下更快补全形状；风险是仿真不确定性与真实电容噪声不一致。

### 8. [CAER: Causal Action Effect Reweighting for World Model Training](https://arxiv.org/abs/2608.30897)
- 可改进点：把 CAER 的 action-effect 权重加上“局部接触先验”：对手/工具附近区域设置弱先验，再由有/无 action 预测差异在线修正。
- 低算力可行原因：只改 loss weight map，可在小 action-conditioned video 数据或 RoboTwin 子集上训练。
- 小实验建议：比较 uniform MSE、CAER、contact-prior CAER，并加入静态背景高占比场景。
- 预期收益与风险：预期收益是更早关注稀疏交互动态；风险是接触先验错误会压低远距因果效应。

### 9. [Does Latent Planning Survive Point Clouds? Action-Conditioned JEPA World Models for Geometric Observations](https://arxiv.org/abs/2608.29434)
- 可改进点：在 point-cloud JEPA 中加入 matched open-loop controls：normal、zero-action、shuffle-action、constant-velocity latent extrapolation。
- 低算力可行原因：主要是评估协议和少量脚本，不需要增加训练规模。
- 小实验建议：复现一个小点云动力学任务，报告各控制的 rollout error 和规划成功率，而不只看 teacher-forced loss。
- 预期收益与风险：预期收益是判断 action-conditioned latent 是否真的携带物理信息；风险是点云采样噪声掩盖动作差异。

### 10. [CometVLA: Co-Training on an Embodied Data Pyramid towards Physical Understanding](https://arxiv.org/abs/2608.30289)
- 可改进点：把 CometVLA 的 GAP token 做信息瓶颈审计：限制 GAP 维度并做 task-agnostic motion probe，检查它是否编码通用运动而非任务标签。
- 低算力可行原因：只需要冻结模型特征或训练小 probe；可以先用公开子集/少量仿真轨迹。
- 小实验建议：比较不同 GAP 维度、随机 GAP、打乱任务标签下的物理 VQA 和动作成功率。
- 预期收益与风险：预期收益是澄清物理 commonsense 到 action 的真实通道；风险是缺少公开完整训练数据时只能做近似复现。
