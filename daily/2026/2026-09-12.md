## 逐篇要点

### 1. [Rapid Learning of Dexterous In-Hand Pen Writing through Real-Time Jacobian Estimation](https://arxiv.org/abs/2609.11775)
- 事实：面向 anthropomorphic hand 的 grasped-object in-hand manipulation，让机器人纯靠手内运动书写单笔画轨迹。
- 事实：方法在真实机器人上实时估计 hand-object system 的 task Jacobian，约 18 秒初始化后即可在线适应，不依赖解析接触模型、仿真训练或预收集 demonstration。
- 事实：作者报告在一个真实手和两个仿真手系统上有效，物理机器人实现平均 0.6 mm 的平面精度。
- 推断：这篇非常值得细读，因为它给出灵巧手低算力、低数据、在线控制路线，和大规模 RL/IL 路线形成清晰对照。
- 可能局限：任务主要是持笔单物体轨迹，复杂三维物体重定位、多接触切换和滑移恢复仍未覆盖。

### 2. [SEED-UMI: Sharing the Exoskeleton between human and robot for onE-to-one Dexterous demonstration](https://arxiv.org/abs/2609.11753)
- 事实：论文指出 dexterous hand imitation learning 的瓶颈是 contact-rich demonstration 难采集、human-to-robot retargeting 接触时退化。
- 事实：SEED-UMI 让人和机器人佩戴同一个外骨骼，外骨骼关节编码和腕部相机成为跨 embodiment 的共享测量。
- 事实：在五个 contact-rich tasks 上，作者报告比外骨骼 teleoperation 高 3.0x 数据效率，平均 rollout success 为 70.0%。
- 推断：这是今天最贴近“灵巧手数据采集协议”的论文，关键不是模型更大，而是把示教坐标系直接物理共享。
- 可能局限：外骨骼机械结构可能限制可示教动作空间，且 raw wrist images 对光照和外骨骼遮挡敏感。

### 3. [IMLE-VLA: Fast Single-Step Action Generation for Vision-Language-Action Policies](https://arxiv.org/abs/2609.10915)
- 事实：IMLE-VLA 用 conditional IMLE 的单步连续动作生成器替代 diffusion/flow matching action head 的多步采样。
- 事实：用于 `π0.5` 后，作者报告推理频率从 15 Hz 提升到 55 Hz，action throughput 最高 11x；LIBERO 平均成功率 98.0%。
- 事实：真实 Franka Panda 四任务中，方法产生更平滑轨迹，jerk 降低 2.2x 到 3.0x，episode inference time 降低 3.9x 到 6.6x。
- 推断：它是 VLA 部署层面的强工程改法，尤其适合真实机器人上“stop-and-go”动作问题。
- 可能局限：单步生成覆盖多模态的能力仍取决于 cIMLE 负样本/候选机制，接触丰富任务需要额外验证。

### 4. [UniMPA: A Unified Memory-Prediction-Action Model via Action-Grounded Transition Modeling](https://arxiv.org/abs/2609.11875)
- 事实：论文把 VLA manipulation 的问题定义为 transition realizability gap，包括 transition ambiguity、prediction-execution mismatch、experience-realization mismatch。
- 事实：UniMPA 使用 persistent-selective future prediction、temporal Visual-Action Memory Bank 和 Action-Visual Memory Bank，把未来预测与历史可执行经验连接起来。
- 推断：它试图把“看起来合理的未来帧”约束到“历史上可执行的视觉-动作转移”，是 VLA/WAM 方向中很关键的因果边界。
- 可能局限：memory bank 若只覆盖训练域经验，遇到新物体或新接触模式时可能把策略拉回错误的历史原型。

### 5. [Memory as Plans: World-Action Modeling with Memory-Grounded Planning](https://arxiv.org/abs/2609.11561)
- 事实：MaP-WAM 将非马尔可夫长时程任务拆成 memory-grounded planning 和 plan-conditioned execution。
- 事实：方法把 completed segment records 转成下一段语言计划和视觉 guidance，WAP model 同时预测 action chunks 与 execution progress。
- 事实：作者报告 RMBench 83.3% success，真实机器人任务 78.0% success，并保持 executor inference latency 基本不随历史长度增长。
- 推断：这是长时程 manipulation 中“记忆放在哪、怎么进入动作模型”的清楚设计。
- 可能局限：计划段划分和 progress calibration 若错误，会造成段切换漂移，尤其是在失败恢复场景。

### 6. [ActSafeGuard: Differentiable and Training-Aligned Constraint Enforcement for Flow-Matching Policies](https://arxiv.org/abs/2609.11697)
- 事实：面向 VLA/WAM flow-matching policies 的 hard physical constraint violation，论文提出训练对齐的可微 safeguard layer。
- 事实：ActSafeGuard 用 analytical ray-scaling operator 把 action feasibility 写入训练，而不是仅在 inference 时外部修正。
- 事实：作者报告在 `π0.5` 与 Fast-WAM 多任务上达到 100% step safety rate，同时保持或提升 task success。
- 推断：这篇适合作为 VLA 安全动作层 baseline，核心价值是解决训练-执行 mismatch。
- 可能局限：hard constraints 的定义如果只覆盖动作边界，不覆盖接触力、碰撞几何和任务语义安全，实际安全仍不完整。

### 7. [FARM: Reading Failure Signals from the Internal Predictive States of a Frozen Robotic World Model](https://arxiv.org/abs/2609.11445)
- 事实：FARM 训练一个 33,985 参数 readout，从 frozen VLA-JEPA predictive states 中读出 step-wise failure scores 与 causal trajectory risk。
- 事实：作者报告七个源任务 pooled AUROC/AUPRC 为 85.68/88.59，并在 PIPER X、SO-101、Franka 等真实机器人上测试固定 readout 迁移和 readout-only adaptation。
- 事实：额外延迟约 0.2256 ms CUDA latency，前提是 frozen predictive state 已可用。
- 推断：这是一篇低成本 robot monitoring 论文，重要点是“不训练世界模型，只读内部预测状态”。
- 可能局限：failure label 的边界与任务成功定义强相关，readout 可能学习到数据采集风格而非真正物理失败。

### 8. [2AM: Grounding Agent-Side Memory as Guidance for Steerable Action Models in Long-Horizon Manipulation](https://arxiv.org/abs/2609.11308)
- 事实：2AM 把 long-horizon task memory 放在 multimodal agent 侧，action model 保持 RGB-only、episodically stateless。
- 事实：Agent 输出 subtask language 和可选 2D grasp/place/move hints，demonstration 中加入 structured hint labels 并用 dropout/noise/jitter 训练 VLA 容错。
- 事实：在 LIBERO-Mem 上，2AM 达到 76.3% average completion，比最强已报 baseline 高 61.5 个点。
- 推断：它清楚检验了“更强记忆”是否必须进入动作模型内部，结论偏向 agent-side guidance。
- 可能局限：2D hints 不能表达深度、接触法向和遮挡后的三维几何，复杂装配任务可能受限。

### 9. [ReCHOIR: Contact-guided Human Object Interaction Retargeting to Diverse Characters](https://arxiv.org/abs/2609.10982)
- 事实：ReCHOIR 面向 human-object interaction motion retargeting，不只转移人体动作，还保持与物体的接触一致性和物体轨迹对齐。
- 事实：方法使用 Part-Aware Motion Embedding autoencoder，并把 object/contact signals 通过 body-part-aligned latent residual branch 注入 interaction-relevant body regions。
- 推断：这是 3D HOI 到动画/机器人动作迁移的重要中间层，尤其是把 contact cue 作为 retargeting 条件。
- 可能局限：角色 retargeting 不等于机器人可执行控制，关节力矩、碰撞和控制带宽需要后续物理验证。

### 10. [ObstaDiff: Generalizable Diffusion Policy Learning via Obstacle-aware Representations](https://arxiv.org/abs/2609.10918)
- 事实：ObstaDiff 针对 cluttered real-world scenes 中 diffusion policy 缺少 obstacle-aware motion generation 的问题。
- 事实：方法抽取 target-obstacle-background structured representation，让 downstream alignment policy 生成朝向 target-centered bottleneck pose 的 end-effector trajectory。
- 事实：作者在每方法 61 次真实温室机器人试验中报告 75.41% 平均成功率与 8.20% 平均 obstacle collision rate。
- 推断：它是农业/杂乱场景里很实用的 obstacle-conditioned imitation learning 路线。
- 可能局限：显式目标/障碍分解依赖视觉分割质量，对透明/反光/遮挡物体可能脆弱。

### 11. [LTLDiff: Finite Linear Temporal Logic-Guided Data Generation and Diffusion Policies for Multi-agent Robotic Manipulation](https://arxiv.org/abs/2609.11043)
- 事实：LTLDiff 将 LTLf specification learning 用于 demonstration generation 和 diffusion policy training。

## 10 篇低算力可改进论文

### 1. [Rapid Learning of Dexterous In-Hand Pen Writing through Real-Time Jacobian Estimation](https://arxiv.org/abs/2609.11775)
- 改进点 1：在 Jacobian estimator 中加入接触相位门控，把 free-slip、stick、edge contact 三类状态用轻量分类器区分；低算力原因是只需在现有轨迹日志上标注少量相位；小实验是在仿真 Allegro/Shadow 手中比较有无门控的轨迹误差；预期收益是减少接触切换时的估计漂移；风险是相位标签噪声会引入不稳定切换。
- 改进点 2：把目标轨迹从 2D 单笔画扩展为 piecewise impedance target，每段给定期望刚度/速度上限；低算力原因是控制层修改小，无需重训大模型；小实验是相同字母在纸面摩擦变化下比较成功率；预期收益是提升真实接触书写鲁棒性；风险是阻抗参数调节不当会损害精度。
- 改进点 3：增加 online rollback，当短时误差超过阈值时回退到最近稳定 Jacobian 并重新小幅扰动估计；低算力原因是纯控制逻辑；小实验是人为加入手指测量噪声和笔尖滑移，统计恢复时间；预期收益是减少灾难性漂移；风险是频繁 rollback 造成动作迟滞。

### 2. [SEED-UMI](https://arxiv.org/abs/2609.11753)
- 改进点 1：在共享外骨骼 wrist image 中加入外骨骼 mask/dropout augmentation，防止策略过拟合机构外观；低算力原因是数据增强即可；小实验是五个任务中改变外骨骼颜色/光照测试 rollout；预期收益是提升跨设备鲁棒性；风险是过强 mask 会破坏有用几何线索。
- 改进点 2：把 joint encoder 序列加入 temporal contrastive alignment，使 human demonstration 与 robot rollout 的同阶段片段更近；低算力原因是训练一个小投影头即可；小实验是用已有 paired trajectories 做 retrieval accuracy 和成功率 ablation；预期收益是降低 retargeting phase drift；风险是失败轨迹会污染对齐。
- 改进点 3：增加接触事件伪标签，例如外骨骼速度突变、关节力矩峰值、图像相对运动，作为辅助监督；低算力原因是不需触觉硬件；小实验是在 contact-rich tasks 上比较是否减少 early release/slip；预期收益是提高接触时策略稳定性；风险是伪标签和真实接触不完全一致。

### 3. [IMLE-VLA](https://arxiv.org/abs/2609.10915)
- 改进点 1：为 cIMLE action head 增加 contact-aware candidate reweighting，用夹爪闭合、末端速度突变等低维信号重排候选动作；低算力原因是只训练小型 scorer；小实验是在 LIBERO grasp/contact 子任务中比较 jerk、成功率和失败类型；预期收益是保留单步速度同时改善接触动作；风险是 scorer 过拟合 benchmark 信号。
- 改进点 2：加入 uncertainty-triggered fallback，只在 cIMLE 候选分歧大时调用少步 flow/diffusion refinement；低算力原因是大多数步仍单步推理；小实验是统计不同阈值下平均 Hz 与成功率曲线；预期收益是在难帧保质量、易帧保速度；风险是阈值设计不稳会造成动作频率抖动。
- 改进点 3：对单步动作加入频域平滑正则，惩罚不必要高频但放过接触事件；低算力原因是 loss-level 改动；小实验是 Franka 四任务或 LIBERO-plus 记录 jerk 与完成时间；预期收益是进一步减少 stop-and-go；风险是过度平滑会压掉快速纠偏。

### 4. [UniMPA](https://arxiv.org/abs/2609.11875)
- 改进点 1：为 Visual-Action Memory Bank 增加负检索，即显式检索历史失败 transition 并远离其 action prototype；低算力原因是 memory-level 改动；小实验是在有失败日志的 RoboCasa/LIBERO 子集做 ablation；预期收益是减少“历史可执行但当前错误”的动作套用；风险是失败定义不统一会误伤可行策略。
- 改进点 2：引入 transition realizability score 校准，用少量 held-out rollout 验证 predicted future 是否真的可由动作实现；低算力原因是只训练 readout；小实验是比较 visual prediction error 与 realizability score 对成功率的相关性；预期收益是避免只优化视觉相似未来；风险是 score 可能被数据分布偏差主导。
- 改进点 3：把 memory retrieval 限制为 object-centric slots，而不是整帧特征；低算力原因是可用现成检测/分割特征；小实验是在换背景、换干扰物场景测试成功率；预期收益是减少背景历史经验干扰；风险是 object detector 出错时召回下降。

### 5. [Memory as Plans](https://arxiv.org/abs/2609.11561)
- 改进点 1：增加 plan boundary verifier，用轻量视觉-语言分类器判断当前 plan segment 是否应结束；低算力原因是只需标注少量 segment boundary；小实验是 RMBench 中比较固定 progress 与 verifier-gated progress；预期收益是减少提前/滞后切段；风险是 verifier 延迟会影响实时性。
- 改进点 2：把 completed segment records 分成成功、恢复、失败三类 memory，planning 时优先检索相同失败恢复模式；低算力原因是 memory schema 改动；小实验是在插入扰动的 long-horizon tasks 上测恢复率；预期收益是增强闭环纠错；风险是数据中恢复样本不足。
- 改进点 3：对 visual guidance 做 sparsification，只保留变化最大的 object patch 或 contact region；低算力原因是推理 token 减少；小实验是比较 executor latency 和成功率；预期收益是更稳定的长历史延迟；风险是删掉隐含上下文导致误计划。

### 6. [ActSafeGuard](https://arxiv.org/abs/2609.11697)
- 改进点 1：把 ray-scaling feasibility 从 action bound 扩展到简化碰撞 signed-distance constraint；低算力原因是可用低分辨率 SDF 或几何 proxy；小实验是在 obstacle-rich LIBERO/RoboCasa 场景测 step safety 与成功率；预期收益是从动作安全走向几何安全；风险是 SDF 估计错误会过度保守。
- 改进点 2：加入 constraint violation curriculum，从宽松边界逐渐收紧到真实边界；低算力原因是训练调度改动；小实验是比较收敛速度和最终安全率；预期收益是减少早期训练梯度冲突；风险是课程设计不当导致模型依赖宽松分布。
- 改进点 3：为 safeguard 输出独立记录 correction magnitude，作为 failure/uncertainty 信号反馈给上层 planner；低算力原因是不训练额外模型；小实验是用 correction magnitude 预测 episode failure；预期收益是安全层兼做诊断层；风险是 correction 大不一定代表任务失败。

### 7. [FARM](https://arxiv.org/abs/2609.11445)
- 改进点 1：把 readout 从单步 failure score 扩展到 phase-conditioned score，不同操作阶段使用不同线性头；低算力原因是参数仍很小；小实验是用任务阶段标签或自动聚类阶段比较 AUROC；预期收益是降低跨阶段阈值不一致；风险是阶段划分错误会损害泛化。
- 改进点 2：加入 uncertainty calibration，报告风险分数的可靠性曲线而非只看 AUROC/AUPRC；低算力原因是 post-hoc calibration；小实验是在四个真实机器人 population 上做 temperature/isotonic calibration；预期收益是让风险阈值可部署；风险是校准集太小会不稳。
- 改进点 3：把 FARM 信号用于轻量 intervention policy，例如暂停、重试、慢速执行三选一；低算力原因是策略规则或小分类器即可；小实验是 replay 或小规模真实任务比较 intervention 后成功率；预期收益是从监控走向闭环恢复；风险是误报导致任务效率下降。

### 8. [2AM](https://arxiv.org/abs/2609.11308)
- 改进点 1：把 2D hints 扩展为 object-centric relation hints，例如 target-left-of、inside、contact-near；低算力原因是只改 hint schema 和标签生成；小实验是在 LIBERO-Mem 中比较只用 2D 点与关系 hint；预期收益是提升空间泛化；风险是语言关系解析误差会误导 action model。
- 改进点 2：加入 hint confidence，让 action model 学会忽略低可信 agent guidance；低算力原因是标签可由扰动强度或 agent self-consistency 产生；小实验是人为加入 hint noise 测成功率退化曲线；预期收益是增强上层 agent 错误容忍；风险是模型学会过度忽略 guidance。
- 改进点 3：将 agent-side memory 压缩成 episodic keyframes，而不是纯语言历史；低算力原因是只保留少量帧特征；小实验是比较语言-only、keyframe-only、混合 memory；预期收益是减少语言摘要丢失视觉证据；风险是 keyframe selection 不好会增加噪声。

### 9. [ReCHOIR](https://arxiv.org/abs/2609.10982)
- 改进点 1：把 contact cue 从二值接触扩展成接触稳定性分数，包含持续时间、相对滑移和法向一致性；低算力原因是从已有 motion/object trajectory 计算；小实验是在 HOI retargeting benchmark 上比较物体漂移和接触穿透；预期收益是减少短暂假接触；风险是无力学标注时稳定性只是近似。
- 改进点 2：增加 robot morphology adapter，把目标角色替换成简化机器人手/臂 kinematic tree；低算力原因是先用仿真 skeleton 不做真实控制；小实验是 retarget 到 Franka/Shadow hand URDF 的运动可达率；预期收益是更接近机器人执行；风险是缺少动力学会高估可执行性。
- 改进点 3：为 object motion decoder 加入物理一致性 penalty，例如速度平滑、非穿透和重力方向约束；低算力原因是几何损失即可；小实验是比较物体轨迹穿透率和接触保持率；预期收益是减少视觉合理但物理不合理的 HOI；风险是 penalty 过强会牺牲动作自然度。

### 10. [ObstaDiff](https://arxiv.org/abs/2609.10918)
- 改进点 1：把 target-obstacle-background representation 换成 uncertainty-aware segmentation，障碍边界不确定处提高避障 margin；低算力原因是只需从现有分割模型取置信度；小实验是温室场景加入遮挡和光照变化，比较 collision rate；预期收益是降低视觉边界错误带来的碰撞；风险是过大 margin 降低可达性。
- 改进点 2：加入 bottleneck pose 多候选采样，再用几何 clearance scorer 选最安全候选；低算力原因是 scorer 可为解析距离函数；小实验是窄通道/枝叶遮挡场景测成功率；预期收益是提高绕障路径多样性；风险是候选过多影响实时性。
- 改进点 3：对 diffusion policy 增加失败 replay buffer，把碰撞前若干步作为 hard negatives；低算力原因是真实/仿真失败样本少量即可；小实验是 50-100 条失败轨迹 fine-tune 后比较碰撞率；预期收益是快速修正常见障碍错误；风险是过拟合特定温室布局。
