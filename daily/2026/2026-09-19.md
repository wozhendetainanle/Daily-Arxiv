## 逐篇要点

### 1. [DexTouch-WM: Learning Action-Conditioned Tactile World Models from Human Touch for Dexterous Robot Manipulation](https://arxiv.org/abs/2609.20649)
- [事实] 面向 contact-rich dexterous manipulation，提出从 human touch 学习 action-conditioned visual-tactile world model。
- [事实] 通过共享触觉阵列布局和动作 retargeting，把人手触觉交互转成机器人可用的 dynamics supervision。
- [推断] 最值得关注的是“人类触觉数据 -> 机器人灵巧操作”的可扩展数据路径；风险在于触觉硬件布局和动作空间兼容性会限制跨平台迁移。

### 2. [TacSushi: Tactile-Grounded World-Action Modeling for Dexterous Sushi Manipulation](https://arxiv.org/abs/2609.19613)
- [事实] TacSushi 处理寿司这类变形、遮挡、接触不确定的 dexterous food manipulation。
- [事实] 方法把 RGB、语言、手状态与 fingertip tactile features 融合，并用 future observation / progress / contact-risk / tactile summary 做训练期 consequence supervision。
- [推断] 它把失败轨迹转成风险监督而非直接模仿，机制很有价值；局限是 340 成功 + 50 失败真实轨迹仍偏小，泛化到其他食材要谨慎。

### 3. [AnyViewDex: View-Invariant Dexterous Manipulation from RGB Observations](https://arxiv.org/abs/2609.20107)
- [事实] AnyViewDex 研究仅用 RGB 的 view-invariant multi-finger dexterous manipulation。
- [事实] 训练期用多视角对比学习和 privileged 3D object-coordinate regression 注入几何知识，部署时不需要 RGB-D 或点云。
- [推断] 对低成本灵巧手很实用，因为 test-time 传感要求低；风险是 sim 中学到的几何 grounding 能否承受真实遮挡和外观偏移。

### 4. [Towards High-DoF Dexterous Manipulation through VLA Post-Training](https://arxiv.org/abs/2609.19666)
- [事实] 论文面向高自由度 dexterous hand 的 VLA post-training，补齐开源 VLA 对高 DoF 手 action interface 的不足。
- [事实] 管线包含 temporal hand-action codec、SFT、DAgger 与 residual RL，并针对 human-gated takeover 的 gesture mismatch 做处理。
- [推断] 它直接命中 VLA × dexterous hand；风险是四阶段训练链条较长，收益需要和单独 codec/DAgger/RL 的消融绑定看。

### 5. [TouchSight: Bare-Handed Tactile Prediction from Egocentric Video via Generative Visual Augmentation](https://arxiv.org/abs/2609.20414)
- [事实] TouchSight 用 monocular egocentric video 预测 dense full-hand contact force，目标是降低触觉数据采集成本。
- [事实] 通过 pressure-glove 数据和生成式视觉增强构造 TwinTouch-20H，把 gloved recordings 重渲染成 bare-hand observations。
- [推断] 这是 3D HOI/hand-object/tactile 的好桥梁；风险是生成增强是否保留真实接触几何和压力分布。

### 6. [Agile-WAM: An Agile Tactile World Action Model for Contact-Rich Robot Control](https://arxiv.org/abs/2609.20761)
- [事实] Agile-WAM 研究 contact-rich robot control 中的 agile tactile World Action Model。
- [事实] 它把视觉和触觉编码到共享 latent，并用 flow-matching 生成 action chunks 与未来视觉/触觉 latent。
- [推断] 相比大型生成 backbone，它强调轻量和异步时标；风险是 latent 预测的物理一致性和真实接触闭环鲁棒性。

### 7. [FunArt: Decoding Functional Structure and Articulation from Generative 3D Latents](https://arxiv.org/abs/2609.20673)
- [事实] FunArt 从单个静态配置的 posed RGB-D observations 构建 articulation-aware functional 3D scene graphs。
- [事实] 它把 fused geometry 转成 TRELLIS.2 的 O-Voxel 表示，并用轻量 query decoder 联合分割 movable parts 与 functional interaction elements。
- [推断] 这篇贴近 functional affordance × articulated 3D understanding；局限是静态观测能否区分相似但功能不同的可动部件。

### 8. [V2-STRep: VLM-Grounded Structured Task Representations for Reusable Robot Skills Acquired from Generated Videos](https://arxiv.org/abs/2609.20582)
- [事实] V2-STRep 从生成视频和初始 RGB-D 观察中提取可复用机器人技能结构。
- [事实] 表示包含 motion phases、references、task constraints，以及点、轴、平面、6D pose 等 minimal geometric structures。
- [推断] 它把 generated video 的一次性运动转成可复用 skill graph；风险是 VLM 2D cues 到 3D 几何的 lift 若出错会系统性污染后续技能。

### 9. [WorldContact: A Contact-Centric World Model for Scalable Robot Learning](https://arxiv.org/abs/2609.19600)
- [事实] WorldContact 是 deformable-object manipulation 的 contact-centric world model，用有限高质量轨迹生成额外训练数据。
- [事实] 摘要报告在 shopping-bag manipulation 上相对源模拟器有 10x state-rollout 加速，并用于 fine-tune VLA policy。
- [推断] 价值在于把接触动力学生成和真实机器人策略连接起来；风险是生成 rollouts 的 contact bias 可能被 VLA 放大。

### 10. [SkipVLA: Skipping VLA Steps with Classical Planning for Fast Robot Manipulation](https://arxiv.org/abs/2609.20648)
- [事实] SkipVLA 用 classical motion planner 跳过 VLA 在自由空间运动中的慢速查询，仅在 grasp/place 等接触阶段调用 VLA。
- [事实] 它把 planner 的几何速度和 VLA 的语义/接触 skill 组合成 hybrid policy。
- [推断] 这是 test-time efficiency 很清楚的 VLA 操控改法；风险是阶段边界判断错误会导致 planner/VLA 接管错位。

### 11. [Compliance for Free: Learning Identifiable Impedance via Bilateral Teleoperation](https://arxiv.org/abs/2609.19976)
- [事实] 论文指出 VLA 给出“移动到哪里”，但 contact-rich tasks 还需要“推多硬”的 compliance。

### 12. [Execution-Aware Pre-Execution Ranking for Grasp-Conditioned Robotic Placement](https://arxiv.org/abs/2609.19946)

### 13. [GeoAAC: Geometry-Based Adaptive Action Chunking from Denoising Trajectories in VLA Policies](https://arxiv.org/abs/2609.20776)

- [推断] 这类过程级 uncertainty 很适合低延迟闭环；风险是 denoising geometry 与真实执行失败之间的相关性可能跨任务不稳。

### 14. [FlipToSee: A Probabilistic Stable Placement Prior for Active Visual Exploration via Regrasping](https://arxiv.org/abs/2609.20078)

### 15. [DITTO: Dexterous Interface for Transparent TeleOperation](https://arxiv.org/abs/2609.19196)

## 10 篇低算力可改进论文

以下建议均为推断性研究方案，不是论文作者已验证结论；目标是用冻结 backbone、小头训练、离线回放、小规模仿真或少量真实复现实验做低算力验证。

### 1. [DexTouch-WM: Learning Action-Conditioned Tactile World Models from Human Touch for Dexterous Robot Manipulation](https://arxiv.org/abs/2609.20649)
- 改进点 1：改法：在 visual-tactile world model 中加入 contact-event contrastive token，让 slip、jamming、stable hold 三类事件有显式分离；低算力实验：只在原模型 latent 上训练一个小投影头并做事件检索；收益是更容易诊断失败，风险是事件标签/启发式切分有噪声。
- 改进点 2：改法：增加跨人手/机器人手的 tactile layout dropout，随机屏蔽部分触觉 taxels 训练鲁棒表示；低算力实验：不重训 backbone，只 fine-tune tactile expert；收益是提升传感器缺失鲁棒性，风险是过强 dropout 降低接触细节。
- 改进点 3：改法：给未来触觉预测加不确定性头，用 high-uncertainty frame 触发更多真实采样；低算力实验：用 MC dropout 或小 ensemble 复现实验；收益是主动补数据，风险是 uncertainty calibration 不稳定。

### 2. [TacSushi: Tactile-Grounded World-Action Modeling for Dexterous Sushi Manipulation](https://arxiv.org/abs/2609.19613)
- 改进点 1：改法：把失败轨迹中的 contact-risk supervision 改成 pairwise ranking loss，让成功/失败相邻状态直接比较；低算力实验：冻结 backbone 训练 risk head；收益是失败边界更清楚，风险是相邻状态配对不准。
- 改进点 2：改法：加入材料属性 prompt 或小型 material token，区分米饭粘性、海苔弯曲和 topping 易碎性；低算力实验：用人工属性标签做 3 类消融；收益是提升 OOD 食材解释性，风险是属性标签粗糙。
- 改进点 3：改法：部署时用 contact-risk head 做 action-chunk veto，而非完全依赖 policy 输出；低算力实验：离线回放比较 veto 前后风险片段；收益是减少灾难性接触，风险是过度保守。

### 3. [Towards High-DoF Dexterous Manipulation through VLA Post-Training](https://arxiv.org/abs/2609.19666)
- 改进点 1：改法：在 hand-action codec 中加入关节协同稀疏正则，鼓励可解释 finger synergy；低算力实验：只重训 codec 并比较重构误差/策略成功率；收益是减小 action space，风险是限制精细动作。
- 改进点 2：改法：对 DAgger takeover 片段做 gesture-mismatch detector，过滤人类接管初始的非自然跳变；低算力实验：基于速度/jerk 阈值做离线过滤；收益是降低纠错轨迹污染，风险是删掉真正需要的快速纠正。
- 改进点 3：改法：residual RL 限制在接触阶段和低维 latent action 上；低算力实验：固定 VLA 与 codec，仅训练 residual adapter；收益是样本效率高，风险是阶段检测错误导致 residual 不生效。

### 4. [AnyViewDex: View-Invariant Dexterous Manipulation from RGB Observations](https://arxiv.org/abs/2609.20107)
- 改进点 1：改法：把 privileged 3D coordinate regression 扩展为 hand-object contact coordinate regression；低算力实验：在模拟中只额外监督 fingertip-near-surface 点；收益是增强接触感知，风险是接触标签依赖仿真质量。
- 改进点 2：改法：加入 test-time 多 crop/多视角一致性投票，不改变传感器硬件；低算力实验：对同一 RGB 做轻量视角扰动并比较 action variance；收益是降低偶然视角偏差，风险是增加延迟。
- 改进点 3：改法：训练中用 object-mask dropout 逼模型关注手-物关系而非背景；低算力实验：只改数据增强和 fine-tune 最后层；收益是提高真实背景泛化，风险是遮挡过强影响 grasp cue。

### 5. [TouchSight: Bare-Handed Tactile Prediction from Egocentric Video via Generative Visual Augmentation](https://arxiv.org/abs/2609.20414)
- 改进点 1：改法：对 gloved-to-bare 生成图加入 contact-boundary consistency loss，约束视觉增强不改变接触区域；低算力实验：用现有 pressure labels 训练边界辅助头；收益是减少生成伪影，风险是边界标签粗。
- 改进点 2：改法：把 dense force prediction 蒸馏成 object affordance/contact heatmap，服务机器人抓取；低算力实验：冻结视觉 backbone 训练 heatmap head；收益是更容易迁移到操作策略，风险是力到 affordance 的映射任务相关。
- 改进点 3：改法：加入不确定性屏蔽，让模型在遮挡严重手指区域输出低置信度；低算力实验：用遮挡增强做 calibration；收益是避免过信伪力，风险是可用监督减少。

### 6. [Agile-WAM: An Agile Tactile World Action Model for Contact-Rich Robot Control](https://arxiv.org/abs/2609.20761)
- 改进点 1：改法：根据触觉变化率自适应调整视觉/触觉 latent horizon，接触突变时缩短 chunk；低算力实验：在离线 rollout 上重排 horizon 策略；收益是提升接触闭环，风险是 horizon 频繁切换引入抖动。
- 改进点 2：改法：给 WAM 加一个小型 contact-consistency critic，判别未来触觉 latent 与动作是否物理一致；低算力实验：冻结 WAM 训练二分类 critic；收益是筛掉不合理 action chunk，风险是 critic 偏保守。
- 改进点 3：改法：把 fast tactile branch 做 int8/蒸馏以测试边缘部署；低算力实验：只量化 tactile encoder 并测延迟/成功率；收益是部署友好，风险是细微触觉信号被量化损失。

### 7. [FunArt: Decoding Functional Structure and Articulation from Generative 3D Latents](https://arxiv.org/abs/2609.20673)
- 改进点 1：改法：为 movable-part decoder 加功能先验 token，如 pull/push/rotate/support；低算力实验：用少量人工标注的交互词 fine-tune query head；收益是从几何 articulation 走向 affordance，风险是功能类别覆盖不足。
- 改进点 2：改法：输出 joint/confidence calibration，低置信度部件交给主动交互验证；低算力实验：用 held-out RGB-D 场景做 reliability diagram；收益是让机器人知道何时需要试探，风险是校准数据少。
- 改进点 3：改法：用单物体合成扰动做 part-consistency regularization；低算力实验：只对 TRELLIS latent 加小噪声训练 decoder；收益是提升静态观测鲁棒性，风险是扰动不符合真实扫描噪声。

### 8. [V2-STRep: VLM-Grounded Structured Task Representations for Reusable Robot Skills Acquired from Generated Videos](https://arxiv.org/abs/2609.20582)
- 改进点 1：改法：给 VLM 生成的 structured task representation 加 schema verifier，检查阶段、约束和几何引用是否闭合；低算力实验：对生成表示做静态规则检查；收益是减少不可执行 skill，风险是 verifier 规则过窄。
- 改进点 2：改法：同一任务生成多条视频，取共享约束而非单视频动作；低算力实验：3-5 个视频样本做 constraint voting；收益是过滤生成模型偶然动作，风险是生成成本上升。
- 改进点 3：改法：对 2D cue 到 3D primitive 的 lift 加置信度传播，低置信度 primitive 只作软约束；低算力实验：用 RGB-D 噪声扰动评估 primitive 稳定性；收益是减少几何误差硬约束，风险是控制目标变松。

### 9. [WorldContact: A Contact-Centric World Model for Scalable Robot Learning](https://arxiv.org/abs/2609.19600)
- 改进点 1：改法：把 world model 生成轨迹按 contact patch diversity 重采样，避免只生成常见接触模式；低算力实验：用几何接触近似统计多样性；收益是 fine-tune 数据更覆盖失败边界，风险是多样性指标与成功率不一致。
- 改进点 2：改法：在 VLA fine-tuning 前用小型 dynamics discriminator 过滤不可信 rollouts；低算力实验：训练二分类器区分真实/生成短片段；收益是减少模型偏差污染策略，风险是误删有用长尾。
- 改进点 3：改法：对 deformable object 状态预测加入 energy/penetration penalty；低算力实验：只在 rollout loss 中加轻量几何约束；收益是物理一致性更好，风险是约束近似粗。

### 10. [SkipVLA: Skipping VLA Steps with Classical Planning for Fast Robot Manipulation](https://arxiv.org/abs/2609.20648)
- 改进点 1：改法：训练 skill-boundary detector，判断何时从 planner 切到 VLA，而不是固定规则；低算力实验：用 VLA action entropy/视觉接触距离做弱标签；收益是减少接管错位，风险是边界误检。
- 改进点 2：改法：planner path 上加入 semantic keep-out zones，由 VLM 标注不可碰区域；低算力实验：只在现有场景中做代价地图改动；收益是安全性提升，风险是 VLM 语义区域过粗。
- 改进点 3：改法：为 skipped free-space segments 做 replay consistency check，确认 VLA 最终接触 pose 没被 planner 偏移破坏；低算力实验：离线比较 planner 终点与 VLA grasp pose；收益是提升长程成功率，风险是增加额外验证延迟。
