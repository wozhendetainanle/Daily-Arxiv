## 逐篇要点

### 1. [Robo-Harness K1: Harnessing Robot-Use Agents via Perception Augmentation](https://arxiv.org/abs/2609.29389)
- [事实] 核心问题：VLM/RUA 要从“看懂物体和空间”真正落到机器人动作，瓶颈在可查询的 3D 空间与抓取证据。
- [事实] 主要方法：Robo-Harness K1 把深度、视觉锚点、物体身份、抓取假设评估等作为工具暴露给 robot-use agent。
- [事实] 关键贡献：摘要报告在 LIBERO-PRO 和 RoboSuite/RoboTwin 任务中提升 Gemini/Astra 与小模型 RUA 的操作性能。
- [推断] 可能局限：需要警惕基线选择、试次数、工具调用成本和真实接触失败模式是否完全匹配。

## 10 篇低算力可改进论文

### 1. [DA-GRD: Decision-Aware Grasp-Relevant Disambiguation for tactile recovery under perception-to-execution mismatches](https://arxiv.org/abs/2609.29065)
- 可改进点：在触觉恢复中加入显式“任务价值”消融：比较只降定位误差、只降不确定性、只提升下一步成功率三种目标。
- 低算力可行原因：可用作者任务或简化 2D belief simulator，不必重训大模型。
- 小实验建议：复现一个遮挡抓取场景，注入可控 pose 偏移和 tactile hit/miss 噪声，比较恢复后的抓取成功率。
- 预期收益与风险：预期能证明 decision-aware 是否真的优于 perception-only；风险是触觉模型简化后差异变小。

### 2. [Simple Torque-Observation Alignment for Zero-Shot Sim-to-Real Grasping with a Direct-Drive Gripper](https://arxiv.org/abs/2609.29031)
- 可改进点：把 torque alignment 从线性标定扩展成温度/速度条件化的小模型。
- 低算力可行原因：只需采集短时空载和夹持电流数据，模型可以是线性回归或小 MLP。
- 小实验建议：在同一夹爪上做冷机/热机两组零样本抓取，比较固定 K_tau 与条件化 K_tau。
- 预期收益与风险：预期提升真实稳定性；风险是额外变量带来过拟合。

### 3. [PolyUMI: Accessible Visual-Tactile-Audio Data Collection for Object Inference and Manipulation](https://arxiv.org/abs/2609.29760)
- 可改进点：做跨模态缺失鲁棒性：训练时随机 drop tactile/audio/proprio token。
- 低算力可行原因：只改训练增强，不需要新硬件或大模型。
- 小实验建议：用 PolyUMI/VisTA 的同一任务，测试某个传感器失效时成功率和滑移检测 F1。
- 预期收益与风险：预期提升部署鲁棒性；风险是完整传感器条件下峰值略降。

### 4. [Direction-Scale Decomposition in Action Representation: Rethinking What to Tokenize for Vision-Language-Action Models](https://arxiv.org/abs/2609.28865)
- 可改进点：加入动作频率敏感性实验，检查 direction-scale tokenization 在不同 control Hz 下是否稳定。
- 低算力可行原因：只需离线重采样 action chunks，算力主要是小规模 fine-tune。
- 小实验建议：在 LIBERO 子集上比较 5/10/20Hz 和不同 chunk length 的成功率。
- 预期收益与风险：预期明确 tokenization 的适用边界；风险是数据重采样引入不可控平滑。

### 5. [KeyGen: Unsupervised Keypoint based Object-Centric Representations for Category-Level Policy Generalization](https://arxiv.org/abs/2609.28818)
- 可改进点：把无监督 keypoints 与接触/抓取候选区域做弱监督对齐。
- 低算力可行原因：可以用现成物体 mask、点云曲率或少量人工接触点，不必大规模标注。
- 小实验建议：在 10 类物体上比较原 KeyGen、曲率约束 KeyGen、少量接触点约束 KeyGen 的 policy transfer。
- 预期收益与风险：预期让 object-centric keypoints 更接近 functional affordance；风险是约束过强损失类别泛化。

### 6. [ActGaze: Learning Action-Grounded Gaze through Counterfactual Visual Interventions for High-Precision Manipulation](https://arxiv.org/abs/2609.28955)
- 可改进点：把 action-grounded gaze 的反事实干预从图像 patch 扩展到 3D object mask。
- 低算力可行原因：可用现成分割/深度估计生成 mask，训练成本低。
- 小实验建议：在高精度插入/抓取任务上遮挡非关键物体和关键接触区域，测动作变化。
- 预期收益与风险：预期得到更接近物理因果的注意力；风险是 mask 质量限制结论。

### 7. [A Simple Gripper Interface for Simulator-Agnostic Cloth Manipulation](https://arxiv.org/abs/2609.29340)
- 可改进点：加入真实布料视频的单步位置误差校准，不改主仿真器。

- 预期收益与风险：预期提升 simulator-agnostic 接口的现实性；风险是点跟踪噪声大。

### 8. [OCC4M: Object-Centric 4D Memory for Spatiotemporal Reasoning in Long-Horizon Manipulation](https://arxiv.org/abs/2609.28798)

- 预期收益与风险：预期区分“有用记忆”和“更多上下文”；风险是任务太简单时不敏感。

### 9. [ADM-Planner: LLM-Guided Long-Horizon Planning for Mobile Manipulators with Attention-Enhanced Dynamic Memory](https://arxiv.org/abs/2609.29212)
- 可改进点：把 ADM 的 object-centric memory 用规则 state graph 替代，检验 LLM 部分是否必要。

- 预期收益与风险：预期获得更便宜的 planning baseline；风险是规则图在开放场景泛化差。

### 10. [Streaming-WAM: Action-Conditioned World-Action Model for Asynchronous Robot Manipulation](https://arxiv.org/abs/2609.28927)
