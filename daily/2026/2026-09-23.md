## 逐篇要点

### 1. [DexTacWAM: A Visuo-Tactile World-Action Model for Dexterous Manipulation](https://arxiv.org/abs/2609.24976)
- [事实] 核心问题：这篇论文聚焦 灵巧手/手物交互；标题和摘要显示其目标是提升机器人在交互、接触或空间推理任务中的策略质量。
- [事实] 主要方法/贡献：方法重点是轻量适配或残差校正，适合观察冻结基础模型后 test-time/finetune 信号是否真正转化为动作收益。
- [推断] 为什么值得关注：值得关注，因为它直面多自由度手部动作空间、接触状态和人手到机器人手的迁移。
- [推断] 可能局限：可能局限是传感器形态、接触标定和采样频率不同会限制跨平台复用。

### 2. [AffordanceWAM: Affordance-Aware Joint World-Action Modeling for Robot Manipulation](https://arxiv.org/abs/2609.22332)
- [事实] 核心问题：这篇论文聚焦 affordance-guided manipulation；标题和摘要显示其目标是提升机器人在交互、接触或空间推理任务中的策略质量。
- [事实] 主要方法/贡献：方法把预测式世界状态与动作生成耦合，核心看点是未来状态建模是否改善闭环操控。
- [推断] 为什么值得关注：值得关注，因为它把“哪里可交互/怎么交互”显式接到机器人策略，是本订阅重点方向。

5. [Dexterous Robot Manipulation from Human Demonstrations via Contact-Anchored Retargeting and Residual Policy Learning](https://arxiv.org/abs/2609.24093)：用 contact-anchored retargeting 与 residual policy learning 处理人类示范到灵巧机器人操控，机制很贴近低算力改法。

## 我认为有明确改进点且不需要太多计算资源的 10 篇

### 1. [AffordanceWAM: Affordance-Aware Joint World-Action Modeling for Robot Manipulation](https://arxiv.org/abs/2609.22332)
- 可改进点：把 affordance heatmap 的监督从人工/强模型标注替换为 SAM2/视频一致性伪标签，再做置信度加权。
- 低算力可行原因：只需在公开 robot/human video 子集上离线生成伪标签，不必重训完整 WAM。
- 小实验建议：固定机器人数据量，对比无 affordance、原 affordance、置信度加权伪 affordance 三组。
- 预期收益与风险：若有效，可证明 affordance 接口的收益不依赖昂贵标注；风险是伪标签在遮挡交互区会偏。

### 2. [DexTacWAM: A Visuo-Tactile World-Action Model for Dexterous Manipulation](https://arxiv.org/abs/2609.24976)
- 可改进点：把 tactile compressor 做成可插拔 latent bottleneck，测试不同触觉通道缺失时的鲁棒性。
- 低算力可行原因：可冻结视频 VAE 和主干，只训练小型 compressor/adapter。
- 小实验建议：在 1-2 个接触任务上随机 drop fingertip tactile channels，比较成功率和接触预测误差。
- 预期收益与风险：收益是得到可部署的传感器缺失鲁棒性；风险是小任务不能代表复杂手内操作。

### 3. [Tactile-JEPA: Topology-Aware Self-Supervised Representation Learning for Distributed Tactile Sensors](https://arxiv.org/abs/2609.24385)
- 可改进点：在 Tactile-JEPA 上增加跨传感器线性 probe 和少样本 adapter，检验 topology-aware 表征是否真正迁移。
- 低算力可行原因：只需要冻结 encoder 后训练线性头或 LoRA，小显存可做。
- 小实验建议：选两类触觉阵列，source 训练、自 target 少量标定，测接触位置/力分类。
- 预期收益与风险：收益是把自监督表征和硬件迁移联系起来；风险是公开数据传感器差异不足。

### 4. [VT-Bridge: Bridging Pretrained Foundation VLAs to VTLAs via Lightweight Residual Adaptation](https://arxiv.org/abs/2609.22606)
- 可改进点：把 VTLA residual adapter 做成按接触阶段启用的门控 adapter，而不是全程统一残差。
- 低算力可行原因：只新增小门控网络，可用现有 VLA/VTLAs 特征离线训练。
- 小实验建议：按接触前/接触中/释放后三段分别启用 adapter，比较成功率和碰撞/滑移指标。
- 预期收益与风险：收益是更清楚地说明触觉何时帮助；风险是阶段边界标注可能噪声大。

### 5. [TACIT: Tactile Contact Supervision for Spatial Attention in Dexterous Manipulation](https://arxiv.org/abs/2609.24507)
- 可改进点：用视觉 point cloud 的接触候选伪标签替代部分真实 tactile supervision，测试 TACIT 是否能半监督扩展。
- 低算力可行原因：只需生成局部几何接触候选和训练 attention head，不必收集大量触觉。
- 小实验建议：在少量带触觉 demo + 多量无触觉 demo 设置下，比较 attention localization 和策略成功率。
- 预期收益与风险：收益是降低触觉采集门槛；风险是几何近接不等于真实力接触。

### 6. [MaskVLA: Visual Masking Against Trajectory Overfitting of Vision-Language-Action Model](https://arxiv.org/abs/2609.23565)
- 可改进点：对 MaskVLA 做任务相关的对象级 mask，而不是随机视觉 mask，验证防轨迹过拟合是否来自对象因果性。
- 低算力可行原因：可用现成检测/分割模型离线产 mask，训练开销小。
- 小实验建议：比较 random mask、object mask、background mask 在 LIBERO/小型真实视频上的泛化差异。
- 预期收益与风险：收益是把 robustness 和 causal object grounding 连接起来；风险是分割质量影响结论。

### 7. [StateMem: Single-State Residual Memory with Adaptive Inference for Vision-Language-Action Policies](https://arxiv.org/abs/2609.22684)
- 可改进点：把 StateMem 的残差记忆限制为单步可解释槽位，例如目标物、接触状态、阶段进度。
- 低算力可行原因：只改小型 memory head，冻结大部分 VLA。
- 小实验建议：在长程任务上比较自由 latent memory 和结构化槽位 memory 的失败恢复率。
- 预期收益与风险：收益是提升可解释性和调试性；风险是槽位设计过强会限制泛化。

### 8. [ForceRFT: Refining VLA Actions through Force-Guided Residual Reinforcement Learning](https://arxiv.org/abs/2609.22840)
- 可改进点：ForceRFT 可加入离线 force consistency reward，先用已有轨迹训练 reward model 再少量 RL。
- 低算力可行原因：reward model 小，且可先离线验证排序一致性。
- 小实验建议：构造成功/失败或滑移片段对，训练 force reward，观察 residual RL 是否减少真实交互步数。
- 预期收益与风险：收益是降低在线交互成本；风险是离线 force reward 可能诱导保守动作。

### 9. [Imagine then Verify: Affordance-Targeted Active Perception for Task-Oriented Grasping in Cluttered Scenes](https://arxiv.org/abs/2609.23504)
- 可改进点：把 active perception 的 imagine-then-verify 拆成只移动相机/只移动夹爪的低成本消融。
- 低算力可行原因：不需要完整策略重训，先用仿真或离线重放评估视角选择。
- 小实验建议：在 cluttered grasping 场景比较 view-only、gripper-only、joint active perception 三组。
- 预期收益与风险：收益是定位收益来自看得更好还是操作验证；风险是真机视角动作成本未计入。

### 10. [GraspTune: Tactile-Driven Execution Refinement for Robust Grasping](https://arxiv.org/abs/2609.24180)
- 可改进点：GraspTune 可测试“触觉触发的局部修正次数上限”，找出最小闭环预算。
- 低算力可行原因：只改执行时 refinement steps，不需要重训。
- 小实验建议：设置 0/1/2/4 次触觉修正，测成功率、耗时和过度挤压指标。
- 预期收益与风险：收益是直接给部署预算建议；风险是不同物体材料上的最佳次数不同。
