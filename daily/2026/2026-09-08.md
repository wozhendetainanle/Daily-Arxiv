## 逐篇要点

### 1. [RoboSPA: Can VLA Models Go Beyond Simple Scenes and Short-Horizon Tasks?](https://arxiv.org/abs/2609.05324)
- 事实：提出 RoboSPA，一个面向 VLA 的机器人空间-流程评测集，覆盖细粒度空间推理和长时程流程规划两个维度。
- 事实：任务包含 10 类、56 个基础任务、5 个难度层级，并收集 527K trajectories；摘要还强调超越二值成功率的诊断指标。
- 推断：它直接补齐 LIBERO 类短任务 benchmark 的复杂度盲区，是今天 VLA manipulation 最值得先读的评测论文。
- 可能局限：若模拟任务仍由模板生成，真实接触失败、遮挡和低层执行误差可能低于真实部署难度。

### 2. [LIBERO-RECOVER: Beyond Task Success Towards Failure Recovery in Robotic Manipulation Models](https://arxiv.org/abs/2609.05178)
- 事实：LIBERO-RECOVER 针对 manipulation policy 的失败恢复，而不是只看 task success；摘要指出现有 VLA/WAM 在 LIBERO 高成功率下仍不等于可部署。
- 事实：论文把模型置于发生偏差或失败后的状态，评估其能否诊断并恢复到可完成轨迹。
- 推断：这篇和 FailureSpot、ROBORMBench 构成今天“失败检测-恢复-评奖”主线，适合做严格 ablation。
- 可能局限：如果恢复状态仍来自 LIBERO 分布，真实机器人连锁失败和不可逆失败会更难。

### 3. [Temporal Tactile Encoding and Compliance for Intent-Aware Robot-to-Human Bimanual Handover](https://arxiv.org/abs/2609.05282)
- 事实：研究 robot-to-human handover 中接收意图识别与安全释放，明确把视觉、触觉、本体感知和 compliance 联合建模。
- 事实：摘要强调触觉时序编码能区分真实接收意图、偶然接触、弱抓握和方向错误的拉力。
- 推断：这篇是本期最接近 tactile + bimanual + human-object handover 的实机论文，优先级高于通用 agent 论文。
- 可能局限：handover 场景窄，触觉编码能否迁移到工具使用或手内操作还要另测。

### 4. [Towards Neuro-Symbolic Procedural Reasoning for Long-Horizon Vision-Language-Action Manipulation](https://arxiv.org/abs/2609.05369)
- 事实：提出神经符号程序推理框架，把 VLA controller 与 procedural state、依赖关系、条件分支和 symbolic monitor 结合。
- 事实：目标是解决短技能 VLA 在长时程流程中的状态记忆和可靠 grounding 问题。
- 推断：其价值在把“任务流程正确性”从语言规划落到 robot execution monitor；适合与 RoboSPA 长流程维度对照阅读。
- 可能局限：符号层若主要来自人工任务图，会限制开放任务泛化。

### 5. [FailureSpot: Label-Efficient Timestamp-Level Failure Detection for Vision-Language-Action Models](https://arxiv.org/abs/2609.04277)
- 事实：FailureSpot 做 VLA 执行过程中的 timestamp-level failure detection，并强调 label-efficient 设定。
- 事实：它面向长时程 manipulation 中不可预测失败，避免只在 episode 末尾给成功/失败标签。
- 推断：这能为 LIBERO-RECOVER 提供触发恢复的前置检测信号，也适合低算力复现。

- [RoboSPA: Can VLA Models Go Beyond Simple Scenes and Short-Horizon Tasks?](https://arxiv.org/abs/2609.05324)：VLA manipulation benchmark 从短任务升级到空间/流程复杂度诊断，是本期最直接的 embodied reasoning 评测。

- [TacPAC: Tactile Prediction and Real-Time Action Correction in World-Action Models for Contact-Rich Manipulation](https://arxiv.org/abs/2609.05266)：把触觉未来预测接入 real-time action correction，是 contact-rich manipulation 的关键方向。
- [Temporal Tactile Encoding and Compliance for Intent-Aware Robot-to-Human Bimanual Handover](https://arxiv.org/abs/2609.05282)：真实 robot-to-human handover 中触觉时序与 compliance 的结合，贴近人-物-机器人交互。
- [Morphology and actuation as inductive biases in robotic hand manipulation](https://arxiv.org/abs/2609.05206)：从 morphology/actuation 解释 robotic hand manipulation 的结构偏置，可防止把 dexterity 全归因于大模型。

## 10 篇低算力可改进论文

### [FailureSpot: Label-Efficient Timestamp-Level Failure Detection for Vision-Language-Action Models](https://arxiv.org/abs/2609.04277)
- 可改进点：把 timestamp failure detection 加入 contact/event boundary 标签，先用现成视频做弱监督。
- 低算力可行原因：只需冻结视觉编码器后训练轻量 temporal head 或 LoRA，不需要机器人采集。
- 小实验建议：在 FailBench/LIBERO 视频上比较整帧、ROI crop、optical-flow/token-delta 三种输入，评估提前量和误报。
- 预期收益与风险：收益是更早触发恢复；风险是视觉不可见接触仍漏检。

### [TacPAC: Tactile Prediction and Real-Time Action Correction in World-Action Models for Contact-Rich Manipulation](https://arxiv.org/abs/2609.05266)
- 可改进点：为 TacPAC 加一个显式 contact-state bottleneck，区分接触建立、滑移、释放和碰撞。
- 低算力可行原因：触觉序列短、模型头小，可在公开或作者数据上做离线监督。
- 小实验建议：固定 WAM backbone，只替换触觉预测头，比较 action correction 的接触相位一致性。
- 预期收益与风险：收益是解释性更强；风险是 contact taxonomy 标注不稳定。

### [Temporal Tactile Encoding and Compliance for Intent-Aware Robot-to-Human Bimanual Handover](https://arxiv.org/abs/2609.05282)
- 可改进点：做 tactile history length 与 compliance threshold 的系统消融，找出最小有效触觉窗口。
- 低算力可行原因：Handover 任务窄，序列模型可小规模训练，实验主要是离线重放。
- 小实验建议：以 0.1s/0.5s/1.0s/2.0s tactile window 训练同一 policy head，测释放时机和错误释放。
- 预期收益与风险：收益是给触觉时序建模定量边界；风险是不同传感器采样率导致结论漂移。

### [Morphology and actuation as inductive biases in robotic hand manipulation](https://arxiv.org/abs/2609.05206)
- 可改进点：把手形态特征转成标准 descriptor：DoF、underactuation、synergy rank、contact workspace。
- 低算力可行原因：不需要大模型，可用 URDF/kinematic model 和少量仿真轨迹计算。
- 小实验建议：在 Allegro/Shadow/LEAP 或简化手模型上跑同一 object reorientation task，回归 morphology descriptor 与控制难度。
- 预期收益与风险：收益是把“结构偏置”量化；风险是仿真接触模型影响排名。

### [LIBERO-RECOVER: Beyond Task Success Towards Failure Recovery in Robotic Manipulation Models](https://arxiv.org/abs/2609.05178)
- 可改进点：给 recovery benchmark 增加失败类型分层：目标错选、抓取滑移、碰撞、路径偏移、阶段漏执行。
- 低算力可行原因：可先用 LIBERO replay/video annotation 做小样本标签，不必重训 VLA。
- 小实验建议：训练一个轻量 failure-type classifier，再用规则 recovery prompt/policy 比较按类型恢复与统一恢复。
- 预期收益与风险：收益是恢复策略更可诊断；风险是类型边界模糊。

### [What Matters, When? Diagnosing and Improving Conditional Visual Grounding in Visuomotor Imitation Policies](https://arxiv.org/abs/2609.05376)
- 可改进点：加入反事实视觉 grounding：只替换 distractor、容器或目标属性，保持动作前缀相同。
- 低算力可行原因：基于现有 imitation 数据和渲染/遮挡增强即可，不必大规模采集。
- 小实验建议：对同一初始状态生成 A/B 目标条件，检查 attention/grad-CAM/动作差异是否只随目标条件变化。
- 预期收益与风险：收益是直接测 conditional grounding；风险是解释图不一定等价于因果使用。

### [Same Trajectory, Contradictory Rewards (ROBORMBENCH): Paraphrase Fragility in Vision Language Reward Models](https://arxiv.org/abs/2609.05401)
- 可改进点：在 reward model 前加目标描述 canonicalization 或 semantic-consistency voting，降低 paraphrase fragility。
- 低算力可行原因：只调用冻结 VLM/LLM 和现成轨迹视频，主要成本是推理。
- 小实验建议：把同义目标 paraphrase 聚类后投票评分，与原始 ROBORMBench 的 reward consistency 对比。
- 预期收益与风险：收益是提升 VLM reward 稳定性；风险是 canonicalization 可能抹掉真实任务差异。

### [MINT: A Unified Model for World-Space Camera and Hand Motion Estimation from Scalable Egocentric Pipeline Supervision](https://arxiv.org/abs/2609.04958)
- 可改进点：为 MINT 增加 object-relative hand motion probe，而不只评估 world-frame hand/camera motion。
- 低算力可行原因：可在现成 egocentric 视频上用冻结 object detector/segmenter 产生伪 object frame。
- 小实验建议：计算手轨迹相对目标物体中心/主轴的速度、距离和接近相位，与动作类别或接触事件弱标签对齐。
- 预期收益与风险：收益是更接近 hand-object interaction；风险是伪物体框误差会污染指标。

### [Where to Look Matters: Learning Influential Views for VLM-based 3D Visual Grounding](https://arxiv.org/abs/2609.04741)
- 可改进点：对 influential-view selector 做视角噪声和遮挡鲁棒性测试。
- 低算力可行原因：只需改输入视角集合和 scene graph/VLM 调用，不需要训练大模型。
- 小实验建议：随机删除 top-k 视角、加入遮挡视角或低分辨率视角，比较 3D grounding accuracy 和调用成本。
- 预期收益与风险：收益是知道主动视角选择是否稳；风险是 benchmark 视角分布单一。

### [CoSkill: Joint Reinforcement Learning of Reasoning and Meta-Skill Agents for Hierarchical Skill Evolution](https://arxiv.org/abs/2609.04865)
- 可改进点：把 CoSkill 的 skill evolution 用到一个小型机器人任务图模拟器，只验证 skill reuse 结构。
- 低算力可行原因：可以在文本/符号任务或 MiniGrid/PyBullet 小任务上运行，不需要真实机器人。
- 小实验建议：把 meta-skill agent 生成的技能映射到 pick/place/navigation primitives，比较平铺 skill library 与层次 skill library。
- 预期收益与风险：收益是评估层次技能是否能迁移到 embodied planning；风险是符号技能成功不代表物理可执行。
