## 逐篇要点

### 1. [GLoTouch: Global-to-Local Haptic Perception Using a Parallel Gripper for Object Search, Recognition, and Grasping Without External Vision](https://arxiv.org/abs/2609.27695)
- [事实] 核心问题：论文面向黑暗或低光环境中外部视觉失效时的目标搜索、识别与抓取。
- [事实] 主要方法：提出 GLoTouch，把容器尺度的触觉探索和物体尺度的局部几何感知连接到同一触觉流程中。
- [事实] 关键贡献：摘要强调其目标是让低自由度 parallel gripper 在无外部视觉下完成搜索、识别和抓取。
- [推断] 可能局限：目前最需要看触觉传感器、容器形态和物体材料变化下的泛化。
- [推断] 关注理由：这是今天最贴近“触觉 × 抓取 affordance × manipulation”的论文。

### 2. [InternW0: A Foundational Physical World Model for Efficient Real-World Interactions](https://arxiv.org/abs/2609.27656)
- [事实] 核心问题：论文认为物理世界模型不只要预测未来，还要在世界持续变化时保持可行动性。
- [事实] 主要方法：InternW0 使用 omnimodal interface、异步多频处理和 video-action flow matching，把未来视觉动态与连续控制联合起来。

## 10 篇低算力可改进论文

以下建议均为推断性研究想法，优先选择 Affordance、灵巧手/触觉、3D object-centric manipulation、VLA/WAM manipulation 相关论文；每条都尽量控制在小模型、子集复现、推理时改动或轻量 adapter 范围。

### 1. [GLoTouch: Global-to-Local Haptic Perception Using a Parallel Gripper for Object Search, Recognition, and Grasping Without External Vision](https://arxiv.org/abs/2609.27695)
- 改进点 1：把触觉探索策略改成不确定性驱动的 next-touch 选择，而非固定扫描。低算力原因：只需在已有触觉 embedding 上加一个小型 uncertainty head。小实验：在 20-30 个容器/物体组合上比较触摸次数、识别率和抓取成功率。预期收益：减少无效触摸并提高搜索效率；风险：不确定性校准差会导致过早 exploitation。
- 改进点 2：加入轻量 shape-prior retrieval：用少量 CAD/真实触觉轨迹建立最近邻先验，辅助局部几何补全。低算力原因：特征库可离线构建，不训练大模型。小实验：遮挡/低光设置下比较无先验、类别先验和实例近邻先验。预期收益：提升少触摸下的物体姿态估计；风险：先验错配会误导抓取。
- 改进点 3：做传感器噪声与接触材料扰动的鲁棒性复现实验。低算力原因：可在已有触觉序列上注入噪声/降采样。小实验：模拟不同采样率、摩擦和软硬材料，画成功率-噪声曲线。预期收益：明确部署边界；风险：模拟噪声未必等价于真实硬件漂移。

### 2. [DEAL-Grasp: Decoupled Alignment Representation for Geometry-Aware Dexterous Grasp Generation](https://arxiv.org/abs/2609.28131)
- 改进点 1：在 DEAL 表示中加入显式 contact-SDF penalty，让生成抓取同时满足几何锚点和接触可行性。低算力原因：只需现有 mesh/SDF 预处理和 loss 级改动。小实验：DexYCB/HO3D 子集上比较穿透率、接触覆盖和 grasp diversity。预期收益：减少视觉上合理但物理不可执行的抓取；风险：SDF 质量差会惩罚真实可行接触。
- 改进点 2：加入 object-part 条件的 retrieval prototype，使相似把手/边缘/凹槽共享 grasp anchor。低算力原因：原型可由冻结 3D/2D 特征聚类得到。小实验：跨类别 held-out objects 做 5-shot 原型补充。预期收益：提升少样本物体泛化；风险：部件语义错误会降低多样性。
- 改进点 3：把 evaluation 从姿态误差扩展到小规模物理仿真抓取稳定性。低算力原因：只需几十个生成样本在 Isaac/pybullet 里短 rollout。小实验：比较原方法、contact loss、prototype 条件三组的稳定抓取率。预期收益：让生成指标更接近机器人执行；风险：仿真摩擦参数会影响排序。

### 3. [LiMA: Bridging Long-term Imagination to Real-time Dexterous Manipulation via Asynchronous Diffusion](https://arxiv.org/abs/2609.28431)
- 改进点 1：把异步 fast executor 的触发条件改成 contact-change/event trigger，而不是固定频率更新。低算力原因：只改推理调度和小阈值模块。小实验：在已有任务回放中比较固定步长、视觉变化触发、触觉/力变化触发的延迟-成功率。预期收益：减少无效 diffusion 调用并提高接触反应；风险：事件漏检会造成动作滞后。
- 改进点 2：用 LoRA/adapter 对 long-horizon imagination 模块做任务条件轻量适配。低算力原因：冻结大部分 backbone，只训练小参数。小实验：选择 3 个新物体/任务，比较 full finetune、adapter、无适配。预期收益：降低新任务成本；风险：adapter 容量不足时只学到语义偏置。
- 改进点 3：加入显式 failure-prediction head 来判断 slow plan 是否需要重采样。低算力原因：可用 rollout 成败标签训练二分类器。小实验：在相同采样预算下比较无筛选、随机重采样、failure-aware 重采样。预期收益：提升实时系统的安全性和成功率；风险：分类器误报会增加延迟。

### 4. [CoPRE: Improving Sensitivity in Proprioceptive Contact Detection for Low-Cost Robot Arms](https://arxiv.org/abs/2609.27381)
- 改进点 1：将 CoPRE residual 从全局阈值改为动作相位条件阈值。低算力原因：只需按速度/关节相位拟合小校准表。小实验：弱接触、快速运动、慢速贴近三类轨迹分别统计 precision/recall。预期收益：减少高速运动中的误报；风险：相位划分过细会过拟合。
- 改进点 2：加入自监督负样本挖掘：把高置信 contact-free 片段用于持续更新 baseline。低算力原因：在线更新小模型或滑动统计即可。小实验：长时间运行后比较温漂前后检测灵敏度。预期收益：提升低成本手臂长期部署稳定性；风险：若误把接触片段纳入负样本会污染模型。
- 改进点 3：做跨机械臂迁移的少量校准实验。低算力原因：每个平台只需数分钟 contact-free 数据。小实验：Duke/KTH/低价机械臂三平台上测零样本和 5 分钟校准。预期收益：证明方法不是单平台调参；风险：控制器日志字段不一致会影响实现。

### 5. [Generalizable Robotic Insertion with World Models](https://arxiv.org/abs/2609.28258)
- 改进点 1：给 world model 增加 occlusion-aware belief state，而不是只用当前 wrist RGB-D。低算力原因：belief 可由小型 recurrent latent 或 particle memory 维护。小实验：选择大 socket/遮挡失败案例，比较单帧、短历史、belief 三种输入。预期收益：改善作者提到的遮挡弱点；风险：历史融合可能累积错误位姿。
- 改进点 2：把插入任务按几何难度分层采样，训练时提高薄孔/大孔等失败类型权重。低算力原因：只改数据 sampler 和少量 finetune。小实验：用 10-20 个 held-out assemblies 做 reweighting ablation。预期收益：提升少数困难几何而不扩大数据集；风险：可能牺牲平均任务表现。
- 改进点 3：加入接触事件预测作为 auxiliary loss。低算力原因：可从仿真接触日志或力阈值自动生成标签。小实验：比较有无 contact auxiliary 的 zero-shot insertion 成功率和卡滞次数。预期收益：让视觉 world model 更懂接触阶段；风险：仿真接触标签迁移到真实会有偏差。

### 6. [AWM-VLA: AlignedWorld Modeling for Efficient and Explainable Vision-Language-Action Policies](https://arxiv.org/abs/2609.27753)
- 改进点 1：把 future tokens 与 object-centric slots 对齐，而不是只对齐全局 vision-language embedding。低算力原因：可接现成 SAM/OV segmentation 产生 slots。小实验：同一 VLA 在遮挡和多物体干扰场景中比较全局对齐与 slot 对齐。预期收益：提升可解释性和动作相关性；风险：slot 分割错会引入噪声。
- 改进点 2：加入 counterfactual future-token dropout，测试策略是否真的依赖未来建模。低算力原因：只需推理时 mask/替换 token。小实验：对成功轨迹替换目标物体 future token，观察动作偏移和成功率。预期收益：把“解释性”变成因果证据；风险：token 干预可能落到训练分布外。
- 改进点 3：用短 horizon 几何指标替代像素重建指标做筛选。低算力原因：只需少量 RGB-D 或点云误差计算。小实验：比较像素相似、slot 几何误差、动作成功三者相关性。预期收益：减少任务无关视觉细节；风险：几何指标可能忽略语义约束。

### 7. [VLMs Can Describe, But Not Measure: Object-Centric Scene Understanding for Robotic Manipulation](https://arxiv.org/abs/2609.28184)
- 改进点 1：把 object-centric 表示扩展为 action-centric affordance fields，为每个物体区域预测可抓、可推、可插入等标签。低算力原因：可用少量人工/LLM 辅助标签和冻结 VLM 特征训练线性头。小实验：151 个 tabletop scenes 中抽 30 个做 affordance 标注，测定位与动作建议一致性。预期收益：从“能描述/测量”走向“能操作”；风险：affordance 标签主观性较强。
- 改进点 2：加入 metric calibration prompt bank，比较 VLM 直接估计与 RGB-D grounded 数值的误差。低算力原因：只需提示模板和已有深度。小实验：对尺寸、距离、相对位置三类问题做 prompt ensemble。预期收益：明确 VLM 几何弱点来自提示还是表示；风险：prompt bank 可能过拟合场景语言。
- 改进点 3：把 planner 接口改成 object-relation graph，显式记录接触前置条件。低算力原因：图结构由现有 object-centric 输出构建。小实验：pick-place/stacking 小任务中比较 flat object list 和 relation graph。预期收益：减少语义正确但几何不可行的计划；风险：关系抽取错误会放大到规划失败。

### 8. [PointCast: One World Model for Rigid, Articulated, and Deformable Object Manipulation](https://arxiv.org/abs/2609.28393)
- 改进点 1：在 PointCast 点状态中加入 contact/near-contact binary token。低算力原因：标签可由点距 end-effector 阈值自动生成。小实验：cloth、rope、cabinet 三类比较有无 contact token 的 rollout error。预期收益：更好建模操控中局部因果点；风险：阈值标签粗糙会误导模型。
- 改进点 2：做 single-checkpoint 多 regime adapter，而非每个 regime 单独 checkpoint。低算力原因：冻结主干，只训练 regime adapter 或 prompt。小实验：rigid/cloth/rope/cabinet 各取小子集训练共享模型。预期收益：验证是否存在通用 object manipulation dynamics；风险：共享模型可能负迁移。
- 改进点 3：把 MPC 采样目标加入 task-level affordance cost，例如抓取点、开合方向或可变形目标区域。低算力原因：不改模型，只改 planning cost。小实验：cabinet opening 或 rope shaping 上比较点误差 cost 与 affordance cost。预期收益：让 world model 更服务任务完成；风险：affordance cost 需要额外标注或规则。

### 9. [TANDEM: Task and Motion Planning with As-Needed Demonstrations for Efficient Vision-Language-Action Model Fine-tuning](https://arxiv.org/abs/2609.28314)
- 改进点 1：把“何时请求演示”改为 uncertainty + plan-precondition violation 的双触发。低算力原因：基于 planner failure 和 VLM confidence 即可实现。小实验：同一长时程任务比较固定人工介入、uncertainty 介入、双触发介入的人类步数和成功率。预期收益：减少不必要演示；风险：过于保守会频繁请求人类。
- 改进点 2：将人工演示切成 reusable skill patches，并自动回填 TAMP domain。低算力原因：只需对少量演示做 pre/post-condition 归纳。小实验：三个相似长任务中测试一次演示能否复用到新任务。预期收益：提高数据复用率；风险：归纳出的前置条件过宽会误用技能。
- 改进点 3：加入失败回放的 negative demonstrations，告诉 VLA 哪些 planner extension 不该用。低算力原因：利用已有失败日志，无需新机器人数据。小实验：比较只用成功演示和成功+失败对比训练。预期收益：降低长时程 cascading failure；风险：失败标签不精确会抑制探索。

### 10. [Pro-Bench: Prompt-Robust Open-Vocabulary Visual Grounding Across Real-World Heterogeneous Environments](https://arxiv.org/abs/2609.27076)
- 改进点 1：把 benchmark 中的 affordance queries 单独拆成子榜，并增加 object-state 条件如 open/closed、empty/full。低算力原因：只需重标一小部分查询和统计切片。小实验：比较 16 个模型在 category、relation、affordance、state 四类 prompt 上的鲁棒性。预期收益：让 robot grounding 评测更贴近操作需求；风险：affordance 定义不统一。
- 改进点 2：加入 prompt-invariance regularizer：同一目标的多种表述应定位到同一实例。低算力原因：可在冻结模型输出上做轻量 reranking 或小 adapter。小实验：对已有 515 查询生成 paraphrase，测 target recovery consistency。预期收益：降低机器人听不同说法时的定位漂移；风险：paraphrase 可能改变真实语义。
- 改进点 3：把定位输出接到一个简单 pick/reach feasibility checker，形成 grounding-to-action 指标。低算力原因：用几何启发式和深度图即可。小实验：统计 IoU 相同但可达性不同的样本，比较 mAP 与 action-feasible accuracy。预期收益：更接近 affordance-guided manipulation；风险：feasibility checker 本身可能偏置。
