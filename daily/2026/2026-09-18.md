## 逐篇要点

### 1. [OpenDexGrasp: Open-vocabulary Task-Oriented Dexterous Grasping](https://arxiv.org/abs/2609.18117)
- [事实] 研究 open-vocabulary task-oriented dexterous grasping：机器人需从自由语言、多视角视觉和物体几何推断功能意图，并生成高自由度灵巧手抓取。
- [事实] OpenDexVerse 用 C2A Recipe 组合大规模自动合成/视觉语言标注与人工遥操作对齐数据；模型把 affordance grounding 与 grasp generation 放进共享 latent。
- [推断] 这是今天最贴近“affordance × dexterous grasp”的论文；风险是开放词汇功能意图是否能稳定落到真实接触区域，还要看未见物体和真实机器人细节。

### 2. [TacBPM: A Tactile-conditioned Behavior Prior Model for Dexterous Reorientation](https://arxiv.org/abs/2609.18174)
- [事实] TacBPM 面向 dexterous in-hand reorientation，把触觉-本体历史蒸馏成 fixed behavior prior，再让下游策略用 residual latent actions 复用。
- [事实] 摘要强调跨各向异性物体、任意姿态迁移、轴向旋转和 arm-hand Grasp-to-AnyPose 任务。
- [推断] 价值在于把“探索 finger gait”变成可复用触觉行为先验；局限是触觉传感/仿真接触模型若偏差大，prior 可能把错误接触习惯固化。

### 3. [Track, Articulate, Act: Generating Articulation from Casual Human Videos](https://arxiv.org/abs/2609.19119)
- [事实] 从 casual monocular human video 重建 simulation-ready articulated object 与 hand-object interaction，不需要 RGB-D、多视角、先验扫描或机器人演示。
- [事实] 核心信号是 dense 3D point tracks：固定 link 近似静止，可动 link 沿关节运动，由此推断 articulation 并转成 robot manipulation 线索。
- [推断] 它把 3D HOI/人类视频直接连到可执行 articulation，是今天最值得细读的 real-to-sim 方向；风险是遮挡、相机运动和非刚体接触会污染关节估计。

### 4. [InterMASH: A Unified Geometric Representation for Grasp Synthesis](https://arxiv.org/abs/2609.18504)
- [事实] InterMASH 提出跨人手与机器人手的统一几何 interaction token：sphere-fixed anchors 上用低阶 spherical harmonics 编码手几何、物体几何和接触。
- [事实] 方法强调 cross-embodiment correspondence，并在此 token 结构上做条件生成。
- [推断] 对 hand-object representation 很有参考价值；风险是 anchors/球谐表示是否足够表达细粒度 fingertip contact 和不同机器人手形态。

### 5. [ForceDelta-VLA: Distilling Force-Conditioned ActionCorrections for Contact-Rich Manipulation](https://arxiv.org/abs/2609.18242)
- [事实] ForceDelta-VLA 从 frozen teacher 的 force-conditioned 与 force-agnostic 模式构造显式 force-correction target，训练轻量策略修正 reference actions。
- [事实] 它还考虑 asynchronous schedule replay 和 delay-correction target，让近期力历史和机器人状态参与闭环。
- [推断] 这是 contact-rich VLA 的实用分解：把“任务动作”和“接触修正”拆开；风险是 teacher 两种模式的差分未必总对应真实可复用 force correction。

### 6. [TAO-Force: Unifying Force-Aware Perception and Fast-Slow Control for Contact-Rich Manipulation](https://arxiv.org/abs/2609.18497)
- [事实] TAO-Force 把力反馈注入 frozen VLA backbone 表征，并结合 contact-regulated fast-slow control 解决视觉中心策略在接触任务中的迟钝。
- [事实] Force-conditioned FiLM 负责感知层面的力条件化，执行端则用力调节控制补足位置控制。
- [推断] 它和 ForceDelta-VLA 形成互补：一个显式蒸馏修正，一个在 backbone 与控制层注入力；风险是传感延迟和 force scaling 对泛化影响很大。

### 7. [Acting in Meters: Learning Metric Interactions for Precise Robotic Manipulation](https://arxiv.org/abs/2609.18243)
- [事实] Acting in Meters 显式建模 actions、objects 与 scene geometry 的 metric relations，用 Interaction-Centric Tokens 和 Metric Action Interaction Field 监督动作。
- [事实] 它把 VLA/WAM 常隐式处理的笛卡尔空间关系放到共享 metric scale 中。
- [推断] 对机器人操控很关键，因为很多失败不是语义错，而是距离/方向/尺度错；局限是 point-cloud metric supervision 的数据成本和噪声。

### 8. [${M}^2$Tok: Multi-head Multi-codebook Discrete Action Tokenization for Vision-Language-Action Models](https://arxiv.org/abs/2609.18259)

- [事实] 结构上把 latent action features 分到多个 heads/codebooks，以保留细粒度控制动态。
- [推断] 适合关注 action-token VLA 的读者；风险是 tokenizer 重构好不等于闭环成功，仍需 task-level 对照。

### 9. [ActionPiece: Rethinking Action Tokenization for Autoregressive Vision-Language-Action Models](https://arxiv.org/abs/2609.18487)

- [事实] 它从 decoded actions 的公共参考系比较不同 token vocab/decoder。
- [推断] 这篇的贡献更像评估契约：能帮 VLA 领域少走“低 MSE 高失败率”的弯路；风险是 PRC 与真实机器人闭环收益还需更多任务验证。

### 10. [From Gameplay to Policy: Towards Scalable Robot Data Collection via Gamified Robot-Free Interaction](https://arxiv.org/abs/2609.18650)

- [事实] 平台强调与具体机器人硬件解耦，目标是扩大多样化、目标导向的操控经验。
- [推断] 它和 UMI/人类视频路线互补，适合低成本数据扩展；风险是游戏化交互的动作分布和真实接触动力学仍有偏差。

### 11. [PointZero: 3D Point Track Completion for Learning Transferable 3D Dynamics](https://arxiv.org/abs/2609.19142)

- [推断] 对 WAM/3D dynamics 很重要，因为它把 web/human video 纳入无需动作标签的 dynamics prior；风险是 synthetic tracks 到真实 RGB-D 的 domain gap。

### 12. [Function-Preserving Data Generation for Zero-Shot Real-to-Sim-to-Real Manipulation](https://arxiv.org/abs/2609.18293)

### 16. [LUMO: Designing Luminous Contact Morphology for Repeatable Whole-Finger Contact Observation](https://arxiv.org/abs/2609.18165)

### 17. [CANTABILE: Learning Expressive Dynamics for Robotic Piano Performance](https://arxiv.org/abs/2609.18213)

## 10 篇低算力可改进论文

以下均为推断性建议，优先选择不需要大规模预训练、不依赖昂贵真实机器人长时间采集的改法。每篇给 3 个方法级改进点。

### 1. [OpenDexGrasp: Open-vocabulary Task-Oriented Dexterous Grasping](https://arxiv.org/abs/2609.18117)
- 改进点 1：改法：把 affordance grounding 分成“功能区域候选”和“抓取姿态可行性”两个头，并在 latent 中加 mutual-consistency loss。低算力：只需冻结主干、训练小头。小实验：在 OpenDex-Align 子集上比较直接生成 vs 两头一致性。预期收益：降低语言功能正确但接触点错误的失败。风险：候选区域标签噪声会限制收益。
- 改进点 2：改法：增加 negative task prompts，例如“不要抓把手/不要遮挡开口”，训练模型显式区分功能 affordance 与反 affordance。低算力：可用现有标注自动改写 prompt。小实验：构造 50 个正负 prompt pair，看抓取区域是否翻转。预期收益：增强开放词汇语义边界。风险：负 prompt 太模板化会被模型记忆。
- 改进点 3：改法：做少样本 object-specific residual pose correction，仅微调 grasp decoder 末层。低算力：每类 5-10 条仿真/真实失败轨迹即可。小实验：未见杯/工具类别 5-shot adaptation。预期收益：提升真实执行成功率。风险：小样本 residual 可能牺牲通用性。

### 2. [TacBPM: A Tactile-conditioned Behavior Prior Model for Dexterous Reorientation](https://arxiv.org/abs/2609.18174)
- 改进点 1：改法：给 tactile behavior prior 加不确定性估计，policy 在高不确定 tactile state 下退回更保守 residual。低算力：MC dropout 或小 ensemble 即可。小实验：遮挡/错误触觉注入下比较物体掉落率。预期收益：避免错误 prior 导致激进 finger gait。风险：过度保守会降低重定向速度。
- 改进点 2：改法：把 latent prior 拆成 grasp-stabilize、roll、release 三个阶段 token，而不是单一 latent。低算力：用接触/角速度阈值自动伪标阶段。小实验：阶段 token vs 全局 token 的 anisotropic object transfer。预期收益：减少阶段切换混乱。风险：伪阶段边界噪声。
- 改进点 3：改法：增加触觉缺失训练，让 prior 在部分 fingertip sensor dropout 下保持可用。低算力：离线 mask 数据增强。小实验：1/2 个 fingertip dropout 的成功率曲线。预期收益：提高真实硬件鲁棒性。风险：mask 过强会降低正常触觉利用。

### 3. [Track, Articulate, Act: Generating Articulation from Casual Human Videos](https://arxiv.org/abs/2609.19119)
- 改进点 1：改法：给 articulated joint inference 加 camera-motion hard negative，显式惩罚把全局相机运动误判为 object articulation。低算力：对原视频做稳定/随机裁剪合成。小实验：门/抽屉视频上比较关节轴误差。预期收益：提升 casual monocular 稳定性。风险：真实 ego-motion 也可能被压掉。
- 改进点 2：改法：在 real-to-sim 输出前加 articulation confidence map，只把高置信 link/joint 交给机器人策略。低算力：从 point-track residual 和遮挡率计算即可。小实验：低置信区域剔除前后仿真交互成功率。预期收益：减少错误结构污染下游。风险：剔除过多导致可操作信息不足。
- 改进点 3：改法：把 hand-object contact event 作为独立监督信号，约束 articulation change 必须与接触时序一致。低算力：用手轨迹与物体轨迹接近度生成弱标签。小实验：有无 contact timing loss 的 joint motion prediction。预期收益：更贴近因果交互。风险：视觉接近不等于真实接触。

### 4. [InterMASH: A Unified Geometric Representation for Grasp Synthesis](https://arxiv.org/abs/2609.18504)
- 改进点 1：改法：为 InterMASH token 加 morphology adapter，分别适配人手、Allegro、Shadow、LEAP Hand。低算力：冻结主干，只训练低秩 adapter。小实验：跨手形态 contact reconstruction。预期收益：提高跨 embodiment 泛化。风险：adapter 容量不足。
- 改进点 2：改法：加入 contact sparsity/coverage dual objective，避免球谐 token 过度平滑接触区域。低算力：只改 loss，无需大数据。小实验：比较 fingertip contact F1 与 grasp stability。预期收益：保留关键局部接触。风险：稀疏约束过强会漏掉掌部支撑。
- 改进点 3：改法：把 token 可解释性用于失败诊断，统计哪些 anchors 在失败抓取中贡献最大。低算力：离线 attribution。小实验：anchor ablation 后的 grasp success。预期收益：形成可调试 representation。风险：attribution 与因果贡献不完全一致。

### 5. [ForceDelta-VLA: Distilling Force-Conditioned ActionCorrections for Contact-Rich Manipulation](https://arxiv.org/abs/2609.18242)
- 改进点 1：改法：把 force correction target 分成 normal/shear/torsion 三个低维分量，而不是单一 correction。低算力：用现有力传感日志重标即可。小实验：插入/擦拭任务上比较 force overshoot。预期收益：更精细接触响应。风险：分量分解受传感坐标误差影响。
- 改进点 2：改法：增加 delay-aware gating，只有 reference-action mismatch 超过阈值时启用 correction。低算力：小 MLP 门控或规则门控。小实验：不同 latency 下成功率和抖动。预期收益：减少无必要修正。风险：阈值不当会错过早期接触变化。
- 改进点 3：改法：把 teacher 差分 correction 做一致性过滤，丢弃 force-conditioned 与 agnostic 都低置信的片段。低算力：离线过滤训练集。小实验：过滤比例 sweep。预期收益：减少伪 correction 噪声。风险：过滤会缩小困难样本覆盖。

### 6. [TAO-Force: Unifying Force-Aware Perception and Fast-Slow Control for Contact-Rich Manipulation](https://arxiv.org/abs/2609.18497)
- 改进点 1：改法：F-FiLM 之外加 force-token dropout，训练模型在力信号缺失/延迟时仍稳定。低算力：数据增强即可。小实验：模拟 50-200ms force delay。预期收益：提升真实传感鲁棒性。风险：dropout 过强削弱力利用。
- 改进点 2：改法：fast-slow control 中加入 contact onset detector，把视觉 VLA 的慢决策与力控快回路切换显式化。低算力：阈值/小分类器即可。小实验：比较接触瞬间峰值力。预期收益：减少碰撞冲击。风险：误检导致频繁切换。
- 改进点 3：改法：用少量真实接触数据做 force scale calibration，把不同工具/物体的力范围映射到统一 token。低算力：每物体几次按压/滑动。小实验：跨材料 force-conditioned policy。预期收益：降低材料域偏移。风险：校准覆盖不足。

### 7. [PointZero: 3D Point Track Completion for Learning Transferable 3D Dynamics](https://arxiv.org/abs/2609.19142)
- 改进点 1：改法：在 PointZero 预训练中加入 object-centric track grouping，让点轨迹先分对象/部件再预测。低算力：可用现有 synthetic segmentation 伪标签。小实验：articulated objects 上比较 track completion EPE。预期收益：改善部件运动边界。风险：错误 grouping 会限制连续形变。
- 改进点 2：改法：把 RGB-D 单帧替换为低帧数 history，测试是否少量历史能显著提升 dynamics prior。低算力：只改输入窗口与小 adapter。小实验：1/2/4 帧输入曲线。预期收益：找到最小充分时间信号。风险：历史帧增加存储和对齐误差。
- 改进点 3：改法：用机器人演示小集线性探针评估 point dynamics prior 是否可预测 action affordance。低算力：冻结 PointZero，只训练线性/小 MLP。小实验：预测 graspable/movable point labels。预期收益：验证 dynamics prior 对操控是否有用。风险：探针可读不等于策略收益。

### 8. [Function-Preserving Data Generation for Zero-Shot Real-to-Sim-to-Real Manipulation](https://arxiv.org/abs/2609.18293)
- 改进点 1：改法：自动识别 task-critical interfaces 后，对非关键区域做更强随机形变、关键区域做约束形变。低算力：基于接触频率/距离阈值生成接口 mask。小实验：插入任务中比较 valid contact rate。预期收益：增加数据多样性同时保功能。风险：接口 mask 错误会破坏任务。
- 改进点 2：改法：给生成资产加 physical validity score，包括穿透、接触法向、稳定姿态三项。低算力：短仿真 rollouts 即可。小实验：score 过滤前后策略训练成功率。预期收益：减少坏数据。风险：过滤过严降低覆盖。
- 改进点 3：改法：加入 real-to-sim-to-real 小闭环，用真实失败样本更新 mesh deformation prior。低算力：每任务少量失败即可。小实验：5 个真实失败回放后的 synthetic demo 质量。预期收益：更快适配真实物体。风险：失败样本太少导致偏置。

### 9. [LUMO: Designing Luminous Contact Morphology for Repeatable Whole-Finger Contact Observation](https://arxiv.org/abs/2609.18165)
- 改进点 1：改法：建立 LUMO 光信号到接触位置的温度/环境光归一化层。低算力：采集少量静态按压数据。小实验：不同光照/温度下位置误差。预期收益：提升日常部署稳定性。风险：长期材料老化仍需重新标定。
- 改进点 2：改法：把 contact location 与 joint torque 联合估计接触力大小，解决同一 torque 多位置歧义。低算力：小回归模型即可。小实验：不同 fingertip/proximal 接触点的 force error。预期收益：从位置观测走向力估计。风险：硅胶非线性会影响回归。
- 改进点 3：改法：在抓取策略中加入 LUMO contact token，比较只用 torque、只用光信号、两者融合。低算力：桌面小物体抓取即可。小实验：滑移前 contact migration 预测。预期收益：验证传感器对 policy 的实际增益。风险：任务太简单时看不出差异。

### 10. [GraphPoint: Semantic Entity Graphs and Point Trajectories for Compositional Robot Manipulation](https://arxiv.org/abs/2609.18358)
- 改进点 1：改法：给 semantic entity graph 加显式 affordance edge，如 support、contain、graspable、movable，并约束 trajectory decoder 注意这些 edge。低算力：用规则/LLM 离线标注小集。小实验：CoMani controlled splits 上 ablation。预期收益：减少语言-几何错配。风险：edge 标注噪声。
- 改进点 2：改法：将 future gripper point trajectories 分解为 approach/contact/transport 子轨迹，分别评估组合泛化。低算力：用轨迹几何阈值自动切段。小实验：长程任务中子轨迹错误定位。预期收益：更容易诊断失败源。风险：切段边界模糊。
- 改进点 3：改法：引入 counterfactual scene swap，保持语言不变只替换一个实体属性，检查 GraphPoint 是否真正跟随语义图。低算力：仿真场景编辑即可。小实验：同一任务下颜色/位置/类别单变量替换。预期收益：压制视觉捷径。风险：合成 counterfactual 分布不自然。
