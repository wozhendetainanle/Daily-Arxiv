## 逐篇要点

### 1. [GIFT: Guided Intermediate Feature Training via Action-Oriented Structural Supervision for Robotic Manipulation](https://arxiv.org/abs/2609.04193)
- 事实：GIFT 针对 VLA 和 World-Action Model 的“视觉特征丰富但控制结构不足”问题，在中间特征上加入几何对齐、affordance 预测和目标区域重建约束。
- 事实：摘要报告其在 LIBERO-Plus 和 RoboCasa 上提升多个 VLA/WAM 变体，尤其强调 articulated-object 与高精度真实操控。
- 推断：这是今天最贴近“Affordance × robot manipulation × VLA/world model”的论文；关键要看 affordance 头是否真的承载可迁移接触/功能信息，而不是任务标签捷径。
- 值得关注：它把 affordance 从口号变成训练时结构监督，适合作为后续做低算力 probe、反事实遮挡和 open-loop 控制的主参照。

### 2. [RoboTok: An Internet-Scale Data Engine for Human Demonstration Retrieval and Dexterous Manipulation Learning](https://arxiv.org/abs/2609.03199)
- 事实：RoboTok 从互联网人类操作视频中检索 manipulation-relevant demonstrations，用 3D hand trajectories 与 actor-centered reference frame 建立紧凑检索表征。
- 事实：目标是把 web video 转成 dexterous robot policy 的可扩展监督源，并在检索基准和下游机器人策略上评估。
- 推断：它连接 3D hand motion、human demonstration retrieval 和 dexterous manipulation，是今天最强的 3D hand-object/robot learning 交叉之一。
- 可能局限：视频中的手轨迹与真实机器人手/夹爪的接触力、约束和可执行动作空间仍有明显域差。

### 3. [Scaling Bimanual Household Manipulation from 1,500 hours of Demonstrations to On-Policy Corrections](https://arxiv.org/abs/2609.03591)
- 事实：论文发布 1,500 小时 bimanual household manipulation demonstrations，并训练 XR-2 VLA 模型。
- 事实：摘要称其研究 expert demonstration 数据量和 DAgger correction 数据两条 scaling axis，并观察到当前规模下成功率稳定提升。
- 推断：数据规模和双手机器人场景很重要，但方法收益可能强依赖数据管线、任务分布和 PrimeBot/Crobotia 硬件生态。
- 值得关注：适合细读其 correction 数据如何进入 post-training，以及 bimanual 动作是否真的学到协同而不只是模仿轨迹。

### 4. [Adaptive Vision-Language Grasping via Composable Foundation Priors and Generalizable Grasp Synthesis](https://arxiv.org/abs/2609.04096)
- 事实：AdaRoboVLG 将 task-dependent foundation priors 与 physically feasible grasp synthesis 解耦，显式使用 kinematic mapping 和 force-closure stability estimation。
- 事实：摘要称框架支持跨不同 robotic hands 的 generalizable grasp synthesis，并能组合空间、认知、时间 priors 处理 clutter/dynamic/functional grasp。
- 推断：这是 grasp affordance / manipulation affordance 方向的强候选；机构信息未可靠抽到，因此机构分不参与抬升。
- 可能局限：foundation-model priors 与底层 force-closure 之间的接口若过于手工，复杂接触和非刚体物体上可能不稳。

### 5. [FWBC-VLA: Force-Aware Whole-Body Compensation for Contact-Rich Loco-Manipulation](https://arxiv.org/abs/2609.03889)
- 事实：FWBC-VLA 针对 contact-rich loco-manipulation，把 VLA 的任务级动作与 whole-body compensation control 连接。
- 事实：方法引入 sensorless residual-torque estimator，将估计的 contact strength/timing 编码为 token 注入 VLA action expert，并结合 WBC 执行。
- 推断：它不是灵巧手，但很接近“VLA × contact-rich manipulation × force-aware control”；其主要价值在 sensorless contact state 接入动作生成。
- 可能局限：WL&Arm Dataset 与 wheeled-legged 平台特化较强，跨平台和细粒度手部接触未被证明。

### 6. [Sensing Which Modality Matters: Evidence-Gated Regularization for Robust VLA Policies](https://arxiv.org/abs/2609.03142)
- 事实：EGR 研究 VLA 多模态输入中的 modality entanglement，用 evidence-gated regularization 区分高证据/低证据传感器。
- 事实：论文在 BEHAVIOR-1K、双 Kinova RGB setup 和 MELFA ASSISTA + GelSight tactile setup 中评估，摘要报告遮挡、干扰和单模态 fallback 下的提升。
- 推断：这篇对 tactile manipulation 很有价值，因为它把视觉、触觉和任务相关证据之间的错配变成可测问题。
- 可能局限：evidence 信号如果来自当前模型自举，可能在未见接触模式下把真正关键的触觉通道误判为低证据。

### 7. [WISE: World-model-guided Imagination Scheduling for Efficient Post-training of Vision-Language-Action Models](https://arxiv.org/abs/2609.03681)
- 事实：WISE 用 world-model imagination 对 VLA post-training 做调度，选择 interaction-relevant states、限制 rollout horizon，并用 progress/completion signals 评价 imagined futures。
- 事实：摘要称相比 full imagination 可减少约 80% GPU 计算时间，并在真实操控分布偏移下提升鲁棒性。
- 推断：它正中“3D/world model agent × robot manipulation”的低成本训练后适配问题；关键在想象何时可信、何时应停止。
- 可能局限：如果 world model 对接触、遮挡或失败状态的预测不可靠，scheduler 可能把错误未来写进策略监督。

### 8. [MINERVA: How Small Can a Manipulation Policy Be and Still Solve LIBERO?](https://arxiv.org/abs/2609.03715)
- 事实：MINERVA 系统评估 LIBERO manipulation benchmark 的最小策略容量，0.54M 参数模型在标准 LIBERO suites 上接近大型 VLA。
- 事实：摘要指出任务 ID permutation 会让成功率接近随机，说明标准 LIBERO instruction conditioning 可能主要是在选择已记忆任务。
- 推断：这篇对评价 VLA manipulation benchmark 的真实难度非常重要，也提供了可在 CPU/小 GPU 上复现的强基线。
- 可能局限：结论主要针对 LIBERO，不能直接外推出开放世界或真实长时程接触操控。

### 9. [Robot Aware Computational Design of Object Specific Passive Grippers for Additive Manufacturing](https://arxiv.org/abs/2609.03761)
- 事实：论文提出从 object mesh、object state 和指定六轴机器人生成 object-specific passive gripper 的端到端计算管线。
- 事实：方法包含 RGB-D/ICP pose registration、surface-contact sampling、wrench screening、robot IK、FDM 有限元筛选和 3D SIMP topology optimization。
- 推断：它是“grasp affordance × object-specific tool/gripper design”的工程向论文，尤其适合低算力 CAD/FEA 局部验证。
- 可能局限：摘要明确说目前为 digital-screening status，缺少 coupon-calibrated 和 instrumented operational tests。

### 10. [ARTiS: An Adaptive Robotic Gripper for Enhanced Tool Manipulation in Disassembly Applications](https://arxiv.org/abs/2609.03362)
- 事实：ARTiS 是面向拆解工具操控的 adaptive robotic gripper，结合 soft palm/fingertips、active jamming 和 fin-ray adaptation。
- 事实：摘要称其 7 DoF 设计使指尖能适配多种表面，并用常见拆解工具评估 compliance、durability 和 versatility。
- 推断：它从硬件角度补足“灵巧工具抓持”问题，适合关注非端到端学习的 dexterity 研究者。
- 可能局限：目前更像专用夹爪设计，是否能泛化到高自由度手内操作还需额外实验。

### 11. [R2S-Eval: Robot Evaluation with Real-to-Sim Calibration via Vision-Language Models](https://arxiv.org/abs/2609.03276)
- 事实：R2S-Eval 用 real-to-sim calibration 生成接近真实评测设置的 rollout videos，再由 VLM 做 pairwise preference evaluation。
- 事实：目标是减少硬件反复评测、人工重置和 success-rate 单指标带来的不稳定。
- 推断：它把 VLA/robot policy 评测从二值成功率推向行为质量比较；适合和人工偏好、失败检测、sim-to-real calibration 联合使用。
- 可能局限：VLM preference 本身可能继承视觉偏差，尤其对接触密集任务中的不可见失败不可靠。

### 12. [FailBench: How Reliable are VLMs at Judging Robot Task Success?](https://arxiv.org/abs/2609.03611)
- 事实：FailBench 收集 2,197 次 manipulation attempts，来自 14 个公开来源，其中多数失败自然发生。
- 事实：摘要显示 13 个 VLM-based detectors 中最好平均 balanced accuracy 仅 0.77，contact-intensive assembly 上接近随机；局部裁剪可无训练提升 2.4 点。
- 推断：这是机器人评测/失败检测的很强 falsifying benchmark，直接提醒不要把 VLM judge 当作可靠物理成功检测器。
- 可能局限：benchmark 的失败类型覆盖虽广，但对触觉、力反馈和长时序因果证据仍可能不足。

### 13. [Toward Physically Grounded JEPA World Models for Goal-Conditioned Robotic Planning](https://arxiv.org/abs/2609.03565)
- 事实：论文在 action-conditioned JEPA world model 中加入 inverse dynamics 与 state alignment，用于 goal-conditioned robotic planning。
- 事实：摘要称模型在 TwoRoom、PushT、OGBench-Cube 等任务上提升规划成功率，并用 transition-subspace 分析比较表示维度。
- 推断：它适合 NFF/JEPA 式物理表示读者细看，因为它直接问 latent transition 是否保留控制相关信息。
- 可能局限：任务仍偏标准控制/仿真，真实机器人接触、遮挡和多物体交互还未充分覆盖。

### 14. [Latent Energy Action Planning with World Models](https://arxiv.org/abs/2609.03294)
- 事实：LEAP 将完整 action horizon 作为可微变量，通过 frozen LeWorldModel 优化 terminal latent goal matching 和 terminal-window state energy。
- 事实：摘要报告在四个控制域中，相比 LeWM+CEM 的 matched protocol 成功率从 77.5% 提至 94.8%。
- 推断：这篇强调不重训世界模型、只优化动作，是低算力规划改造的优先读物。
- 可能局限：优化结果依赖 frozen LeWM 的 latent/decoder 一致性，若世界模型错了，动作优化会放大错误。

### 15. [VeriPhy: Agentic Physical Reasoning for World Model Evaluation and Refinement](https://arxiv.org/abs/2609.03153)
- 事实：VeriPhy 构建可审计 physical-verification system：text-only planner 先把 prompt 编译成 typed physical obligations，再调用 frozen low-level experts 取证。
- 事实：摘要强调每个 verdict 都保留 provenance-carrying evidence record，并在 1,500 个 human-annotated flaw clip 上评估。
- 推断：虽然主要面向生成视频/world model 评价，但它的方法适合机器人世界模型的物理约束审计。
- 可能局限：低级专家如 segmentation/tracking/depth 的错误会传导到 typed resolvers，且三值 verdict 可能过于保守。

### 16. [WorldReward: Reward Modeling for Camera-Conditioned World Models](https://arxiv.org/abs/2609.03952)
- 事实：WorldReward 是 camera-conditioned world models 的 VLM-based pairwise preference reward model，分解视频为 action-aligned chunks。
- 事实：它同时评估 action consistency、appearance quality 和 motion quality，并用于 HY-WorldPlay 1.5 的 RL post-training。
- 推断：这篇对交互式世界模型有价值，但离真实 robot manipulation 还有一层仿真/视频到控制的距离。
- 可能局限：frontier VLM 生成的 reasoning-augmented preference 数据可能引入评判偏好，且短局部接触证据仍可能被遗漏。

### 17. [Toward Unified Robot Learning: Bridging Representation, Vision-Language-Action, and World Models](https://arxiv.org/abs/2609.03927)
- 事实：这是一篇 survey，试图统一 representation learning、VLA models 和 world models 三条 robot learning 线索。
- 事实：摘要提出环境表示、策略学习和预测建模三个轴，并讨论 uncertainty、OOD、cross-embodiment、long-context 与 long-horizon planning。
- 推断：作为综述适合建立地图，但不是新算法；如果要追具体实验，应优先读前面 GIFT/WISE/EGR/MINERVA 等实证论文。
- 值得关注：它有助于把今天多篇 VLA/world-model 操控论文放到同一设计空间里。

### 18. [Rethinking World Models for Safety-Critical Embodied Systems](https://arxiv.org/abs/2609.03774)
- 事实：RIWM 是一篇 perspective，批评高 likelihood/视觉保真不等于 safe decision-making 所需证据。
- 事实：作者提出 Risk-Informed World Model，强调后果、干预、epistemic uncertainty、recoverability 和 runtime safety assurance。
- 推断：它更像研究议程，但对 embodied systems 的安全评估框架有用。
- 可能局限：没有新 benchmark 或训练算法，价值取决于后续能否转化为可执行约束和 falsifying tests。

### 19. [Air-Ground Collaborative Vision-and-Language Navigation via Shared Bird's-Eye Maps](https://arxiv.org/abs/2609.03483)
- 事实：AGC-VLN 是 air-ground collaborative VLN 的 training-free baseline，通过共享 BEV map 让 UAV 全局视角与 UGV 第一视角互补。
- 事实：摘要报告在 CARLA-Air Town10HD 的 100 个闭环 episode 上达到 77% joint success，并超过单体 baseline。
- 推断：这是 embodied navigation 里的 multi-agent spatial collaboration 论文，低于操控主线但对 agentic embodied reasoning 有价值。
- 可能局限：CARLA-Air 场景和 BEV 标注接口较理想化，真实室内/室外机器人通信延迟与定位误差可能影响结果。

### 20. [GraFT: A Training-Free Framework for Spatial Reasoning in Multimodal Large Language Models via 3D Scene Graphs](https://arxiv.org/abs/2609.03892)
- 事实：GraFT 通过 compact 3D scene graph 给 frozen MLLMs 提供 deterministic geometry、BEV layout 和 egocentric visual grounding。
- 事实：摘要称其在 ScanQA 和 VSI-Bench 上显著提升空间推理表现，且不需要大规模 fine-tuning 或专用 3D encoder。
- 推断：这篇是“3D scene graph × multimodal agent spatial reasoning”的实用路线，可服务于机器人任务规划前的空间问答。
- 可能局限：scene graph 的构建质量是瓶颈；动态图、可操作对象和接触状态并未自动解决。

### 21. [BRIDGE: An Open-Source Humanoid Platform via Morphology-Control Co-Design for Physical AI](https://arxiv.org/abs/2609.03497)
- 事实：BRIDGE 用 morphology-control co-design 设计开源 88cm humanoid platform，并发布控制策略。
- 事实：摘要提出 kinematic retargeting fidelity 与 dynamic tracking performance 共同度量 human-like movement。
- 推断：它对“用人类行为数据驱动 humanoid embodiment”重要，但和手部灵巧操控的交叉还不是主问题。
- 可能局限：平台规模、执行器能力和开放材料完整度需要实测核验。

### 22. [Real-Time Shape Control of Multi-Segment Soft Robotic Arms Using Koopman Operators with Global and Local Observables](https://arxiv.org/abs/2609.03175)
- 事实：论文用 Koopman-based MPC 结合 global/local observables 做多段 soft robotic arm 的实时 shape control。
- 事实：摘要报告数值实验扩展到 10 个独立驱动段，物理实验覆盖 3/5 段软臂、0.6 m/s tip speed、载荷和侧向扰动恢复。
- 推断：这是 contact-safe / constrained-space manipulation 的控制底层候选，尤其适合柔性臂或狭窄空间任务。
- 可能局限：Koopman observables 的选择与平台结构耦合强，迁移到多指手并不直接。

### 23. [Programming and execution of skill-based human-robot-crane collaborative tasks](https://arxiv.org/abs/2609.03392)
- 事实：论文展示 CAD-model based programming 与 modified Behavior Tree，用于 parametrized robot skills 和 skill monitors。
- 事实：案例是 human-robot-crane collaboration：人指挥吊车和机械臂把重物插入目标。
- 推断：这偏工业协作系统，但“skill + monitor + parameterized execution”对工具使用和重物操控有借鉴意义。
- 可能局限：没有体现 VLA/3D 语义理解，更多是工程控制结构。

### 24. [DropClick: Semi-Automated One-Click Segmentation for Agricultural Robotic Data](https://arxiv.org/abs/2609.03680)
- 事实：DropClick 是 agricultural robotic data 的 single-click / missing-click robust segmentation 工具，只用 5 张训练图就可部署伪标签生成。
- 事实：摘要报告在 SB20/BUP20 上一键分割达到 70.0/72.6 mIoU，并可节省 31.9%-46.3% 用户输入。
- 推断：它不是操控策略论文，但对低成本机器人感知数据标注很有用。

### 25. [RoughSense: Lightweight Terrain-Induced Rover Vibration Prediction Using Point Clouds and IMU Feedback](https://arxiv.org/abs/2609.03720)
- 事实：RoughSense 用 LiDAR point cloud 和 IMU feedback 做轻量 vibration-aware traversability mapping。
- 事实：方法从局部点云几何估计振动 proxy，再用 IMU 与 Recursive Least Squares 在线修正。
- 推断：这是机器人导航中的低算力地形感知论文，适合 embodied navigation 和边缘部署。
- 可能局限：面向 rover/terrain，和室内操控、手物交互相关性较弱。

### 26. [MulDP: Multimodal Diffusion Policy for Autonomous Quadruped Parkour Navigation across Complex Terrains](https://arxiv.org/abs/2609.03984)

- 事实：论文构建 QPND 数据集，并在仿真和真实实验中验证长时程自主导航。
- 推断：它体现 perception-action 紧耦合的 embodied execution，但不涉及物体操控或 affordance。
- 可能局限：扩展到带手臂的 loco-manipulation 需要显式处理接触和任务对象。

### 27. [TRaIL-Odom: Tightly Coupled Continuous Time Radar-IMU-LiDAR Odometry with Adaptive Doppler Weighting](https://arxiv.org/abs/2609.03561)

- 推断：它对 embodied agents 的鲁棒 3D localization 有实际价值，是导航/移动机器人基础能力论文。

### 28. [A hybrid pipeline for dynamic ontology-based semantic mapping](https://arxiv.org/abs/2609.03891)

- 事实：系统持续更新 object instances、spatial properties 和 semantic relations，构建 dynamic semantic world model。
- 推断：这和 object-centric embodied memory 相关，但方法偏传统系统，ML/VLA 成分较弱。
- 可能局限：依赖检测、跟踪和 homography 投影质量，复杂三维遮挡下可能不足。

### 29. [Automated Weld Seam Recognition and 3D Mapping for Robotic Post Processing Using Photogrammetry and Semantic Segmentation](https://arxiv.org/abs/2609.03970)

- 事实：目标是减少大工件高精度扫描的数据量和时间成本。
- 推断：这是工业机器人视觉管线，和“3D perception × robotic post processing”相关。
- 可能局限：摘要明确是 preliminary stage，高精度测量、闭环打磨/检测仍需后续验证。

### 30. [Predictive Zonotope Reduction: Precise Runtime Monitoring under Uncertainty](https://arxiv.org/abs/2609.03699)

### 31. [QLAUN: A Research-Oriented, Robust, Agile, Modular, and Affordable Torque-Controlled Quadruped Robot](https://arxiv.org/abs/2609.03623)

### 32. [ReRoom: Blending Virtual and Physical Contexts for In Situ Room Planning in Mixed Reality](https://arxiv.org/abs/2609.03596)

### 33. [Point&Spawn: Mid-Air Reference-Free Object Instantiation Using Gaze and Hand Gestures in Extended Reality](https://arxiv.org/abs/2609.03661)

### 34. [VI3: Grounding Pretrained 3D Foundation Models with Inertial Cues](https://arxiv.org/abs/2609.03824)

### 36. [OctWorld: Long-Range World-Consistent Video Generation with Octree-Based 3D Mapping](https://arxiv.org/abs/2609.03919)

### 37. [Unfold The World: Factorize 4D Properties in Reinforcing Spatial Reasoning](https://arxiv.org/abs/2609.03729)

- 事实：摘要称其在 multi-view/video benchmarks 上提升 3D/4D reasoning。
- 推断：这对 agentic spatial reasoning 有价值，但离真实机器人操控还有任务接口缺口。

- 推断：它对长时程 embodied perception 有实用价值，尤其是移动机器人/AR 的在线重建。

### 40. [RealCADBench: Benchmarking Parametric CAD Modeling from Industrial Design Intents](https://arxiv.org/abs/2609.03773)

## 今日最值得细读的 5 篇

1. [GIFT: Guided Intermediate Feature Training via Action-Oriented Structural Supervision for Robotic Manipulation](https://arxiv.org/abs/2609.04193)：显式把 affordance、几何和 goal region 放进 VLA/WAM 中间特征监督，是今天最强的 affordance × manipulation 交叉。
2. [RoboTok: An Internet-Scale Data Engine for Human Demonstration Retrieval and Dexterous Manipulation Learning](https://arxiv.org/abs/2609.03199)：用 3D hand trajectories 从互联网视频检索人类示范，直接服务 dexterous manipulation 数据扩展。
3. [Scaling Bimanual Household Manipulation from 1,500 hours of Demonstrations to On-Policy Corrections](https://arxiv.org/abs/2609.03591)：1,500 小时双手 household manipulation 数据与 XR-2 VLA scaling，对双手机器人学习有直接价值。
4. [Adaptive Vision-Language Grasping via Composable Foundation Priors and Generalizable Grasp Synthesis](https://arxiv.org/abs/2609.04096)：把 foundation priors 与跨手型 grasp synthesis 解耦，切中 functional/grasp affordance 和物理可执行抓取。
5. [Sensing Which Modality Matters: Evidence-Gated Regularization for Robust VLA Policies](https://arxiv.org/abs/2609.03142)：把视觉/触觉/多传感器是否真正任务相关变成训练约束和诊断，非常适合 tactile/VLA manipulation 研究。

## 10 篇低算力可改进论文

以下均为推断性研究建议，优先选择不需要重新训练大模型、可用小规模仿真、离线轨迹、局部 probe、冻结模型特征或轻量评测脚本验证的方向。每个改进点都针对论文方法本身，而不是简单扩大训练。

### 1. [GIFT: Guided Intermediate Feature Training via Action-Oriented Structural Supervision for Robotic Manipulation](https://arxiv.org/abs/2609.04193)
- 改进点 1：给 GIFT 的 affordance prediction 加反事实遮挡审计。具体改法是在训练/评测时遮挡 instruction-relevant object、end-effector contact region 和无关背景三类区域；低算力可行原因是只需冻结模型特征并跑 LIBERO/RoboCasa 小子集；小实验是在 50-100 条轨迹上比较正常、遮挡关键区域、遮挡背景、shuffle instruction 的成功率和 affordance map 变化；预期收益是验证 affordance 监督是否真的对控制有用；风险是遮挡策略过粗会破坏整体视觉分布。
- 改进点 2：把 geometry/affordance/goal 三个中间约束做动态权重，而不是固定混合。具体改法是用小 gating head 根据任务阶段估计每个约束的权重；低算力可行原因是只训练小头或离线重加权，不需要重训 backbone；小实验是在 articulated-object tasks 上比较固定权重、阶段规则权重和 learned gating；预期收益是减少某个辅助目标在非相关阶段干扰动作；风险是 gating 可能学成任务 ID 捷径。
- 改进点 3：加入 matched open-loop controls。具体改法是保留同样架构，但替换为 random affordance labels、object mask labels 和 no-affordance 三组对照；低算力可行原因是可用少量 epoch 或只训练 readout；小实验报告特征 probe、动作误差和 rollout success 的共同变化；预期收益是分离“额外监督”与“真 affordance 信息”；风险是训练预算太小导致差异不显著。

### 2. [RoboTok: An Internet-Scale Data Engine for Human Demonstration Retrieval and Dexterous Manipulation Learning](https://arxiv.org/abs/2609.03199)
- 改进点 1：在 RoboTok 检索空间加入动作阶段边界。具体改法是先用手速度、接触近似和物体相对运动把视频切成 approach/contact/transport/release；低算力可行原因是阶段检测可用 3D hand trajectory 的规则或轻量 HMM；小实验是在 1k 网络短片上比较全片 embedding 与阶段对齐 embedding 的 top-k retrieval；预期收益是减少外观相似但接触阶段不匹配的示范；风险是无物体轨迹时接触边界噪声较大。
- 改进点 2：加入 robot feasibility filter。具体改法是把检索到的人手轨迹通过目标机器人手/夹爪的简化 kinematic reachability 和 collision proxy 过滤；低算力可行原因是只跑 IK/几何检查，不训练大模型；小实验比较过滤前后下游 policy 的小样本行为克隆成功率；预期收益是缩小 human-to-robot embodiment gap；风险是过严过滤会丢掉有价值但需重定向的示范。
- 改进点 3：做负样本难例挖掘。具体改法是构造同一物体不同功能用法、同一手势不同物体、同一轨迹不同目标的 hard negatives；低算力可行原因是主要改检索损失和评测集；小实验看 retrieval nDCG 与 5-10 个机器人任务微调效果；预期收益是提升功能性动作区分；风险是人工/半自动 hard negative 标注成本。

### 3. [Scaling Bimanual Household Manipulation from 1,500 hours of Demonstrations to On-Policy Corrections](https://arxiv.org/abs/2609.03591)
- 改进点 1：对 DAgger correction 做失败类型分层采样。具体改法是把人工干预按抓取失败、双手协同失败、遮挡失败、终止时机失败分桶；低算力可行原因是只改 correction 数据选择；小实验用同样 correction 数量比较随机采样与分层采样；预期收益是提高少量人工修正的边际价值；风险是失败分类噪声会影响采样。
- 改进点 2：加入双手相对约束 probe。具体改法是训练小 probe 预测双手相对距离、相对速度和物体夹持状态，检测 XR-2 表征是否编码 bimanual coordination；低算力可行原因是只用冻结特征和日志；小实验比较成功/失败轨迹 probe error 与策略成功率相关性；预期收益是发现模型是否真的学到协同；风险是 proxy 标签不等于真实力闭合。
- 改进点 3：构造单手退化对照。具体改法是在相同任务中屏蔽一只手观察或动作，测 bimanual benefit；低算力可行原因是评估脚本改动为主；小实验选 5 个必须双手和 5 个可单手任务，比较完整、左手屏蔽、右手屏蔽；预期收益是量化数据规模是否带来真正双手机制；风险是屏蔽方式可能产生训练外分布。

### 4. [Adaptive Vision-Language Grasping via Composable Foundation Priors and Generalizable Grasp Synthesis](https://arxiv.org/abs/2609.04096)
- 改进点 1：为 composable priors 加冲突检测。具体改法是当空间、认知、时间 priors 给出相互矛盾 grasp candidates 时，用 force-closure margin 和任务成功先验做显式仲裁；低算力可行原因是只在候选抓取层重排序；小实验在 cluttered mug/tool grasp 中人为制造 conflicting prompts；预期收益是避免 foundation prior 互相抵消；风险是仲裁规则过度依赖手工阈值。
- 改进点 2：跨手型一致性正则。具体改法是同一功能 grasp 在不同 hand kinematics 下保持接触功能区域一致，而不是仅保持末端姿态相似；低算力可行原因是可用仿真抓取候选和简化接触点；小实验比较 Allegro/parallel gripper/三指手的功能区接触覆盖；预期收益是提升 cross-hand generalization；风险是不同手型的可行接触拓扑本来就不同。
- 改进点 3：加入失败后局部重采样。具体改法是抓取失败后只在原候选邻域重采样接触点和 wrist pose，而不重新调用全部 foundation modules；低算力可行原因是局部采样和稳定性估计便宜；小实验在动态/拥挤桌面上比较一次性 grasp 与 3 次局部修复；预期收益是提高真实闭环成功率；风险是局部 basin 错误时会反复失败。

### 5. [Sensing Which Modality Matters: Evidence-Gated Regularization for Robust VLA Policies](https://arxiv.org/abs/2609.03142)
- 改进点 1：加入传感器证据的反事实 shuffle。具体改法是在训练后评测中对 RGB、tactile、proprioception 分别做时间错位、同任务错配和跨任务错配；低算力可行原因是纯 inference diagnostic；小实验测 EGR 与 baseline 在三类错配下的动作漂移；预期收益是确认 evidence gate 是否识别任务相关模态；风险是 shuffle 分布过强导致所有模型都崩溃。
- 改进点 2：把 evidence gate 变成阶段条件。具体改法是根据 grasp/contact/transport/release 阶段给不同模态证据阈值；低算力可行原因是阶段可由夹爪状态和触觉变化近似；小实验在 GelSight 真实任务上比较统一阈值与阶段阈值；预期收益是接触阶段更重视触觉，移动阶段更重视视觉；风险是阶段检测错误。
- 改进点 3：加入低证据模态的 dropout curriculum。具体改法是早期轻微腐蚀低证据通道，后期逐步增加遮挡和噪声；低算力可行原因是训练目标不变，只改数据增强 schedule；小实验复现实验中的 BEHAVIOR-1K 10 个 skill；预期收益是减少模型对无关传感器的依赖；风险是过强 dropout 损害多模态互补。

### 6. [WISE: World-model-guided Imagination Scheduling for Efficient Post-training of Vision-Language-Action Models](https://arxiv.org/abs/2609.03681)
- 改进点 1：给 imagination scheduler 加可信度校准。具体改法是用短 horizon 真实 rollout 与 imagined rollout 的 discrepancy 训练小校准头；低算力可行原因是只需少量真实/仿真片段和冻结 world model；小实验比较无校准、固定 horizon、校准 horizon 在 5 个操控任务上的 post-training 效果；预期收益是减少错误想象监督；风险是校准集过小导致过拟合。
- 改进点 2：做交互关键帧选择的负对照。具体改法是比较 interaction-relevant states、随机 states、视觉变化最大 states、接触近似 states 四种调度；低算力可行原因是只改调度策略；小实验测 GPU 时间、成功率和 imagined future error；预期收益是验证 scheduler 的真实来源；风险是不同任务关键帧定义不统一。
- 改进点 3：把 progress/completion signals 分解为对象状态与机器人状态。具体改法是对 imagined futures 分别评分 object displacement、gripper relation 和 collision/smoothness；低算力可行原因是可用现成检测/状态标签；小实验比较单一完成分数与分解分数的 action refinement；预期收益是避免只优化看似完成的视觉结果；风险是分解指标无法覆盖语义任务。

### 7. [MINERVA: How Small Can a Manipulation Policy Be and Still Solve LIBERO?](https://arxiv.org/abs/2609.03715)
- 改进点 1：扩展 task-ID permutation probe。具体改法是加入 instruction paraphrase、object texture swap 和 layout swap，区分任务记忆、语言理解和视觉泛化；低算力可行原因是 MINERVA 本身 CPU/小 GPU 可跑；小实验在标准 LIBERO 与 LIBERO-Plus 各取 20 个任务；预期收益是更清楚界定 benchmark capacity floor；风险是扰动生成不够规范。
- 改进点 2：加入接触敏感动作表示。具体改法是在小模型中比较 direct L1、flow matching、piecewise spline、contact-event token 四类动作头；低算力可行原因是模型小且训练快；小实验报告成功率、动作 jitter 和接触阶段误差；预期收益是找出小模型是否也需要结构化动作；风险是 contact-event 标签需近似。
- 改进点 3：做 cross-benchmark miniature transfer。具体改法是用同一 0.54M/1M 架构在 LIBERO、CALVIN 小子集和一个真实录像评测上迁移；低算力可行原因是只训练小模型；小实验看参数量、视觉容量和 action chunk 长度的交互；预期收益是避免把 LIBERO floor 误读成通用机器人 floor；风险是不同数据格式对齐成本。

### 8. [R2S-Eval: Robot Evaluation with Real-to-Sim Calibration via Vision-Language Models](https://arxiv.org/abs/2609.03276)
- 改进点 1：加入 VLM judge 的不确定性拒答。具体改法是当 pairwise preference 的证据不足或帧间结论不一致时输出 abstain，并触发少量真实硬件复评；低算力可行原因是评测层改动；小实验比较无拒答、置信阈值拒答和人工 spot-check；预期收益是减少错误策略排名；风险是拒答过多降低自动评测效率。
- 改进点 2：用失败类型校准 real-to-sim。具体改法是不只匹配视觉场景，还匹配滑落、碰撞、未闭合、错物体等 failure modes 的频率；低算力可行原因是可从少量真实 rollout 标注统计；小实验看校准前后模拟 ranking 与真实 ranking 的 Kendall tau；预期收益是提高评测结论可信度；风险是小样本 failure 分布不稳定。
- 改进点 3：加 region-of-interest evidence path。具体改法是要求 VLM preference 同时输出关键帧和对象区域，再用裁剪区域复核；低算力可行原因是只调用裁剪/二次评估；小实验比较全视频 judge 与 ROI judge 在 contact-heavy tasks 上的一致性；预期收益是减少背景和流畅度偏见；风险是 ROI 定位错误。

### 9. [FailBench: How Reliable are VLMs at Judging Robot Task Success?](https://arxiv.org/abs/2609.03611)
- 改进点 1：把 FailBench 的局部裁剪从静态 ROI 扩展到时序事件裁剪。具体改法是按 object motion/contact change 自动选 3-5 个事件片段；低算力可行原因是只需光流/检测轨迹或已有视频；小实验比较全视频、静态裁剪、事件裁剪的 balanced accuracy；预期收益是提升 contact-intensive assembly 失败检测；风险是事件检测会漏掉慢性失败。
- 改进点 2：加入成功偏置校准。具体改法是用 temperature scaling 或阈值移动专门校正 ambiguous evidence 下的 success bias；低算力可行原因是只用验证集 logits/分数；小实验按失败可见性分桶报告 ECE、balanced accuracy 和 false success rate；预期收益是减少危险的假成功；风险是过度校准会增加假失败。
- 改进点 3：构造触觉/力代理提示。具体改法是在只有视频时补充由视觉估计的接触持续时间、相对速度突变、夹爪闭合状态作为文本/表格证据；低算力可行原因是无需新传感器；小实验看加入代理证据后 VLM 对装配/插入任务的判断；预期收益是弥补不可见接触信息；风险是代理指标错误会误导模型。

### 10. [Toward Physically Grounded JEPA World Models for Goal-Conditioned Robotic Planning](https://arxiv.org/abs/2609.03565)
- 改进点 1：加入 action-shuffle / zero-action / constant-latent 三个 open-loop 对照。具体改法是在同一 JEPA 表征上替换动作输入，报告 rollout 与 planning success；低算力可行原因是评估协议改动；小实验复现 PushT 或 OGBench-Cube 小规模训练；预期收益是确认 latent transition 是否真的 action-conditioned；风险是任务太简单时对照差异过小。
- 改进点 2：做 state alignment 维度瓶颈。具体改法是限制 SA target 或 projection dimension，观察成功率和 transition effective dimension 的关系；低算力可行原因是只改投影头；小实验用 3 个维度设置和 3 个随机种子；预期收益是找出物理状态信息的最低足够维度；风险是维度变化与优化难度耦合。
- 改进点 3：加入接触/关键对象区域 reweight。具体改法是 state alignment 对物体和末端附近状态给更高权重，背景/静态区域降低权重；低算力可行原因是可用仿真状态或简单 mask；小实验比较 uniform SA 与 object-centric SA；预期收益是让 JEPA 更关注交互动态；风险是 mask 不准会遗漏远距离因果。
