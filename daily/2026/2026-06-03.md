**逐篇要点**

1. CoT in ICL：研究 CoT 深度如何影响 ICL 泛化；用高维线性回归和随机矩阵理论给出精确误差公式；亮点是相变、过度思考与最优推理深度，局限是理论模型仍简化。
2. LEAP：面向 Lean 形式证明；用 agentic framework 把非形式推理、分解和 Lean 编译器反馈结合；值得看其 Lean-IMO-Bench，但结果依赖强基础模型。
3. ReLoRA：解决 base model 更新后旧 LoRA 失配；用 Bayesian optimization 初始化和 scheduled regularization 快速再适配；工程价值高，机构信息需谨慎。
4. CtM LoRA：解决多个 LoRA 合并成单一低秩 adapter；先压缩到共享子空间再合并；适合低成本验证，局限是任务冲突结构可能影响结论。
5. Muon Momentum：解释 Muon 中 momentum 的作用；把 momentum 视为 spectral filter；理论与 LLM 预训练实验相连，适合优化器理论读者。
6. Group Composition：研究神经网络如何学习有限群组合；用 Fourier/表示论刻画梯度流；理论含量高，和符号结构、低秩表示有关。
7. GRZO：面向 LLM fine-tuning 的 zeroth-order optimizer；用 group-relative normalization 降低方差；低显存实用，但大模型收益需复核。
8. MAdam：指出 MOO solver 接 Adam 会产生权重和几何错配；提出 metric-aware wrapper；贡献清楚，低成本可在 toy MOO 上复现。
9. Unit Cell Flow Matching：用 flow matching 做有机晶体结构预测；显式生成 unit cell 并大幅加速；应用强，计算化学泛化仍要看更多体系。
10. Stable Flow Matching DS：把 flow matching 和 Lyapunov 稳定约束结合；用于机器人模仿学习；方法漂亮，但机构未能从抽取文本确认。
11. Bootstrap Your Generator：无配对数据训练 flow matching 编辑模型；用 frozen model 语义线索和 cycle consistency；NVIDIA/Tel Aviv 组合强，算力门槛偏高。
12. Neurosymbolic VQA：用 LLM 蒸馏 ASP 规则；把 VQA 的神经感知和逻辑推理连接起来；数据需求少，但规则正确性依赖 solver feedback。
13. VistaHop：提出多跳视觉推理 benchmark 和工具环境；当前 MLRM 表现很低；适合做视觉证据链和区域重访研究。
14. VEPO：发现文本 RLVR 的 entropy token selection 不适合视觉推理；加入视觉敏感性做 token selection；贡献直接，需检查不同 VLM 的稳健性。
15. Tensor Network ITE：用 logarithmic grid + implicit stepping 加速 MPS imaginary-time evolution；非 cs 但 tensor network 高相关；适合量子多体方法读者。
16. ML-QEM：用近 Clifford 模拟数据训练量子误差缓解模型；面向 VQE，最多到 12 qubits；非 cs，但 ML + quantum 交叉明确。
