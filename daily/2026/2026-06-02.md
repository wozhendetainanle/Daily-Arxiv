**论文要点**

1. Neuro-symbolic CYK：把 CYK 句法解析算法直接注入神经网络结构；用矩阵-向量操作编码动态规划；值得看的是“已知算法转神经结构”的可复用路线，局限是实验语法较简单。

2. Self-Certifying Transport MCMC：用 normalising flow 作 MCMC proposal，并给 spectral-gap 证书；贡献在于把采样质量从经验诊断推进到可计算证书；局限是高维 covering certificate 会变弱。

3. Representation Collapse：研究多阶段 LLM post-training 后隐藏表征低秩/各向异性塌缩；给出 hidden states、logits、LoRA updates 的测量套件；局限是摘要看起来更像 protocol/benchmark，需看实验完整性。

4. Balanced LoRA：指出 LoRA 低秩因子存在参数不变性，导致条件数差异；提出 BaLoRA 投影到 balanced manifold 加速收敛；低成本、理论和实践都贴近，非常值得细读。

5. FBHM：构造功能性 hateful meme benchmark，区分修辞机制和目标群体；提出 learnable steering vectors，少量样本超过 ICL/PEFT；局限是安全/偏见评估需看标注质量和毒性覆盖。

6. Quantum GP Kernels：用谱熵解释 quantum GP kernel 的 dequantization、posterior pathology 和 BO 失效；有 IBM Heron 硬件实验；值得看在于把量子核有效性变成可诊断谱坐标。

7. TRACE：短 warm-start probing 找任务核心参数，用于 continual fine-tuning；目标是少存储、少干扰地替代多 adapter/replay；局限是参数选择稳定性和任务顺序敏感性需验证。

8. GraphARC：把 abstract reasoning 从网格扩展到图结构；适合测 relational abstraction 和 few-shot transformation；局限是是否真正测推理而非模板匹配，要看生成规则和 split。

9. DisjunctiveNet：用可微凸化优化层表达逻辑/线性约束知识；适合小数据、规则丰富场景；局限是 relaxation 与真实离散逻辑之间可能有可行性偏差。

10. FOCUS：做 in-context object localization，无训练更新，用 support constraints + policy optimization；贴近视觉 ICL；局限是 support set 选择和类无关泛化会决定上限。

11. Positional vs Symbolic Heads：在受控任务中分析 attention head 的位置型/符号型学习动态与 RoPE 几何；核心价值是解释 length generalization；局限是合成任务到真实 LLM 的外推。

12. Equivariant Latent Alignment：用 flow matching 在群对称下对齐 latent space；面向几何一致生成/视角变化；局限是群假设明确时有效，开放世界变换更难。

13. Generative Quantum Data Embeddings：学习量子 embedding circuit，而不是固定 ansatz；目标是提升经典数据到量子态的监督学习表现；局限是优化搜索成本和小规模量子优势证据。

14. PatchWorld：通过 executable code patch 做世界模型的梯度-free 优化；神经符号味道很强，适合 agent 环境；局限是代码可执行性、安全性和 patch search 空间控制。

15. Constrained Flow Optimization：用 sequential fine-tuning 让 diffusion/flow molecular generator 同时追 reward 和 constraints；适合药物/分子设计；局限是 reward hacking 和约束满足的真实化学有效性。
