## 逐篇要点

### 1. [Grounding Generated Video Plans in Simulation Towards Versatile Dexterous Controllers](https://arxiv.org/abs/2609.10050)
- 事实：把生成的 hand-object interaction 视频当作可控参考动作，再用仿真 HOI tracking 将这些参考落到低层 dexterous controller。
- 事实：论文声称以少量人工介入 grounded 1,500+ generated videos，并在真实闭环实验中展示 functional grasps、non-prehensile manipulation 和物体姿态跟踪。
- 推断：它把视频生成、HOI reconstruction 和可执行控制连起来，是今天最贴近 3D HOI 到机器人控制的论文。
- 可能局限：生成视频参考如果几何/接触不守恒，tracker 会学到视觉上合理但物理上脆弱的动作先验。

### 2. [GTA-2: A Multi-VLM Framework for Synthesizing Robot Manipulation Skills via Grounded Task Axes](https://arxiv.org/abs/2609.09808)
- 事实：GTA-2 用多个 VLM agent 将 manipulation task 分解为 object-centric task axes、keypoints、controller composition 与场景参数。
- 事实：目标是在没有任务特定 demonstration、policy training 或 fine-tuning 的情况下生成可执行 task-bespoke skills。
- 推断：它的价值在于把 VLM 的语义推理限制到几何轴和控制器接口，比直接输出动作更可诊断。
- 可能局限：skill 质量会受 RGB-D grounding、控制器库覆盖范围和物体几何假设共同限制。

### 3. [Time-Frequency Geometric Cross-Attention for Chunked Vision-Language-Action Models](https://arxiv.org/abs/2609.09925)
- 事实：论文指出 chunked VLA 输出的是 1-2 秒多变量动作轨迹，但常被当成普通 timestep token 解码。
- 事实：TFGCA 在 DCT/小波式 time-frequency 表示中做 geometric cross-attention，试图分离平滑趋势和高频修正。
- 推断：这是对 VLA action head 的结构性改法，适合直接插入现有 VLA/flow/action-chunk baseline 做低成本验证。
- 可能局限：频域分解能否覆盖接触瞬间的非平稳突变，需要在 tactile/contact-rich 任务上单独验证。

### 4. [HaWMPO: Hallucination-Aware World Model-based Policy Optimization for Generalist Robot Policy](https://arxiv.org/abs/2609.09941)
- 事实：HaWMPO 针对世界模型 imagined rollout 的 hallucination 问题，为 VLA post-training 引入 action-conditioned hallucination score。
- 事实：方法把 hallucination score 写入 group-relative policy optimization 的 Reward-Soft 机制，降低不可靠 action chunks 的训练权重。
- 推断：这篇适合和 DUET-DINO、物理 world-model 诊断类工作连读。
- 可能局限：hallucination detector 若仍由同一视觉生成分布训练，可能低估真实机器人偏移和接触失败。

### 5. [DUET-DINO: Simultaneous Cross-View World Modeling for Latent Planning in Robot Manipulation](https://arxiv.org/abs/2609.10506)
- 事实：DUET-DINO 同时建模 side camera 与 wrist camera 的 action-conditioned latent future，用 cross-view conditioning 支持 7-DoF planning。
- 事实：在 reach、angled-reach、grasp-and-lift 等任务上优于单视角和独立双视角 baseline，并报告 DINOv3 比 V-JEPA 2 更能捕捉细粒度动作诱导变化。
- 推断：它把“全局场景视角”和“夹爪近场视角”的互补性显式放进 world model，是 VLA/WAM 操控中很实际的设计点。
- 可能局限：cross-view 同步、标定误差和遮挡会决定真实部署上限。

### 6. [Compact Visuotactile World Models for Lifting: Prediction, Reward Alignment, and Force Constraints](https://arxiv.org/abs/2609.09597)
- 事实：研究 compact visuotactile world model 是否能通过 contact prediction 支持 lifting 决策，而不是只优化预测误差。
- 事实：触觉显著降低端点力预测误差，但 force-budget success 仍落后于直接 force feedback；trajectory-level calibration 明显优于 frame-level calibration。
- 推断：这篇的贡献在于把 prediction、reward alignment、force constraints 分开量化，避免把好预测误当成好控制。
- 可能局限：实验集中在 Lift，结论迁移到滑动、旋转或多接触 manipulation 仍需验证。

### 7. [FolDeX: A Physical-World Benchmark for Long-Horizon Robotic Manipulation of Deformable Objects](https://arxiv.org/abs/2609.10243)
- 事实：FolDeX 是真实机器人长时程 deformable-object manipulation benchmark，以 garment folding 为主任务。
- 事实：数据覆盖 2,000+ 小时、20+ tasks，并组织成人类干预/恢复、跨任务、跨场景、跨 embodiment 复用四条研究轴。
- 推断：它正好补目前 VLA/WAM 在短时程刚体任务上的评测偏差，是物理世界 benchmark 方向的重点论文。
- 可能局限：真实数据规模大但采集域可能集中在 folding，不能直接代表所有 deformable object skills。

### 8. [Assembling Two Parts in One Hand](https://arxiv.org/abs/2609.10137)
- 事实：论文研究单只 dexterous hand 内完成两刚体装配，不借助第二机械臂或夹具。
- 事实：RL formulation 由目标相对位姿驱动，用 function-based auxiliary reward、单个人类参考姿态正则化、domain randomization 和历史 proprioception/object observation 融合增强鲁棒性。
- 推断：这是今天最直接的 in-hand manipulation / robotic hand 论文，且把手形态限制暴露为 benchmark 变量。
- 可能局限：三类装配任务仍较窄，接触失败和状态估计误差可能在更复杂零件上放大。

### 9. [Show-Harness: Just a VLM Agent Can Play Robots](https://arxiv.org/abs/2609.10522)

- 推断：这是低成本 robot agent 接口路线，重点不在大模型变强，而在动作接口能否压住物理决策空间。
- 可能局限：离散 semantic action units 若设计不完整，会把困难从 policy 学习转移到接口工程。

### 10. [Deformable Object Manipulation under Partial Observability via Real-Time Full-Shape Estimation](https://arxiv.org/abs/2609.10308)

- 推断：这是 deformable manipulation under partial observability 的强工程论文，因为它明确对齐控制周期预算。

### 11. [Frequency-Conditioned Flow Matching for Vision-Language-Action Models](https://arxiv.org/abs/2609.10405)

- 推断：它是今天最容易低算力复现的数据质量论文，适合作为 VLA 微调前的过滤器。
- 可能局限：gradient compatibility 依赖 validation set 是否干净且覆盖关键失败模式。

### 13. [Geometry Conditioning in an Embodied SLM: Training Controls and Robustness Diagnostics in a 0.8B Hybrid Model](https://arxiv.org/abs/2609.09213)

### [Grounding Generated Video Plans in Simulation Towards Versatile Dexterous Controllers](https://arxiv.org/abs/2609.10050)
- 改进 1：具体方法改法：把 generated HOI reference 增加接触一致性过滤：用简单 penetration、接触点速度、物体质心能量变化规则筛掉物理不可能片段。 低算力可行原因：只需后处理已有 generated videos/reconstructions，不必重训视频模型。 小实验：在 100 条生成轨迹上比较过滤前后的 HOI tracker 成功率和接触异常率。 预期收益：减少 tracker 学习错误参考。 主要风险：规则过严会丢掉非预期但可行的 non-prehensile 动作。
- 改进 2：具体方法改法：加入 reference uncertainty map：把重建不确定的手/物体点作为低权重 tracking target，而不是等权拟合。 低算力可行原因：只改 tracking loss 权重，可在小仿真集上完成。 小实验：人为遮挡手指或物体边缘，比较等权 loss 与 uncertainty-weighted loss 的 sim success。 预期收益：提升遮挡场景稳定性。 主要风险：不确定性估计本身可能偏。
- 改进 3：具体方法改法：做 language-conditioned failure bucket：按 grasp、push、post-grasp tracking 分开统计失败，并训练小 classifier 预测哪类 reference 更可执行。 低算力可行原因：使用现有 execution logs 和轻量特征即可。 小实验：用 200 条 grounded videos 训练 logistic/MLP 预测执行成功。 预期收益：把生成模型采样从“好看”转向“可执行”。 主要风险：早期日志分布太窄。

### [GTA-2: A Multi-VLM Framework for Synthesizing Robot Manipulation Skills via Grounded Task Axes](https://arxiv.org/abs/2609.09808)
- 改进 1：具体方法改法：给四个 VLM agents 增加 typed intermediate schema，强制 keypoint、axis、controller 参数带单位和坐标系。 低算力可行原因：只改 prompt/schema 与解析器，无需训练。 小实验：在 20 个 tabletop RGB-D 任务上统计 schema violation 与人工修复次数。 预期收益：减少 VLM 输出歧义。 主要风险：schema 过窄会限制新技能表达。
- 改进 2：具体方法改法：加入 counterfactual grounding check：对同一任务替换 distractor object，检查 task axis 是否仍绑定正确目标。 低算力可行原因：可用已有 RGB-D 场景复制和对象替换完成。 小实验：每个任务构造 3 个 distractor 版本，比较 target-axis consistency。 预期收益：增强 object-centric grounding。 主要风险：VLM 可能通过文本先验绕过视觉。
- 改进 3：具体方法改法：把 controller composition 做最小 ablation library：同一 axis 下替换 position/force/impedance 控制器，自动记录失败类型。 低算力可行原因：控制器库小即可，不需大规模 demo。 小实验：选择 5 个插入/旋转/推拉任务比较三种控制器组合。 预期收益：定位“语义分解对了但控制错了”的失败。 主要风险：硬件或仿真控制器实现差异大。

### [Time-Frequency Geometric Cross-Attention for Chunked Vision-Language-Action Models](https://arxiv.org/abs/2609.09925)
- 改进 1：具体方法改法：把 TFGCA 的频带贡献做 per-phase attribution：reach、contact、adjust、settle 分段统计低/高频 attention 贡献。 低算力可行原因：只需保存 action chunks 和 hidden states，分析脚本轻量。 小实验：在 LIBERO 选 50 条 rollout，比较成功/失败轨迹的频带权重差异。 预期收益：证明频域模块是否真的对接触阶段有用。 主要风险：阶段标签自动切分不准。
- 改进 2：具体方法改法：加入 contact-aware frequency mask：接触前偏低频平滑，接触后允许高频修正。 低算力可行原因：只改 guidance/loss mask，可在已有模型上微调。 小实验：用夹爪闭合或物体速度变化近似接触时刻，做 mask on/off 对比。 预期收益：提升高频动作使用效率。 主要风险：错误接触检测会抑制必要修正。
- 改进 3：具体方法改法：做低秩替代版 TFGCA：用固定 DCT + small MLP 替代完整 cross-attention。 低算力可行原因：参数少，适合单卡快速比较。 小实验：同一 VLA backbone 上比较 full TFGCA、low-rank、no-frequency 三组。 预期收益：判断性能来自频域归纳偏置还是大模块容量。 主要风险：低秩版欠拟合。

### [HaWMPO: Hallucination-Aware World Model-based Policy Optimization for Generalist Robot Policy](https://arxiv.org/abs/2609.09941)
- 改进 1：具体方法改法：把 hallucination score 拆成视觉一致性和动作可达性两项，避免只惩罚图像不真实。 低算力可行原因：可用冻结视觉特征距离和简单 IK/碰撞检查实现。 小实验：对 imagined rollouts 同时计算 feature drift 与 IK feasibility，比较哪个更预测真实失败。 预期收益：让 Reward-Soft 更贴近机器人可执行性。 主要风险：可达性检查对复杂接触不充分。
- 改进 2：具体方法改法：加入 short-horizon real anchor refresh：每隔 N 个 imagined steps 用少量真实或高保真 sim 状态重置 latent。 低算力可行原因：不需要大量真实交互，只需复用离线 dataset。 小实验：在 20 条长任务 rollout 上比较无 refresh、每 3 步、每 5 步 refresh。 预期收益：抑制长时程 hallucination 累积。 主要风险：训练/部署分布接口变复杂。
- 改进 3：具体方法改法：使用 disagreement-aware sample selection：多个轻量 world model 对同一 action chunk 分歧大时降低优化权重。 低算力可行原因：训练 3 个小模型或 checkpoint ensemble 即可。 小实验：分析 ensemble variance 与 rollout failure 的相关性。 预期收益：更稳健地过滤坏 imagination。 主要风险：ensemble 成本增加且可能过度保守。

### [DUET-DINO: Simultaneous Cross-View World Modeling for Latent Planning in Robot Manipulation](https://arxiv.org/abs/2609.10506)
- 改进 1：具体方法改法：加 cross-view dropout curriculum：训练时随机丢 wrist/side view，测试双视角缺失或延迟。 低算力可行原因：只改数据增强，不需新数据。 小实验：在 DROID/RoboArena 子集上比较无 dropout 与 curriculum dropout 的 single-view fallback。 预期收益：提升相机遮挡/掉帧鲁棒性。 主要风险：双视角协同能力被削弱。
- 改进 2：具体方法改法：做 view-specific action sensitivity probe：分别测 side/wrist latent 对平移、旋转、夹爪动作的预测误差。 低算力可行原因：分析已有 action-conditioned predictions 即可。 小实验：按动作维度分桶，计算未来特征误差和 planning success。 预期收益：解释双视角为何有效。 主要风险：latent 误差与控制结果未必单调。
- 改进 3：具体方法改法：把 latent planning 加入 collision/risk readout：在 DINO latent 上训练小头预测近场碰撞或 lift force violation。 低算力可行原因：小头训练成本低，可用已有失败标签或仿真标签。 小实验：加入 risk readout 后比较 grasp-and-lift 失败类型。 预期收益：从视觉 future 转向安全 future。 主要风险：标签噪声影响规划。

### [Compact Visuotactile World Models for Lifting: Prediction, Reward Alignment, and Force Constraints](https://arxiv.org/abs/2609.09597)
- 改进 1：具体方法改法：把 force-budget reward 拆成阶段化约束：接触建立、lift、hold 分别设置 margin。 低算力可行原因：只改 reward，不需更大模型。 小实验：在 40 个 test initial conditions 上比较统一 8N 预算与阶段预算。 预期收益：减少因早期保守导致 lift 失败。 主要风险：阶段划分错误会引入奖励漏洞。
- 改进 2：具体方法改法：用触觉 persistence 当 teacher，训练 compact model 预测何时需要真实 force feedback。 低算力可行原因：利用论文已报告 persistence 强 baseline，可做蒸馏。 小实验：训练二分类器决定 open-loop/tactile/force-feedback 模式切换。 预期收益：降低传感和控制成本。 主要风险：切换滞后导致过力。
- 改进 3：具体方法改法：把 trajectory-level calibration 改成 conformal risk controller：直接约束整段 force violation probability。 低算力可行原因：统计校准即可，计算轻量。 小实验：比较 frame-level、trajectory-level、conformal risk 三种 margin 的成功率和违规率。 预期收益：让校准目标更贴近控制安全。 主要风险：小样本下置信区间过宽。

### [FolDeX: A Physical-World Benchmark for Long-Horizon Robotic Manipulation of Deformable Objects](https://arxiv.org/abs/2609.10243)
- 改进 1：具体方法改法：从 FolDeX 中抽取 intervention moment 小基准：只评估失败前后 5 秒恢复。 低算力可行原因：不需训练全长 folding policy，裁剪真实数据即可。 小实验：构造 200 个 intervention clips，评估 VLA 是否预测恢复动作。 预期收益：把长时程 benchmark 分解成可复现子任务。 主要风险：裁剪破坏长期状态依赖。
- 改进 2：具体方法改法：设计跨 garment category 的 state descriptor adapter：用少量关键点/轮廓统计替代类别特定视觉 embedding。 低算力可行原因：只训练小 adapter，数据量低。 小实验：T-shirt 训练，毛巾/裤子测试，比较 adapter vs 原始视觉特征。 预期收益：提升可解释迁移。 主要风险：descriptor 表达不了复杂褶皱。
- 改进 3：具体方法改法：加入 bimanual coordination metric：分开衡量两臂时序差、张力平衡和布料状态进展。 低算力可行原因：可从轨迹和视觉状态离线计算。 小实验：对成功/失败 folding demos 计算指标，检验是否比 task success 更早区分失败。 预期收益：benchmark 更诊断。 主要风险：指标定义可能依赖任务模板。

### [Assembling Two Parts in One Hand](https://arxiv.org/abs/2609.10137)
- 改进 1：具体方法改法：把 finger role assignment 显式离散化：先预测每根手指的 hold/align/push/support 角色，再输出连续动作。 低算力可行原因：只需在仿真中用启发式角色标签预训练小头。 小实验：三类装配任务上比较 role-conditioned policy 与原始 policy 的样本效率。 预期收益：增强 finger-level coordination 可解释性。 主要风险：角色标签过粗限制策略。
- 改进 2：具体方法改法：加入接触图辅助 reward：奖励正确手指-部件接触边，而不是只看最终相对位姿。 低算力可行原因：可由仿真 contact log 直接获得。 小实验：Bottle/Marker 任务中比较无接触图和接触图 reward 的成功率与接触稳定性。 预期收益：减少靠偶然碰撞完成装配。 主要风险：contact reward 可能诱导过多用力。
- 改进 3：具体方法改法：做形态敏感性小实验：冻结策略结构，改变手指长度/关节限位，量化可装配区域。 低算力可行原因：纯仿真参数扫即可。 小实验：每个任务扫 5 个形态变量，报告 success heatmap。 预期收益：把 morphology demand 变成设计指导。 主要风险：仿真手模型与真实硬件偏差。

### [Show-Harness: Just a VLM Agent Can Play Robots](https://arxiv.org/abs/2609.10522)
- 改进 1：具体方法改法：把 semantic action units 做最小完备性测试：统计每次失败是否因 action unit 不存在、解释器失败或 VLM 选择错误。 低算力可行原因：只需人工标注少量失败日志。 小实验：100 次 rollout 后三分类失败归因。 预期收益：定位接口瓶颈。 主要风险：失败归因主观。
- 改进 2：具体方法改法：加入 affordance-like precondition checker：每个 semantic action unit 执行前检查目标是否可达、可见、可抓。 低算力可行原因：可用规则/深度图/开源检测器实现。 小实验：precondition on/off 比较零样本任务安全失败率。 预期收益：减少 VLM 直接做物理决策的风险。 主要风险：checker 漏检会给假安全感。
- 改进 3：具体方法改法：训练小 VLM 的 action-unit contrastive head：让相似视觉状态中不同 action unit 的 embedding 拉开。 低算力可行原因：few GPU-hours 范围内可做 LoRA 或线性头。 小实验：在 GUMI demos 子集上比较 contrastive vs cross-entropy fine-tuning。 预期收益：减少离散动作混淆。 主要风险：过拟合接口词表。

### [Deformable Object Manipulation under Partial Observability via Real-Time Full-Shape Estimation](https://arxiv.org/abs/2609.10308)
- 改进 1：具体方法改法：把 cRVAE 的 latent uncertainty 接入 MPC：不确定区域扩大 obstacle/shape safety margin。 低算力可行原因：只需让 VAE 输出方差并改 cost。 小实验：在 rope/fabric 遮挡比例递增下比较固定 margin 与 uncertainty margin。 预期收益：partial observation 下更安全。 主要风险：保守导致任务完成率下降。
- 改进 2：具体方法改法：加入少量物理参数 token：即使推理不做在线辨识，也给模型输入粗粒度 stiffness/friction bucket。 低算力可行原因：参数 bucket 可由小规模仿真生成。 小实验：跨三种布料刚度测试 no-token vs bucket-token。 预期收益：提升跨材质泛化。 主要风险：bucket 估计错误时反而误导。
- 改进 3：具体方法改法：做 corner sensor placement ablation：比较 2/3/4 个 corner nodes 和非角点观测对 full-shape 估计的影响。 低算力可行原因：只需仿真重采样观测点。 小实验：固定模型容量，扫观测点数量和位置，报告 shape error 与 MPC success。 预期收益：指导真实传感器布置。 主要风险：仿真观测噪声低估真实难度。
