**逐篇要点**
1. LoRA-Muon：把 Muon 的谱最速下降规则迁移到 LoRA 低秩流形；贡献是学习率可跨 rank/宽度/深度迁移；局限是实验规模偏小，但非常适合低算力复现。
2. LoRA scaling：指出 LoRA 的 `alpha` 不是学习率替代品，而是主导优化信号/漂移平衡；贡献是 Signal-Drift 解释；局限是需看更多模型族验证。
3. GRIP：针对 multimodal ICL 的示例检索，不再只按视觉相似度选例；贡献是用反馈信号训练 prompt retrieval；局限是依赖反馈数据质量。
4. PolyFlow：做多面体约束下的 flow matching，避免采样时反复投影；贡献是 constraint embedding + projection-free update；局限是复杂约束泛化仍需看。
5. Clipped ASGD：解释 gradient clipping 为何让异步/联邦 SGD 抗 straggler；贡献是给出 oracle complexity 不依赖最大延迟的理论；局限是理论假设与大模型训练仍有距离。
6. Learning with Simulators：研究有近似 simulator 时的 no-regret/泛化；贡献是把依赖数据过程下的学习保证拉回经典 VC 形式；局限是 simulator 质量假设关键。
7. Module-wise Geometry：发现 Transformer 不同模块偏好不同权重流形约束；贡献是 attention/MLP 的几何分配经验；局限是 GPT-2 预训练设定仍窄。
8. Projection Caustics：用 projection caustics 解释 diffusion/flow sampler 的模式承诺突变；贡献是 CBD 诊断不稳定窗口；局限是理论漂亮但工程收益需验证。
9. OPD sparsity：分析 on-policy distillation 的参数更新稀疏性和几何；贡献是只训练发现的子网络接近完整 OPD；局限是 teacher/student 组合覆盖有限。
10. Path-space DPS：把 diffusion posterior sampling 写成受控随机过程和 trust-region path-space 优化；贡献是更稳的逆问题采样；局限是实现复杂度高于启发式 guidance。
11. Language-Guided AVR：用语言引导 ARC 式视觉抽象；贡献是把视觉直觉与语言抽象结合；局限是可能受 LLM 先验和模板影响。
12. Operadic consistency：提出 label-free 信号检测 LLM compositional reasoning 失败；贡献是从子结论组合一致性入手；局限是 operad 表示的任务适配成本未知。
13. Symbolic World Models：讨论非高斯系统下 symbolic world model 的可辨识和长期一致性；贡献是挑战 Gaussian alignment 边界；局限是实证还需更强基准。
14. Mixed-categorical BBO：用 information-geometric bilevel decomposition 做混合类别黑盒优化；贡献是面向强类别交互；局限是高维真实 HPO/NAS 需进一步测。
15. Logconcave sampling：给出统一复杂度界；贡献是对采样理论和优化理论有基础价值；局限是偏理论，工程直接收益较间接。
16. LLM for VQC design：用 LLM agent 闭环设计量子 feature map/ansatz；贡献是把文献检索、代码生成、实验反馈接起来；局限是 agent 成本和可复现性需关注。
17. SymQNet：为 adaptive Hamiltonian learning 学一个低延迟实验选择策略；贡献是 amortized acquisition；局限是模拟到硬件噪声迁移待检验。
18. Neuro-Symbolic Agents：面向监管流程自动化提出 compliance-by-construction 议程；贡献是把符号约束作为架构核心；局限是偏 agenda，缺少系统实验。

## 10 篇低算力可改进论文
| 论文 | 可改进点与小实验 |
|---|---|
| LoRA-Muon | 改进 rank/alpha/weight decay 联动规则；在 TinyStories 或 SST-2 上扫 rank 2/4/8；收益是调参规律，风险是小模型结论外推弱。 |
| LoRA scaling | 做动态 `alpha` schedule；用 RoBERTa/小 Llama 做同学习率不同 alpha 曲线；收益是简单可复用，风险是任务依赖强。 |
| GRIP | 加入失败样本记忆而非只做反馈检索；用 CLIP 特征加 Qwen2.5-VL 小子集复现；收益是 ICL 选择更稳，风险是反馈噪声。 |
| PolyFlow | 扩展到非凸约束的 toy 任务；2D/3D synthetic polytopes 即可；收益是验证边界行为，风险是离真实机器人约束远。 |
| Projection Caustics | 把 CBD 用在小型 DDPM toy mixture；检查是否预测 prompt/intervention 敏感窗口；收益是诊断工具，风险是指标解释不唯一。 |
| OPD sparsity | 用开源小模型复现“只训子网络”；比较 AdamW vs SGD sparse update；收益是省训练成本，风险是 teacher 质量主导。 |
| Language-Guided AVR | 对 ARC 子集做语言抽象模板消融；无需训练大模型；收益是定位语言帮助来源，风险是模板工程偏手工。 |
| Mixed-categorical BBO | 在 NAS-Bench-201 或 tabular HPO 上加预算约束；收益是样本效率比较清楚，风险是 benchmark 太小。 |
| SymQNet | 用小 qubit Hamiltonian 模拟做主动实验选择 ablation；收益是能复现 acquisition 逻辑，风险是硬件噪声缺失。 |
| S-GBT | 把 certified robustness 从 LSTM/CNN 扩到小 Transformer classifier；收益是方法影响面更大，风险是二阶界可能变松。 |
