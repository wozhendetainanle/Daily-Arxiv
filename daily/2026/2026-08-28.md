## 逐篇要点

### 1. [Reconstructing Humans and Objects in Interaction using Large Reconstruction Models](https://arxiv.org/abs/2608.27407)

- 事实：论文面向单图 3D HOI 重建，使用 Large Reconstruction Models 先给出人和物体的几何 scaffold，再分割人/物、拟合人体模型，并在可用时对齐物体模板；论文称代码见项目页。
- 事实：官方 listing 显示已被 ECCV 2026 接收，项目页显示作者来自 UT Austin。
- 推断：这是今天与 3D HOI、hand-object/whole-body object interaction、具身感知最直接相关的论文，相关性 98；机构强度 8.5 的依据是项目页明示 UT Austin。
- 可能局限：LRM mesh scaffold 能缓解深度与遮挡，但对真实接触、手部细节、物体可操作部件和动态交互的物理一致性仍可能不足。
- 为什么值得关注：可作为从图像重建 3D interaction state 的前端，后续可接 affordance、contact planning 或 robot imitation。

### 2. [Rapid On-Robot Learning for Dynamic Manipulation Skills: Robot Juggling](https://arxiv.org/abs/2608.26800)

- 事实：论文提出在线学习框架，让双臂、多指手机器人在实体硬件上几分钟内学习三球 juggling，包括 cascade、tennis、half-shower、shower、box 等模式。
- 事实：方法结合不完美全局先验、regularized memory-based local model，以及 mutually reachable set 来约束安全 throw/catch 切换。
- 推断：这是今天最强的灵巧操作/双手协调论文之一，相关性 97；机构未从 arXiv listing 或本轮可访问项目页确认，因此机构强度记 3.0。
- 可能局限：juggling 任务虽动态性强，但物体形态、接触状态和手内重定位范围相对窄，泛化到多形状工具操作仍需验证。
- 为什么值得关注：它直接挑战“真实机器人上快速、连续、自我改进”的低交互预算问题，与 dexterous manipulation 和 sim2real 关系紧。

### 3. [Riemann-1.0: An Embodied World Action Model for Physical AI](https://arxiv.org/abs/2608.27033)

- 事实：论文提出因果自回归 World Action Model，把多视角视觉、机器人状态和 embodiment-specific actions 放入统一序列，显式建模 action 与 world evolution 的因果状态转移。
- 事实：arXiv listing 将其归为 Robotics。
- 推断：相关性 96，主要因为它把世界模型与机器人动作生成合并，而不是只做视频预测；机构未确认，机构强度 3.0。
- 可能局限：摘要未给出足够细的跨机器人/跨任务泛化边界；如果数据规模依赖很强，小实验复现难度可能较高。
- 为什么值得关注：若实现扎实，它会成为 VLA 与 video/world model 之间的关键桥梁，尤其适合看 action token、状态 token 和多视角观测如何耦合。

### 4. [CLAP: Cross-Embodiment Video World Models are Zero-Shot Physical Simulators](https://arxiv.org/abs/2608.27406)

- 事实：CLAP 研究跨 embodiment 的 action-conditioned video world model，统一 end-effector pose、language instruction 与 latent action 三类动作条件。
- 事实：摘要称方法利用人类与机器人视频学习通用物理先验，随后把先验落到 end-effector action space；覆盖 DROID、Bridge、bimanual YAM、G1 humanoid 等形态，代码和模型开源。
- 推断：相关性 95，因为它直接覆盖 cross-embodiment、world model、bimanual robot 和 zero-shot simulator；项目页显示 affiliation coming soon，所以机构未确认、机构强度 3.0。
- 可能局限：跨 embodiment 的“同一物理规律”假设需要严谨拆分动作表征收益、视频规模收益和机器人数据收益。
- 为什么值得关注：它是把大规模视频世界模型迁移到真实机器人操作的强候选路线。

### 5. [TemporalFlow-VLA: Learning Physically Grounded Execution History for Long-Horizon Robot Manipulation](https://arxiv.org/abs/2608.26821)

- 事实：论文指出多帧历史不一定能表达最近物理变化，提出用机器人状态、机器人几何和标定相机构建 robot-surface temporal flow，作为训练期监督信号。
- 事实：摘要报告 LIBERO 平均成功率 97.63%，LIBERO Long 96.60%，RoboTwin 12 任务 Clean/Randomized 成功率 85.5%/84.2%；部署时不使用几何监督路径，并用异步缓存保持近单帧采样延迟。
- 推断：相关性 95，重点在 VLA long-horizon manipulation 和物理执行历史建模；机构未确认，机构强度 3.0。
- 可能局限：temporal flow 依赖较完整的机器人几何和相机标定，非标平台或手部软体/多指接触可能更难构造监督。
- 为什么值得关注：这比简单加历史帧更机制化，适合借鉴到 contact-rich 或 dexterous manipulation 的 history representation。

### 6. [GRAFT: Grounded and Efficient Online Reinforcement Adaptation for Fine-Grained Robot Manipulation](https://arxiv.org/abs/2608.27079)

- 事实：GRAFT 面向细粒度 biomedical robot manipulation 的在线 VLA adaptation，使用 region-level supervision 学 view-specific visual anchors，部署时不需要 region proposal。
- 事实：方法还结合 single-step action generation 和 cached visual-language prefix reuse；摘要称四个 biomedical manipulation 任务上在相同 adaptation budget 下成功率提升 25 个百分点。
- 推断：相关性 94，核心在在线适应、视觉 grounding、细粒度操控；机构未确认，机构强度 3.0。
- 可能局限：region-level supervision 的获取成本、标注粒度和跨视角迁移稳定性是关键风险。
- 为什么值得关注：它把 VLA 的高层泛化和局部视觉锚点绑定，适合衍生 affordance/contact-region guided adaptation。

### 7. [FLARE: A Failure-Aware Framework for Autonomous Correction and Recovery in Visual-Language Robotic Manipulation](https://arxiv.org/abs/2608.26645)

- 事实：FLARE 针对 VLA 在长程、接触丰富操作中难以从 missed grasp、dropped object、unexpected collision 等失败恢复的问题。
- 事实：方法包含 Retry 机制和 Reset pipeline：通过扰动/桥接段扩展演示，并用 MLLM 离线分析执行视频来识别 OOD 状态，收集 object-centric reset skills；论文被 CVPR 2026 接收。
- 推断：相关性 93，重点在 failure recovery、VLA manipulation、contact-rich execution；机构未确认，机构强度 3.0。
- 可能局限：Reset skill library 的规模、覆盖率和失败检测延迟会决定真实部署收益。
- 为什么值得关注：它直接面向机器人操作里最常见的闭环失败恢复，而不是只追求离线成功率。

### 8. [FlashVLA: Streaming Action Decoding for Fast and Asynchronous VLA Inference](https://arxiv.org/abs/2608.27384)

- 事实：FlashVLA 关注 VLA 在真实机器人部署中的高推理延迟和异步执行不稳定，尤其是 flow-matching VLA 需要多步 action decoding。
- 事实：论文提出 streaming action decoding，在同一框架下处理低延迟推理和时间一致的异步执行。
- 推断：相关性 92，因为它切中 VLA control frequency 的实际瓶颈；机构未确认，机构强度 3.0。
- 可能局限：摘要未完全说明对精细接触任务的稳定性，以及流式 action 被部分修正时是否会引入动作不连续。
- 为什么值得关注：对任何 VLA manipulation 系统，推理 latency 很快会成为真实闭环控制瓶颈。

### 9. [TrapVLA: Trapping Vision-Language-Action Models in Configured Failure Modes](https://arxiv.org/abs/2608.26578)

- 事实：TrapVLA 定义 Configured Failure Trapping，对 VLA 注入隐蔽文本触发，让机器人进入指定失败模式，例如以特定位姿偏移去抓取。
- 事实：论文构建 Trap-LIBERO 和 Trap-RoboTwin 两个 benchmark，提出学习 trigger-induced action residual 的攻击方法；项目页显示机构为 Sun Yat-sen University、Pengcheng Laboratory、HKU、Jiangxing Intelligence。
- 推断：相关性 92，原因是它从安全角度直接作用于 VLA manipulation；机构强度 8.0 基于项目页显示的高校/实验室组合。
- 可能局限：攻击设置是否贴近真实自然语言误导、以及防御评估是否充分，是阅读重点。
- 为什么值得关注：VLA 安全不能只看“失败”，还要看攻击者是否能控制失败形态，这对具身系统更危险。

### 10. [PredVLA: A Sub-Million-Parameter Predictive-Coding Policy for Robot Manipulation](https://arxiv.org/abs/2608.26673)

- 事实：PredVLA 是 0.68M 参数的 language-conditioned predictive-coding policy，不依赖 robot-data pretraining，通过层级生成式循环动力学预测视觉特征和 proprioception。
- 事实：摘要报告 LIBERO 三个短程套件平均成功率 86.9%，加入长程套件后 75.4%；在相同 frozen front end、demonstrations、action decoder 和评估协议下优于同参数 Transformer/LSTM。
- 推断：相关性 91，原因是它挑战大 VLA 的规模假设，并提供可关闭 prediction-error latent inference 的 open-loop 对照；机构未确认，机构强度 3.0。
- 可能局限：长程任务仍有明显下降，且是否能扩展到触觉/多指手还未明确。
- 为什么值得关注：小模型、机制清楚、可做因果 ablation，非常适合低算力复现。

### 11. [Active Surface-Driven Reconfigurable Gripper](https://arxiv.org/abs/2608.26883)

- 事实：论文针对书本、纸张、织物、塑料膜等薄物体抓取，提出带 active-surface thumb 和 underactuated compliance 的重构夹爪。
- 事实：方法建模桌面平放和书架竖放两类场景，结合物理模型优化结构参数和抓取策略；RSS 2026 接收。
- 推断：相关性 90，属于 grasp affordance/manipulation affordance 的硬件侧强候选；机构未确认，机构强度 3.0。
- 可能局限：薄物体类别虽然丰富，但仍集中在片状/柔性对象，复杂工具或非平面薄物体需要额外验证。
- 为什么值得关注：它把 object affordance 从视觉标签推进到具体接触几何和机械结构。

### 12. [KnockGS: interaction-Grounded Calibration of Physical Gaussian Representations](https://arxiv.org/abs/2608.27365)

- 事实：KnockGS 用已知外力下的动态响应来估计 3D Gaussian 物体的 elasticity 和 density scale，再把估计参数写回同一 simulator 测试。
- 事实：论文在隐藏材料参数恢复、3D particle trajectories、response-curve statistics 和 rendered-frame quality 上评估，声称优于 response retrieval、global regression 和固定默认材料。

## 10 篇低算力可改进论文

### 1. [MILO: Reconstructing Humans and Objects in Interaction](https://arxiv.org/abs/2608.27407)

1. 改进点：在 LRM mesh segmentation 后增加 contact-aware refinement，用 Chamfer/contact distance、penetration penalty 和 hand/object surface normal consistency 微调 SMPL/SMPL-X 与物体位姿；低算力原因：只优化单样本或小 batch 几何变量，不需重训 LRM；小实验：在 BEHAVE/InterCap 子集上比较 contact F1、penetration depth 和 object pose error；预期收益：提升手-物/身体-物接触可信度；风险：过强接触约束可能牺牲投影一致性。
2. 改进点：把物体模板对齐扩展为 retrieval-then-deform，先用开放词汇类别检索粗模板，再用少量 control points 做非刚性拟合；低算力原因：模板检索和小规模优化即可；小实验：选 5 类常见可操作物体，比较无模板、刚性模板和可变形模板；预期收益：改善物体形状 variability；风险：检索错类会引入系统性偏差。
3. 改进点：增加 affordance tag head，把 mesh 区域预测为 support、handle、contact、occluding 等功能区域；低算力原因：可用少量人工/伪标签训练浅层 head；小实验：对 100 张 HOI 图像手标 contact/handle 区域，测区域 IoU 和机器人抓取启发式成功率；预期收益：让 3D HOI 输出更接机器人任务；风险：标签定义可能不稳定。

### 2. [Rapid On-Robot Learning for Robot Juggling](https://arxiv.org/abs/2608.26800)

1. 改进点：把 memory-based local model 改为 uncertainty-gated mixture，在经验稀疏处自动提高 global prior 权重，在重复接触区域提高 local model 权重；低算力原因：只在低维 throw/catch state 上拟合小模型；小实验：仿真或硬件日志重放中比较固定混合权重与不确定性门控；预期收益：减少早期在线学习不稳定；风险：不确定性估计错误会抑制有效探索。
2. 改进点：在 mutually reachable set 中加入视觉置信度和球轨迹预测方差，形成 chance-constrained reachable set；低算力原因：可用现有视觉轨迹输出加小型 Kalman/ensemble；小实验：人工注入遮挡和检测噪声，测 unsafe transition 次数和成功接球率；预期收益：让安全约束更贴近真实视觉误差；风险：约束过保守会降低动作多样性。
3. 改进点：增加 pattern-level curriculum scheduler，按失败类型从单球、双球到三球组合逐步开放动作模板；低算力原因：调度器是规则或小表格，不重训大模型；小实验：比较固定练习顺序与失败驱动 curriculum 的 5 分钟学习曲线；预期收益：提高样本效率；风险：课程策略可能过拟合特定机器人动力学。

### 3. [TemporalFlow-VLA](https://arxiv.org/abs/2608.26821)

1. 改进点：把 robot-surface temporal flow 扩展为 object-surface/contact temporal flow，使用物体 mask/depth 或手工接触点生成额外监督；低算力原因：只添加训练 target，可冻结主 VLA 前端微调 temporal queries；小实验：在 LIBERO/RoboTwin 选择 3 个移动物体任务，对比只用 robot flow 与 robot+object flow；预期收益：提高对物体状态变化的敏感度；风险：物体 mask 误差会污染监督。
2. 改进点：做 history order counterfactual regularization，随机交换近邻历史帧并惩罚 action logits 不合理不变；低算力原因：数据增强和 loss 级修改即可；小实验：固定模型规模，测 long-horizon tasks 中 shuffled-history 干预后的成功率下降是否更符合预期；预期收益：强化真正的时间因果使用；风险：过强正则可能降低对准静态任务的鲁棒性。
3. 改进点：把异步特征缓存改为 event-triggered cache refresh，当视觉差分或动作残差超过阈值才刷新；低算力原因：推理工程改动，无需训练；小实验：测 RoboTwin randomized 下 latency、cache hit rate、success；预期收益：在动态阶段获得更好历史表示；风险：阈值不稳会导致缓存抖动。

### 4. [GRAFT](https://arxiv.org/abs/2608.27079)

1. 改进点：把 region-level supervision 从人工区域扩展为 language-to-region weak labels，用 GroundingDINO/SAM 伪标 task-relevant anchors；低算力原因：离线伪标和小 adapter 训练即可；小实验：四个 biomedical task 各取 20 条演示，比较人工区域、伪区域、无区域；预期收益：降低部署到新任务的标注成本；风险：开放词汇 grounding 在专业器械上可能错。
2. 改进点：加入 contact-proxy reward，将视觉 anchor 区域的运动、遮挡和工具接近度组合成 dense reward；低算力原因：基于已有视频特征，不需额外传感；小实验：用离线日志做 reward ranking，再小规模在线 adaptation；预期收益：缓解 task-level sparse reward；风险：proxy reward 可能奖励视觉接近而非真实操作成功。
3. 改进点：对 cached prefix 做 task-phase segmentation，不同阶段缓存不同视觉语言前缀，避免长任务阶段错配；低算力原因：阶段可以由动作/语言规则或小聚类得到；小实验：在 2 个多阶段任务上比较全局 prefix 与 phase prefix；预期收益：减少在线更新开销同时保持阶段敏感；风险：阶段切分错误会带来灾难性动作。

### 5. [FLARE](https://arxiv.org/abs/2608.26645)

1. 改进点：把 Retry/Reset 仲裁改为 explicit failure taxonomy，包括 missed grasp、slip、collision、object displaced、goal invalid 等离散标签；低算力原因：可用 MLLM 零样本或少量标注训练轻量分类器；小实验：标注 100 段失败视频，测分类准确率和 reset skill 选择成功率；预期收益：提升恢复策略可解释性；风险：失败类别边界不清。
2. 改进点：为 Reset skill library 增加 coverage estimator，记录每个 reset skill 覆盖的 object state region；低算力原因：只维护低维状态覆盖图；小实验：在已有任务中故意扰动物体位置，测覆盖估计与恢复成功相关性；预期收益：知道何时不该盲目 reset；风险：状态表征过粗会低估风险。
3. 改进点：将 perturbation/bridging segments 改为自动最小扰动生成，让演示更接近真实失败分布；低算力原因：在已有轨迹上做局部插值和小优化；小实验：比较随机扰动、人工扰动和最小扰动桥接对成功率的影响；预期收益：减少训练分布偏差；风险：过于温和的扰动不能覆盖真实失败。

### 6. [PredVLA](https://arxiv.org/abs/2608.26673)

1. 改进点：增加 tactile/proprioceptive prediction head，即使没有真实触觉也用接触事件或 gripper force proxy 作辅助预测；低算力原因：0.68M 主体可保持不变，只加小 head；小实验：在 LIBERO 把 gripper state/contact proxy 作为辅助目标，测长程任务成功率；预期收益：提升接触状态估计；风险：伪触觉噪声可能干扰视觉预测。
2. 改进点：设计 open-loop degradation suite，系统关闭 prediction-error latent inference 的不同通道，量化视觉、proprioception、语言各自贡献；低算力原因：无需重训，只做推理干预；小实验：对每个任务记录 closed-loop、no-vision-correction、no-proprio-correction、full-open-loop；预期收益：让小模型优势更机制化；风险：干预实现若不等价会导致解释偏差。
3. 改进点：用 LoRA/adapter 把 frozen visual front end 的中间层接入 predictive coding，而不是只接最终特征；低算力原因：训练参数少；小实验：比较 final-feature、mid-level-feature、multi-scale-feature 三种输入；预期收益：改善细粒度物体位姿敏感性；风险：中间层特征维度高会破坏轻量优势。

### 7. [Active Surface-Driven Reconfigurable Gripper](https://arxiv.org/abs/2608.26883)

1. 改进点：把薄物体抓取策略显式建成 affordance map，预测可插入边缘、可摩擦滑移区域和可支撑面；低算力原因：小数据几何规则或浅层视觉模型即可；小实验：对书、纸、布、薄塑料各采 20 个姿态，比较人工规则与视觉 affordance map；预期收益：提高对未知薄物体的策略选择；风险：透明/反光材料难以分割。
2. 改进点：增加低成本 tactile strip 或电流反馈，用于检测 active-surface thumb 是否完成重定位；低算力原因：传感处理是阈值或小滤波器；小实验：同一夹爪在无反馈和有反馈下做连续 grasp-place 任务；预期收益：减少滑移和未完全夹取；风险：硬件改动带来校准成本。
3. 改进点：建立简化仿真参数扫描，把摩擦、厚度、柔性和初始姿态作为 domain randomization；低算力原因：准静态/低维仿真即可；小实验：找出最容易失败的参数组合并回到真实测试；预期收益：指导结构参数优化；风险：简化仿真可能无法捕捉薄物体弯折。

### 8. [KnockGS](https://arxiv.org/abs/2608.27365)

1. 改进点：从已知力扩展到 unknown-force joint estimation，同时估计外力脉冲和材料参数；低算力原因：只在少数标量参数上做优化或粒子滤波；小实验：用合成 PhysicalGS 序列隐藏力大小，比较已知力和联合估计误差；预期收益：更接近机器人真实敲击；风险：力和材料参数可能不可辨识。
2. 改进点：加入多点/多方向主动探测策略，选择下一次敲击位置来最大化材料参数信息增益；低算力原因：候选动作离散，模拟少量 rollout；小实验：比较随机敲击、固定敲击和信息增益敲击的参数收敛速度；预期收益：减少交互次数；风险：模拟偏差会误导探测。
3. 改进点：把 rendered-frame quality 与 particle trajectory loss 做权重自适应，避免只拟合视觉或只拟合物理；低算力原因：loss reweighting 不改大模型；小实验：在 5 个材料目标上扫权重，测跨方向 re-simulation fidelity；预期收益：提高视觉-物理一致性；风险：指标间冲突可能无单一最优点。

### 9. [MeshPriorDiT](https://arxiv.org/abs/2608.26766)

1. 改进点：把 mesh GNN prior 设为可置信度输出，让 Residual DiT 只在高不确定区域生成残差；低算力原因：加一个 uncertainty head，不增大 DiT；小实验：15-step rollout 上比较全局残差与不确定性门控残差；预期收益：减少生成模型破坏局部物理；风险：不确定性校准难。
2. 改进点：显式加入 grasp/contact constraint token，把夹爪接触点、固定点和滑移状态作为 DiT 条件；低算力原因：条件 token 维度小；小实验：在三种布料任务中只标少量接触点，测 Edge-strain MSE 和成功预测率；预期收益：改善操作相关区域的动力学；风险：接触标注误差放大。
3. 改进点：做 rollout error correction schedule，短程用 GNN prior，长程逐步提高 residual correction；低算力原因：推理调度或训练 curriculum；小实验：比较固定 residual scale 与 horizon-dependent scale；预期收益：降低自回归漂移；风险：不同任务最优 schedule 不同。

### 10. [Cross-Platform Benchmark of Neural 3D Reconstruction for Autonomous Laboratory Robots](https://arxiv.org/abs/2608.26383)

1. 改进点：增加 manipulation-aware reconstruction metrics，例如 graspable edge fidelity、support plane error、object scale drift 和 collision proxy，而不只看 view synthesis；低算力原因：评估脚本和少量标注即可；小实验：在现有实验室物体上手标可抓边缘，比较 NeRF/3DGS/SAM3D 排名是否变化；预期收益：让 benchmark 更服务机器人；风险：人工指标主观性高。
2. 改进点：提出 tiered scheduling policy，根据机器人任务阶段选择 SAM3D 快速重建、3DGS 局部优化或 NeRF 离线优化；低算力原因：只做策略层仿真和少量真实计时；小实验：模拟 10 个实验室抓取/观察任务的 latency budget，测任务完成率；预期收益：把 benchmark 变成可执行系统建议；风险：不同硬件平台差异大。
3. 改进点：引入 transparent/reflective/low-texture subset，因为实验室物体常见此类失败模式；低算力原因：采集少量对象即可；小实验：每类 5 个对象，比较几何误差与下游抓取启发式；预期收益：暴露真实场景短板；风险：数据规模小导致统计不稳。

## 重大更新 / Replacement submissions

以下论文出现在 Replacement submissions，不进入今日 New 主榜，但与当前主题高度相关，建议作为更新跟踪：

- [GraG: Learning 3D Grasping with Simple 2D Images](https://arxiv.org/abs/2604.12929)：3D grasping 与 2D image learning 相关，适合关注低成本抓取泛化。
- [TouchThinker: Advancing Vision-Language Models for Tactile Reasoning](https://arxiv.org/abs/2606.11637)：触觉推理与 VLM 结合，和 tactile dexterity 方向高度相关。

- [Pre-training Visual Dexterity in Simulation Enables Closed-loop In-hand 3D Object Reconstruction](https://arxiv.org/abs/2608.15917)：in-hand 3D object reconstruction 与 visual dexterity 交叉，值得跟踪更新内容。

- [Embodied-Navigator: Generalist Embodied Agent with Visual Semantic Navigation](https://arxiv.org/abs/2608.17512)：导航型 embodied agent 更新，非 manipulation 但与 spatial embodied agents 相关。
