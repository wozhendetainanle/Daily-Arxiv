**论文要点**

1. Score Hamiltonian
- 核心问题：把 score-based diffusion 采样与绝热输运/薛定谔算子联系起来。
- 方法贡献：提出 Score Hamiltonian，并给出密度重构界和退火日程解释。
- 关注点：为 diffusion 理论提供物理化框架；局限是实际模型误差和谱隙估计可能难。

2. LeanMarathon
- 核心问题：长程 Lean autoformalization 容易上下文漂移、依赖错乱。
- 方法贡献：多 agent + evolving blueprint + CI-gated repair，完成 7 个目标定理且无 sorry。
- 关注点：neural-symbolic/形式化数学很强；值得看系统设计和可复现实验。

3. LoRA 高维理论
- 核心问题：解释预训练表示如何影响有限数据 LoRA fine-tuning。
- 方法贡献：在可解 attention 模型中给出高维极限、误差和表示对齐预测。
- 关注点：LoRA 理论少见且方向正；局限是 rank-one/简化模型到真实 LLM 的外推。

4. NF-CoT
- 核心问题：文本 CoT 成本高，现有 latent reasoning 又损失 likelihood/KV-cache 兼容性。
- 方法贡献：用 normalizing flows 建模连续 thought token，保留自回归接口。
- 关注点：flow + reasoning 结合紧；建议细看训练稳定性和 latent 可解释性。

5. DRIFT
- 核心问题：VLM 离散 token 接口不适合连续定位/控制输出。
- 方法贡献：粗预测器 + flow matching residual refinement。
- 关注点：对 VLA/机器人控制有用；局限是 residual 分布是否总比全局分布简单需验证。

6. TLA-Prover
- 核心问题：LLM 生成 TLA+ 常语义不正确。
- 方法贡献：SFT + repair-based GRPO + TLC 直接作 reward，pass@1 显著高于未调 baseline。
- 关注点：verifiable reward 的 formal-method 小闭环很清晰；算力门槛相对可控。

7. Multimarginal Flow Matching
- 核心问题：普通 flow matching 只约束端点，忽略中间 observed marginals。
- 方法贡献：用 OT potential 软约束多边际动态，应用到单细胞、海洋、气象数据。
- 关注点：scientific ML 中很实用；affiliation 仅弱确认。

8. DoPr
- 核心问题：验证损失最优的 optimizer 不一定带来 rollout/test-time performance。
- 方法贡献：双重预条件鼓励更均匀 feature learning，缓解 test-time feedback。
- 关注点：对自回归、flow、机器人策略都相关；建议看与 AdamW/Muon 的组合实验。

9. Thinking with Imagination
- 核心问题：VLM 难以推断未观察视角和空间布局。
- 方法贡献：RL-trained VLM policy 调用 world simulator 生成 imagined observations。
- 关注点：abstract/visual spatial reasoning 很对口；局限是 simulator 一致性和幻觉风险。

10. Geodesic Flow Matching
- 核心问题：盲图像复原中的退化空间不是欧氏线性结构。
- 方法贡献：把退化建模为低维黎曼流形，用 geodesic flow matching 学内禀输运。
- 关注点：理论动机清楚；需看真实 mixed degradation 上是否胜过强 diffusion baseline。

11. LatentSkill
- 核心问题：LLM agent 每步塞 textual skill 有上下文成本和泄露风险。
- 方法贡献：用 hypernetwork 把文本技能转为可插拔 LoRA adapters。
- 关注点：ICL-to-weight 的方向很有潜力；风险是技能更新和冲突合并。

12. Smooth DNN Uniform Convergence
- 核心问题：ReLU 网络在 uniform convergence 上可能受维度灾难影响。
- 方法贡献：给 smooth DNN 的 pseudo-dimension、近似和非渐近 uniform rates。
- 关注点：理论质量高；实用意义在 worst-case reliability。

13. PC Layer
- 核心问题：LLM 预训练中权重谱条件数影响优化稳定性。
- 方法贡献：多项式权重预条件层，训练后可 merge，无推理开销。
- 关注点：和 Muon/AdamW 都相关；小模型复现价值高。

14. Reactive Flux Matching
- 核心问题：稀有事件路径采样有数据，但机制解释和自适应采样难。
- 方法贡献：学习 reactive current velocity 与 reaction coordinate。
- 关注点：flow matching 扩展到科学机制发现；局限是依赖高质量反应轨迹集合。

15. Dominant-Layer ZO
- 核心问题：ZO fine-tuning 省显存但不知道更新集中在哪些层。
- 方法贡献：发现单个 dominant layer 常可匹配全模型 ZO，并能由 activation outlier 预选。
- 关注点：低算力 fine-tuning 很实用；需防止任务/模型族外失效。

16. Code2LoRA
- 核心问题：代码模型需要 repo 知识，RAG 长上下文和 per-repo 微调都贵。
- 方法贡献：hypernetwork 从 repo snapshot/diff 生成 LoRA adapter。
- 关注点：软件演化场景很新；风险是 benchmark 与真实大型 monorepo 差距。

17. Sharp Lower Bounds
- 核心问题：高阶光滑非凸优化的一阶 oracle lower bound 是否匹配上界。
- 方法贡献：给 Hessian-Lipschitz 和三阶光滑情形的匹配下界。
- 关注点：理论结果干净；更偏优化理论，不是直接算法改进。

18. Quantum Rare Event
- 核心问题：未知稀有事件采样需要巨大样本开销。
- 方法贡献：不预先知道稀有事件集合也能做量子发现/采样，并给最优量子缩放。
- 关注点：与 AI safety edge case 有概念关联；实现依赖量子硬件假设。

19. TLA+ Evaluation
- 核心问题：当前 LLM 能否从自然语言可靠生成 TLA+。
- 方法贡献：评测 30 个模型，语义正确率很低， progressive prompting 才有效。
- 关注点：是 TLA-Prover 的必要背景；改进空间明确。

20. SASA
- 核心问题：标准 SAE 把多维特征拆成许多单向量 latent，影响可解释性。
- 方法贡献：subspace decoder + block sparsity + nuclear norm。
- 关注点：mechanistic interpretability 很相关；小模型可复现。

21. MGSD Visual Planning
- 核心问题：视觉规划要先从像素恢复符号状态，再做多步推理。
- 方法贡献：训练时用 symbolic teacher，自蒸馏给视觉 student，推理时纯视觉。
- 关注点：neural-symbolic bridge 清楚；可在 grid/planning toy tasks 上扩展。

22. LoRA Memory vs KV Cache
- 核心问题：document LoRA 与 KV cache context memory 如何互补。
- 方法贡献：发现 KV 被强压缩时 LoRA 才显著贡献，像 decoding-time parametric memory。
- 关注点：对长上下文/RAG/parametric memory 有直接启发。

23. Quantum Triangle Cut Sparsification
- 核心问题：三角形 cut sparsifier 如何利用量子 triangle listing 加速。
- 方法贡献：给量子 listing 算法与 sparsifier 构造。
- 关注点：quantum + graph algorithms；非 cs 主分类但含 cs.DS。

24. TS-ICL
- 核心问题：时间序列 foundation model 往往只做 forecasting，缺少统一 imputation。
- 方法贡献：time-indexed ICL encoder-regressor Transformer，支持协变量和缺失观测。
- 关注点：ICL 迁移到时序任务；低算力可用小数据集验证。

25. ATWU Unlearning
- 核心问题：LLM unlearning 中不是所有 token 都同样该忘。
- 方法贡献：用 retain-conflict 学 token-level forget specificity，无需外部 token 标注。
- 关注点：方法轻量；风险是 forget/retain 边界定义依赖数据集。

26. SDP Quantum State Families
- 核心问题：判断状态族是否 classically simulable。
- 方法贡献：构造完整 SDP hierarchy 和 dual witness。
- 关注点：偏量子信息理论；对 tensor/convex optimization 读者有价值。

27. Utility-Scale QAOA Angles
- 核心问题：100+ qubit QAOA 角度设置缺乏实践准则。
- 方法贡献：比较 MPS、Pauli propagation、小到大角度迁移，并上硬件验证。
- 关注点：机构强、工程价值高；但需要量子硬件资源。
