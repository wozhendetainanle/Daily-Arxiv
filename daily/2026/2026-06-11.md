**逐篇要点**
1. Flow Matching 理论：建立 NN 参数化 velocity field 的 GD 收敛、泛化与 Wasserstein 采样保证；假设偏强但很适合作为 flow matching 理论基线。
2. MPS 无差局部极小：解释 tensor network/MPS 为何比浅量子线路更可训练；亮点是 gauge freedom 等价于局部过参数化；非 cs 但与优化地形高度相关。
3. MFD：把 flow distillation 解释为低通滤波，降低 VSD 高方差；目标是单步/少步生成；局限在复杂大模型下训练成本仍需验证。
4. Flow-DPPO：用精确 Gaussian KL 替代 PPO ratio clipping；适合 flow-based image/video RL alignment；风险是 reward model 偏差仍可能主导。
5. FlowBP：把 reward backprop 的反向轨迹设计成可控 surrogate；降低存储与 Jacobian 链式爆炸；值得看其 active-set 选择能否泛化。
6. Mean-field attention：把多头 attention 视为粒子系统，得到 Wasserstein gradient-flow PDE；理论漂亮但模型简化明显。
7. FOGO：将遗忘视为通用梯度干扰问题，用正交化与方向记忆保护稀有更新；亮点是覆盖优化器和 continual learning；需独立复现开销。
8. Compression & generalization：用 prompt 压缩/二值反馈解释 ML research agents 不易 benchmark overfit；概念新，适合研究 agent 科学发现的可证伪机制。
9. 3SPO：把 LLM agent RL 从轨迹级推到 step-wise state score；声称在 ALFWorld/WebShop 优于 GRPO；需关注 state score 是否会过拟合环境。
10. FlatPO：发现 PEFT 泛化由少量 sharp dimensions 主导，并只平滑关键维度；低成本、可复用；需看更多非视觉任务。
11. SDBN：把 adversarial training 引入 PEFT 的小数据噪声场景；优点是不加参数；风险是扰动集合设计可能决定效果。
12. Which LoRA：多语指令微调中复杂 LoRA 变体未显著优于 basic LoRA；负结果有价值；局限是模型/语言覆盖仍有限。
13. EEVEE：面向多数据流 test-time prompt learning，用 router-prompt co-evolution 减少跨任务干扰；很适合 agent ICL；需验证长期漂移。
14. VIBE：给 visual ICL 做跨域、跨任务统一 benchmark；贡献主要是评测协议；可直接作为后续 AVR/VICL 测试平台。
15. Tiny VICL：1M 参数小模型挑战视觉 ICL “规模即能力”叙事；亮点是低算力反例；可扩展到抽象视觉推理。
16. Quantum permutation：在连接受限量子硬件上做均匀置换生成；给出线性深度构造和 Beneš-like 非均匀性证明；非 cs 但量子优化相关。
17. Kernel bandits：统一 GP-UCB 与 DEC/MAMS 的算法信息视角；适合看 minimax 与算法复杂度差异；理论读者优先。
18. GIF HPO：用 warm-start 估计重要性再分组调度 HPO budget；工程上 plug-compatible；需在真实大模型调参中验证。
19. FoA-SR：用 profile-aware preference optimization 区分 faithful/aesthetic SR；结合 flow matching 和 LoRA adapter；较偏应用。
20. NOVA：Rust symbolic regression 搜索可解释驾驶模型；优势是结构可解释与低算力；局限是领域较窄但 neural-symbolic 价值明确。

## 10 篇低算力可改进论文
1. [Which LoRA?](https://arxiv.org/abs/2606.10428)：改进点是加入 rank/target-module 交互；低算力因 basic LoRA 即可；实验：3 个低资源语言小模型；收益是更可靠的 LoRA 选择，风险是结论依赖语料。
2. [Small Data, Big Noise](https://arxiv.org/abs/2606.10610)：改进点是扰动集合消融；低算力因 PEFT+小数据；实验：Banking77 逐步加噪；收益是稳健性边界，风险是只对分类有效。
3. [FlatPO](https://arxiv.org/abs/2606.10488)：改进点是验证 sharp dimensions 是否跨任务稳定；低算力因只改 PEFT 梯度；实验：CLIP/VLM 小任务；收益是通用 PEFT 规则，风险是指标不稳。
4. [VIBE](https://arxiv.org/abs/2606.10967)：改进点是加入 ARC-like 抽象形状任务；低算力因主要是评测；实验：合成几何变换 one-shot；收益是连接 AVR，风险是任务过合成。
5. [Tiny VICL](https://arxiv.org/abs/2606.10905)：改进点是更严格区分“记住任务编码”和“上下文推理”；低算力因 1M 模型；实验：打乱 prompt encoding；收益是评测更干净，风险是小模型欠拟合。
6. [EEVEE](https://arxiv.org/abs/2606.11182)：改进点是 router 加 replay/uncertainty；低算力因只调 prompt；实验：4 个小 benchmark 顺序流；收益是降低灾难性 prompt 漂移，风险是路由复杂化。
7. [FOGO](https://arxiv.org/abs/2606.10406)：改进点是 memory size 与 random projection 维度曲线；低算力因可在 CIFAR/GPT-2 small；实验：与 AdamW/Muon 小规模对比；收益是明确开销-收益，风险是实现细节敏感。
8. [GIF HPO](https://arxiv.org/abs/2606.10068)：改进点是接入 Optuna/BOHB 的真实 API；低算力因可用 NAS-Bench/解析函数；实验：固定 50 trials；收益是实用调参插件，风险是高维假设不总成立。
9. [Flow-DPPO](https://arxiv.org/abs/2606.11025)：改进点是小模型上测试 predictive divergence mask；低算力因可用小 diffusion/LoRA；实验：CIFAR 或 toy T2I reward；收益是验证 KL mask 必要性，风险是小模型不代表视频生成。
10. [NOVA](https://arxiv.org/abs/2606.10583)：改进点是合成动力系统上做 identifiability 测试；低算力因 symbolic search 可控；实验：带噪 car-following simulator；收益是证明发现机制，风险是现实数据外推有限。
